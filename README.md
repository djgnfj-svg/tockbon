# 탁본 (Tockbon)

**다시 짓는 중이다. 게임을 세 번 접었고, 2026-08-22 저녁에 세 번째로 돌아가 코드를 되살렸다.**

## 지금 만드는 것 — **세포 군대 로그라이크**

**네모난 세포 열 마리로 시작해 섬을 하나씩 먹고, 먹은 것으로 군대를 만들어, 마지막 섬의 사자와 붙는다.**
**전투 중에는 손이 안 움직인다** — 어디에 내리느냐가 누구와 붙느냐를 정하는 것이 이 게임의 결정이다.

**틀 넷이 2026-08-22 저녁에 정해졌다**: **12월에 데모**를 낸다(출시가 아니다) · **로그라이크** ·
데모 다음이 **펀딩** · **어그로는 조립한 몸이 읽히는 것에 건다.**

⚠ **코드는 아직 안 되살렸다.** 커밋 `62ff57d`에 통째로 있고, 아이디어를 먼저 정하기로 했다.
**무엇을 정해야 하는지는 [.scratch/cell-hook/](.scratch/cell-hook/)에 티켓 다섯으로 있다.**

⚠⚠ **같은 날 아침에 마법진 게임으로 갔다가 저녁에 돌아왔다.** 되돌린 것은 **12월 기한**이다 —
기한이 서자 **컨셉이 서 있는 쪽이 이겼다.** 마법진은 정해진 것이 「조립을 만들 수 있다」 하나뿐이었고,
세포는 세션 루프가 통째로 서 있다. **마법진 설계는 안 지웠다**:
[docs/design/circle-rune-glyph.md](docs/design/circle-rune-glyph.md)

## 접은 것 셋

| | 접은 날 | 무엇이었나 |
|---|---|---|
| 1차 | 2026-08-12 | 횡스크롤 마법 액션 + 픽셀 물·불 시뮬레이션. **재미있는 순간이 한 번도 없었다** |
| 2차 | 2026-08-16 | 오픈 필드 세포 게임. 나흘에 계획 다섯, **그물 25장에 검사 3541개가 초록**이었고, 만든 사람이 해보고 *"그냥 재미가 없다"* 고 했다 |
| 3차 | 2026-08-22 | 세포 군대 오토배틀러. 지어졌고 그물 스무 장이 초록이었는데, **사람이 화면으로 끝까지 가본 적이 한 번도 없다.** ⚠⚠ **같은 날 저녁에 되살리기로 했다** — 접은 근거가 「재미없다」였는데 **재미 판정을 받아본 적이 없다는 것이 확인됐다** |

**세 번의 공통점은 장르가 아니라 순서다** — **재미를 매번 맨 마지막에 확인했다.** 다 짓고 난 뒤 ·
묻기도 전에. 확인할 때쯤엔 되돌리기엔 커져 있어서 지우는 것 말고 방법이 없었다.
⇒ **이번의 목적지는 「12월 데모를 사람 앞에 놓는 것」이다.** ⚠ 세 번 다 시스템을 다 지은 뒤에 물었다.

⚠⚠ **3차 코드는 커밋 `62ff57d`에 통째로 있다.** 로컬 태그 `v3-cellarmy`도 같은 곳을 가리킨다.
**태그는 원격에 못 올린다 — 이 저장소는 태그 푸시가 403이다.** 1·2차가 태그로 남아 있다던 기록이 틀린
이유가 이것이고, **커밋 해시가 실제로 유일하게 작동하는 주소다.**
