# 탁본 (Tockbon)

**다시 짓는 중이다.** 게임을 두 번 지웠고, 지금 세 번째를 설계하고 있다. **`src/`는 비어 있다.**

## 지금 만드는 것 — **세포 군대 오토배틀러**

**한 줄: 먹을 것을 고르러 간다.**

네모난 세포 한 무리로 시작해 **섬을 하나씩 먹는다.** 노드 지도에서 갈 섬을 고르고, **배를 타고
해안선으로 상륙시키고**, 전투는 자동으로 굴러간다. 이긴 섬의 **특산물을 살아남은 병사 몸에 붙여**
자기 군대를 만든다.

- **병사는 섬을 넘어 남는다. HP도 넘어가고, 죽으면 영구 소멸이다**
- 플레이어가 하는 것은 **어디에 · 언제 · 누구를 내리나**와 **무엇을 누구에게 붙이나**
- 보상 축이 셋이고 섬 하나는 하나만 준다 — **수** · **특산물**(한 병사) · **아티팩트**(군대 전체)
- 패배 조건은 **제한 시간**

설계는 [docs/design/cell-army-gdd-ko.md](docs/design/cell-army-gdd-ko.md)에 있다
(영문판 [cell-army-gdd.md](docs/design/cell-army-gdd.md)). **미정은 그 문서의 「미정」 절에 모여 있다.**
**하지 않기로 한 것과 이유**는 [docs/decisions/](docs/decisions/)에 있다.
