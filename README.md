# 탁본 (Tockbon)

**다시 짓는 중이다. 게임을 세 번 접었고 지금 네 번째다. `src/`는 비어 있다.**

## 지금 만드는 것 — **마법진 로그라이크**

**룬을 마법진에 합쳐 커스텀 마법을 만들고, 그 진을 들고 근접으로 던전을 깬다.**
사용자가 댄 레퍼런스는 **스컬 · 데드셀**.

**설계의 뿌리는 셋을 시간으로 자른 것**이다 — **진**은 쏘는 순간, **룬**은 떠난 뒤, **문양**은 떨어진 뒤.
셋이 시간에서 안 겹치고, 겹치면 서로를 잡아먹는다.
[docs/design/circle-rune-glyph.md](docs/design/circle-rune-glyph.md)

⚠ **아직 안 정한 것이 대부분이다** — 근접이 무엇인지, 진이 어디에 박히는지, 진을 손으로 그리는지 칸에
놓는지, 진이 언제 터지는지, 첫 한 판이 무엇인지. **전부 [.scratch/spell-circle/](.scratch/spell-circle/)에
티켓으로 있다.**

| 2차 | 2026-08-16 | 오픈 필드 세포 게임. 나흘에 계획 다섯, **그물 25장에 검사 3541개가 초록**이었고, 만든 사람이 해보고 *"그냥 재미가 없다"* 고 했다 |
| 3차 | 2026-08-22 | 세포 군대 오토배틀러. 지어졌고 그물 스무 장이 초록이었는데, **사람이 화면으로 끝까지 가본 적이 한 번도 없다** |

**세 번의 공통점은 장르가 아니라 순서다** — **재미를 매번 맨 마지막에 확인했다.** 다 짓고 난 뒤 ·
묻기도 전에. 확인할 때쯤엔 되돌리기엔 커져 있어서 지우는 것 말고 방법이 없었다.
⇒ **네 번째의 목적지는 「첫 한 판을 빨리 사람 앞에 놓는 것」이다.**

⚠⚠ **3차 코드는 커밋 `62ff57d`에 통째로 있다.** 로컬 태그 `v3-cellarmy`도 같은 곳을 가리킨다.
**태그는 원격에 못 올린다 — 이 저장소는 태그 푸시가 403이다.** 1·2차가 태그로 남아 있다던 기록이 틀린
이유가 이것이고, **커밋 해시가 실제로 유일하게 작동하는 주소다.**
