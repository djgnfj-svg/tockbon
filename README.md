# 탁본 (Tockbon)

**다시 짓는 중이다. 게임을 세 번 접었고, 2026-08-22 저녁에 세 번째로 돌아가 코드를 되살렸다.**
⚠⚠ **2026-08-26 에 그 게임의 공수가 통째로 뒤집혔다.**

## 지금 만드는 것 — **섬 하나를 지킨다**

**사람 회사가 섬 하나를 들고 그 위를 지어 올린다. 짐승은 배를 타고 온다 — 짐승이 적이다.**
**플레이어는 검사 하나**이고, 적은 **늑대 · 곰 · 까마귀 · 사자** 넷이다. **배는 내가 놓는 것이 아니라
적의 것이다.**

**부대는 판 위에서 언제든 명령한다.** ⚠⚠ **「전투 중에는 손이 안 움직인다」는 죽었다** — 2026-08-25 에
사용자가 Bad North 를 해보고 뒤집었고, 스왑에서 한 번 더 죽었다. **이 게임의 결정은 어디에 내리느냐가
아니라 어디에 세우느냐다.**

**제한 시간이 지나면 보스가 온다.** 섬을 비우고 **다른 섬을 약탈하러 나갈 수 있고, 나간 사이에도
시계는 돈다.**

⚠⚠ **판의 원천은 블렌더다.** 스크립트를 한 번 돌리면 **그리는 것**(`island.glb`)과 **걷는 것**
(`island.json`)이 같이 나오고, **게임은 읽기만 한다.** 지형을 코드로 만들지 않는다.

**틀 넷이 2026-08-26 에 정해졌다**: ⚠⚠ **12 월은 데모다** · **로그라이크** ·
데모 다음이 **펀딩** · **다른 섬 약탈이 들어간다.** ⚠⚠ **이 줄은 같은 날 두 번 뒤집혔다** — 아침에 「출시다」로 갔다가 저녁에 되돌아왔다. **양쪽 다 기록으로 남긴다.** 데모는 저장·옵션·소리·스토어 페이지·언어를 안 진다 —
저장과 이어하기 · 옵션 화면 · 소리 · 스토어 페이지와 빌드 · 언어. **멀티는 꼭 한다** ⇒ **계산은
결정론으로 유지한다.**

**첫 목표는 셋뿐이다 — 섬 · 캐릭터 · 움직임.** ⚠ **집도 건설도 웨이브도 첫 목표에서 빠졌다.**
무엇을 정해야 하고 무엇을 짓는 중인지는 **[docs/plan/](docs/plan/)** 에 있다 — **로드맵 한 장**(무엇을
할 것인가) · **결정 로그 한 장**(왜 그렇게 됐나) · **티켓 마흔여덟 장**(일 하나씩).
**이 저장소가 무엇을 만드는지는 거기서 읽는다.**

⚠ **코드는 돈다.** **저장소 루트의 `Godot_v4.7.1-stable_win64.exe`** 가 게임과 그물을 둘 다 돌린다.
사용자 `~/bin` 에 있는 다른 고도가 아니라 **여기 있는 하나로만** 돈다.
⚠⚠ **게임은 그 엔진을 `--path` 로 직접 불러서 켠다** — `play.bat` 은 2026-08-29 에 창을 못 띄웠다.

**세 번의 공통점은 장르가 아니라 순서다** — **재미를 매번 맨 마지막에 확인했다.** 다 짓고 난 뒤 ·
묻기도 전에. 확인할 때쯤엔 되돌리기엔 커져 있어서 지우는 것 말고 방법이 없었다.
⇒ **이번의 목적지는 「12 월 데모를 사람 앞에 놓는 것」이다.** ⚠ 세 번 다 시스템을 다 지은 뒤에 물었다.

⚠ **2026-08-22 아침에 마법진 게임으로 한 번 갔다가 저녁에 되돌아왔다.** 그 설계(`circle-rune-glyph.md`)는
한동안 남겨 뒀다가 **2026-08-29 에 지웠다** — 돌아갈 게임이 없으니 돌아올 논쟁도 없다. `git log` 에 있다.

⚠⚠ **3차 코드는 커밋 `62ff57d`에 통째로 있고, 그 해시가 유일한 주소다.**
⚠ **`v3-cellarmy` 태그는 없다.** 있다고 적혀 있었으나 실제 태그는 `v1-sim` 과 `v2-openfield` 둘뿐이다
