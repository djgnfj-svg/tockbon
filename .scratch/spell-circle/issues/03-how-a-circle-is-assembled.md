# 진을 어떻게 짜나 — 그리나, 놓나

## Question

**플레이어가 진을 만들 때 손으로 그리나, 칸에 룬을 놓나?**

## 왜 프로토타입인가

사용자, 2026-08-22: ***"직접 그리는 게 옛날에 있었는데 지금 지웠거든. 직접 그리게 했지. 그것도 좀
고민이네."***

⚠ **말로는 안 갈린다.** 앞 게임에서 정비 화면이 **글로만 두 번 설계되고 아무도 본 적이 없었고**,
사용자 본인이 그때 ***"UI 목업까지 하고 진행하자"***고 했다. **이건 보고 정한다.**

## 두 갈래가 서로 다른 게임을 만든다

| | **직접 그린다** | **칸에 놓는다** |
|---|---|---|
| 플레이어가 하는 것 | 획을 긋는다 | 룬을 집어 칸에 넣는다 |
| 실력이 붙는 곳 | **손** — 잘 그리는 사람이 유리 | **머리** — 조합을 아는 사람이 유리 |
| 순서 | 그린 순서가 곧 순서 | 칸 순서가 곧 순서 |
| 전투 중에 | **가능하다** — 그리는 게 행동이 된다 | 어렵다. 멈춰야 한다 |
| 로그라이크 빌드 | 약하다 — 아무거나 그릴 수 있으면 모을 게 없다 | **강하다** — 룬이 전리품이 된다 |
| 숏이 나오나 | **그리는 손이 찍힌다** | 결과만 찍힌다 |

⚠⚠ **「쇼트 올리기가 좋다」는 사용자가 이 게임을 고른 이유 중 하나다.** 그리는 쪽이 거기서 유리한데,
**로그라이크 빌드에서는 불리하다** — 아무거나 그릴 수 있으면 룬을 모을 이유가 없다.
⇒ **섞는 갈래가 따로 있다**: 그리되 **가진 룬만** 그릴 수 있다.

## 만들 것

**셋 다 만들어서 나란히 본다.** 진짜 게임에 안 넣고 따로 만든다 — 버릴 것이므로.

1. **그린다** — 마우스로 획, 획이 룬이 된다
2. **놓는다** — 칸에 룬을 끌어다 놓는다
3. **섞는다** — 가진 룬 목록에서 골라 그린다

**세 화면과, 각각에서 같은 마법 하나(예: 불+가속+퍼짐)를 만드는 데 걸리는 조작 수를 같이 적는다.**

⚠ **화면은 찍어서 본다. 상수를 계산하지 않는다** — 이 저장소가 그걸 한 게임에서 네 번 틀렸다.
⚠ **만든 것은 이 티켓에 링크한다. 붙여넣지 않는다.**
