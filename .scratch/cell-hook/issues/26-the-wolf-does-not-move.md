# 붙어서 벌렁거리는 것밖에 없다 — 늑대에게 동작을 준다

## Question

**무는 순간에 화면에서 무슨 일이 일어나야 하나, 그리고 그중 몇 개가 그림 없이 되나?**

## 어디서 왔나

**2026-08-25, 사용자가 게임을 직접 돌리다가** (`idea-inbox` 321):

> ***"명령 반응도 있고, 타격감 그리고 공격할 때 이렇게 쓱쓱하고 뭔가 애니메이션이 있어요.
> 일단은 늑대 쪽으로 해서 한번 애니메이션도 만들어. 지금 너무 재미없어 그냥 붙어서 그냥
> 벌렁벌렁하는 거밖에 없어가지고 좀 애니메이션을 만들어줘야 될 듯."***

⚠⚠ **이것이 「쫄깃하게 움직인다」의 답이기도 하다** — 사용자가 셋을 다 짚었다: **명령 반응 · 타격감 ·
공격 동작.**

## ⚠⚠ 이미 알고 있던 자리다

**[붙어서 가만히 있으면 재미가 죽는다]** — 사용자가 ***"존나 중요해"*** 라고 한 규칙이고,
**쿨타임을 빈 시간으로 두지 않는다**가 그 내용이다. **오늘 그 규칙이 화면에서 깨져 있는 것을
사용자가 직접 봤다.**

## ⚠ 지금 무엇이 있고 무엇이 없나

- **늑대 그림은 좌·우 두 장이 전부다.** 걷기도 무는 것도 죽는 것도 없다
- ⚠⚠ **프레임을 넘기는 장치가 코드에 아예 없다.** 그림이 아홉 장이어도 안 움직인다
- ⚠ **지도가 「늑대 걷기 아홉 장을 유료 도구로 뽑아 봤다」고 적었는데 그 아홉 장이 리포에 없다.**
  `assets/` 에도 생성 폴더에도 없다 — **유료 도구 쪽에만 있고 안 가져온 것으로 보인다**
- **그림 뽑는 길이 둘이다**: **로컬 ComfyUI**(무료, 이 PC, 원래 파이프라인이 **캐릭터 4방향 걷기
  시트 전용**이라고 적혀 있다) · **유료 도구**(283 장 남음, 8월 30일 충전. **걷기 아홉 장으로
  그림체가 유지되는 것을 이미 확인했다**)

## ⚠⚠ 타격감의 절반은 그림이 0 장이다

**붙었을 때 밋밋한 이유가 전부 그림 부족은 아니다.** 그림 없이 되는 것:

- **무는 순간 앞으로 튀어나갔다 돌아온다**(lunge) — 위치만 움직인다
- **맞은 쪽이 밀린다 · 깜빡인다 · 색이 튄다**
- **화면이 짧게 흔들린다**
- **명령에 대한 반응** — 누르면 즉시 돌아서는 것

⇒ **이것들이 없으면 늑대 그림을 아홉 장 넣어도 여전히 밋밋하다.**

## ⚠ 정해야 하는 것

1. **그림 없는 타격감을 먼저 넣나**
2. **그림은 어느 도구로 뽑나** — 로컬(무료)이냐 유료(283 장)냐
3. **몇 동작을 만드나** — 무는 것 · 걷는 것 · 죽는 것
4. **다섯 종 전부인가 늑대만인가** — 사용자는 ***"일단은 늑대 쪽으로"*** 라고 했다
5. **프레임을 넘기는 장치를 어떻게 만드나** — 지금 몸은 카메라를 보는 판때기다

## 무엇에 맞물리나

- ⚠ **몸이 방금 84px 에서 49px 로 줄었다.** **작아진 몸에서 동작이 읽히는지는 아무도 안 쟀다**
- ⚠ **티켓 25(손이 움직인다)의 「명령 반응」이 여기 절반 들어 있다**

## ✅ 2026-08-25 에 지어진 것 — **절반이 들어갔다**

### 1. 그림 없는 타격감 — **없던 게 아니라 안 보이고 있었다**

⚠⚠ **런지 · 넉백 · 플래시 · 맞은 고리 넷 다 이미 구현돼 있고 실제로 발화하고 있었다.**
**전부 심(sim) 반지름에 매달려 있는데 그림은 49px** 이라 안 보였을 뿐이다.

| | 전 | 후 |
|---|---|---|
| 늑대 런지 | 7.70px | **13.48px** |
| 움찔 | 3.00px | **5.39px** |
| 맞은 고리 | 18.9px | **33.1px** |

⚠⚠ **방패병의 맞은 표시는 지름 43.2px 로 56px 짜리 몸 안쪽에 그려지고 있었다** — **몸 밑에 깔려
있었다는 뜻이다.** ⚠ **죽음 폭발이 「그려졌는데 안 보였던」 것과 같은 결함이고, 그때 그것 하나만
고쳤다.**

**화면 흔들림은 사용자가 거절해서 지웠다** (***"이게 화면이 흔들릴 필요는 없을듯?"***).

### 2. 「붙어서 벌렁벌렁」의 원인

**걸음 동작이 이동 거리로 위상을 잡아서 「안 움직이는 몸은 애니메이션하지 않는다」**로 되어 있었다.
⇒ **붙어 있는 두 몸 — 제일 집중해서 보는 자리 — 이 화면에서 유일하게 완전히 정지한 물체였다.**
**못 움직이는 몸에 흔들림을 붙였다**(0.5초 뒤 시작 · 제 그림 반폭의 25% · 몸 키로 위상 흩기).

### 3. 늑대 그림 열여섯 장 — **로컬 GPU, 유료 안 씀**

⚠⚠ **문서의 「애니메이션은 로컬로 못 한다」가 틀렸다** — 근거가 걷기 도구가 사람 전용이라는 것인데
**이 게임 짐승은 저폴리 렌더지 픽셀아트가 아니다.** **한 이미지에 네 프레임 줄**을 그리게 하면
한 스타일이 한 번 적용되어 프레임 간 몸·조명·폴리곤 크기가 같다.

⚠ **한계**: **「턱을 벌린 늑대」는 되고 「땅을 박차고 덮치는」은 안 된다**(22 개 중 하나, 재현 불가).
**덮치는 동작을 원하면 거기가 유료를 쓸 자리다.**

⚠⚠ **채도를 맞추는 것은 색을 맞추는 것이 아니다** — 채도를 목표에 맞췄는데 **파랑이 16·13 더
무거웠다.** 채널별 이득으로 다시 맞춰 **모든 채널 ±3.7** 안에 넣었다.

⚠⚠ **캔버스 규칙이 하중을 받는다**: 몸을 그릴 때 **가로는 몸 반지름이, 세로는 그림의 가로세로 비율이**
정한다 ⇒ **프레임마다 캔버스가 다르면 늑대가 뛰고 떠오른다.** **열여덟 장 전부 74×40 한 캔버스.**
**나중에 「프레임을 딱 맞게 잘라 용량 줄이기」를 하면 그날 깨진다.**
**서 있는 늑대도 원본 512px 에서 다시 잘라 같은 캔버스로 넣었다** — 이어지는 자리의 튐이 **40% → 8%**.

### 4. 프레임 넘기는 장치

**몸마다 시계 둘.** 걷기는 **거리가 아니라 시간**으로 돌고 시작 위상을 몸 키로 흩는다.
**무는 것은 런지를 켜는 그 사건에서 같이 켜진다.** **한 장 0.12 초, 넉 장 0.48 초.**
**종 이름 분기가 한 줄도 없다** — 그림표 줄마다 「몇 장짜리인가」 칸이 붙어서 **열 번째 종은 제 줄만
고치면 움직인다.**
