# output-styles — 답장을 어떻게 말하나

**`fluent-korean` 을 2026-08-22 밤에 넣었다.** 사용자가 그날 하루에 세 번 *"말을 이상하게 한다"* 고
했고, 만들지 말고 찾으라고 해서 찾아온 것이다.

| | |
|---|---|
| 어디서 | https://github.com/snflkd/fluent-korean |
| 무엇 | Claude Code 출력 스타일. 조사와 어미가 빠지고 명사만 늘어놓는 기계 한국어를 막는다 |
| 라이선스 | MIT (`LICENSE-fluent-korean` 에 원문 그대로 있다) |
| 넣은 방법 | `/plugin` 이 아니라 **파일을 직접 복사했다** — 그래야 저장소를 받는 모든 세션이 같이 갖는다 |

**둘 중 하나를 고른다.** `settings.json` 의 `outputStyle` 이 지금 `fluent-korean` 을 가리킨다.

- **`fluent-korean`** — 코딩 지침을 유지한다. **이 저장소는 이걸 쓴다**
- **`fluent-korean-not-coding`** — 코딩 지침을 뺀 것. 코드를 안 건드리는 대화용

## ⚠ `CLAUDE.md` 의 답장 규칙과 부딪히는 곳이 둘 있다

**둘 다 사용자가 정할 일이라 여기 적어만 둔다. `CLAUDE.md` 는 사용자만 고친다.**

1. **엠대시.** 이 스타일은 엠대시를 자제하고 콜론이나 접속사로 바꾸라고 한다.
   지금 답장과 문서가 엠대시를 아주 많이 쓴다.
2. **생략.** 이 스타일은 **문장 성분을 생략하지 말라**고 하고,
   `CLAUDE.md` 는 **모든 줄이 짐을 져야 한다**고 한다. 짧게 쓰다 보면 성분을 생략하게 된다.

⇒ **부딪히면 무엇을 말하나는 `CLAUDE.md`, 어떻게 말하나는 이 스타일이 정한다.**
