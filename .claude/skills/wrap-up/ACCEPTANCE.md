# Acceptance — **the user's own words, and where they go**

**Ask once whether they looked. They always answer one way or the other, so never infer it.**

⚠⚠ **There is no acceptance-debt file any more.** It held these rows until the user deleted it on
 **The rule that replaced it: the user's own words go verbatim into the ticket they belong to.**
Do not recreate the deleted file.

| What happened | What you write |
|---|---|
| **They looked** | **Their words, verbatim, into that ticket, that turn**, and whatever it was open on is struck |
| **They looked and it was wrong** | **Same thing** — closes a row exactly as a pass does, and **the wrong words are the valuable ones** |
| **They did not look, or said nothing** | **A row in the ticket**: what shipped · **how to see it** · when it landed. ⚠ **Silence is a row, not a pass** |

⚠⚠ **Verbatim, not a paraphrase.** The sentences that lived only inside design docs died with them on
, and **they were the only measurement this repo ever had of whether a game of its own was any
good.**

⚠ **The "how to see it" column is the whole point.** The user works this list off **in one sitting**,
weeks later, and will not re-derive how to reach each thing. **Name the screen, the key, and what should
look different.**
