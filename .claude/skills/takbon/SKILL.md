**2D 사이드뷰 마법 로그라이크.** 마법진을 조립해 쏜다 · 타일 파괴 · 멀티.
🔴 **2026-08-02에 v2로 갈아엎었다 — `src/`가 비어 있다.** v1(탑다운)은 `main` 브랜치에 있다.
「게임이 무엇인가」 = `docs/GDD.md`(§6이 **미정 목록** — 짐작으로 채우지 마라) · 「왜」 = `docs/DECISIONS.md`.

## 0. 파이프라인 — 이게 본체다

**설계 → 구현 → 리뷰 → 리드 검증 → 커밋.** 코드부터 얹지 마라.
실행 모드 = **서브에이전트**(`Agent` 도구, `subagent_type: general-purpose`). 리드가 매 단계를 읽고 다음을 배차한다.

🔴 **기획(무엇을·왜·재밌나)은 위임하지 마라.** 서브에이전트는 사용자와 대화를 못 해 혼자 정한다.
하드 게이트 셋: ① 착지 전 **최소 3라운드 왕복** ② **확정 결정마다 사용자 발언 근거** ③ 승인 전 구현 금지.

🔴🔴 **모든 단계에 "보고서를 `docs/_reports/<이름>.md`에 써라"를 넣어라.** 채팅 최종 보고는 리드에게 **안 온다**(idle 알림만 온다). 설계·리뷰는 산출물이 보고서뿐이라 파일로 안 시키면 작업 전체가 증발한다.

각 프롬프트 첫 줄에 **`.claude/skills/takbon/SKILL.md`를 먼저 Read해라**를 넣어야 아래 계약이 전달된다.

| 단계 | 무엇 | 산출 |
|---|---|---|
| **설계** | 씬 트리·노드 책임·시그널 맵·데이터 흐름·「이미 있는 것 vs 새로 만들 것」·회귀 위험·검증 포인트. **코드는 안 쓴다.** 확정된 방향을 뒤집지 마라 — 구멍이 보이면 "리드가 사용자와 재확인 권함"으로 표시 | `_reports/<주제>_design.md` |
| **구현** | 최소 변경으로 기존 패턴을 **확장**한다(복사 아님). typed GDScript | 코드 + `_reports/dev_<주제>.md` |
| **리뷰** | §1 계약·§2 함정을 조준. Critical/Important/Minor로 나누고 **고칠 법까지** 준다. 고치진 마라 | `_reports/<주제>_review.md` |
| **검증·커밋** | **리드만.** §3·§4 | — |

⚠ 병렬로 여럿 띄울 땐 **읽기 전용 작업만** 준다. 에디터는 하나뿐이라 게임을 띄워 조작하는 에이전트는 **한 번에 하나**이고, 부를 때 그렇다고 명시해라.

🔴 **리드가 안 놓는 것 = 기획 · 검증 · `--import` · 커밋.**
**에이전트의 "그린 나왔습니다"를 근거로 쓰지 마라** — 리드가 직접 돌리고 뮤테이션으로 검출력을 확인한다(§3).

### 아트가 필요하면

🔴 **생명체·프롭을 도형(`Polygon2D`·`ColorRect`)으로 때우지 마라**(사용자 확정). 그림이 없으면 구현을 멈추고 리드에게 보고한다.
🔴 **아트는 레퍼런스부터다** — 리드가 예시를 뽑아 사용자에게 고르게 하고 **파일 경로를 프롬프트에 넣어** 그리게 한다. 경로 없이 시키지 마라.
⚠ 예외 = **절차적 VFX**(파티클·Line2D 궤적·가이드선)는 애초에 그림이라 도형이 맞다.

## 1. 계약

- **typed GDScript.** 모든 변수·인자·반환에 타입.
- **서브에이전트는 `class_name` 금지** → `const X := preload(...)`. 전역 클래스 캐시는 리드의 `--import` 때만 갱신된다.
- **모듈 간 통신은 EventBus 시그널 + `src/core` 스키마만.** 타 모듈 직접 preload/get_node 금지. 예외를 만들려면 리드에게 물어라.
- **밸런스 수치를 코드에 박지 마라** — 스키마의 `@export`가 진다. ⚠ **예외 = 손맛 연출값**(넉백·히트스톱·팝)은 스크립트 `const`가 맞다. 사용자가 직접 때려 조이는 값이라 밸런스가 아니다.
- **단일 소스를 늘리지 마라.** 같은 수치·문구·좌표를 두 곳에서 계산하면 반드시 갈라진다.
- **데이터 주도** — 가능하면 "새 X = `.tres` 한 장".
- **커밋·`--import`·`src/core` 수정은 리드만.** 에이전트는 자기 모듈 폴더 + `tests/` 자기 파일만. 스키마·시그널 신설이 필요하면 **만들지 말고 보고해라.**

### 🔴🔴 멀티 — v2에서 새로 생긴 축

**멀티는 기능이 아니라 아키텍처다.** 모든 게임플레이 코드가 **「누가 권위를 갖나」**를 알고 있어야 하고, 나중에 붙이는 건 거의 재작성이다.

- 🔴 **상태를 바꾸는 코드를 쓸 때마다 물어라 — 이건 서버가 정하나, 클라가 예측하나.** 답을 안 정하고 짜면 그 자리가 나중에 통째로 뒤집힌다.
- 🔴 **물리 시뮬레이션은 결정론적이지 않다**(부동소수점·실행 순서). 클라마다 다른 결과가 나오므로 **물리 결과를 동기화 근거로 쓰지 마라.**
- ✅ **타일 파괴는 "이 좌표 지워라" 이벤트 하나로 동기화된다** — 이게 셀 오토마타 대신 타일을 고른 이유다(`DECISIONS.md`).
- ⚠ **마법 투사체는 물리 강체로 만들지 않는다** — 직접 이동 + `Area2D` 감지. 성능·제어력·동기화 전부 그쪽이 낫다.

## 2. 조용히 깨지는 함정 (에러가 안 난다)

**먼저 갈래를 물어라 — 답이 나오면 같은 갈래의 다른 자리도 이미 깨져 있다.**
⚠ 아래 여덟은 v1에서 전면 감사로 뽑은 것이고 **코드가 아니라 실패 양식**이라 v2에도 그대로 적용된다.

| | 테마 |
|---|---|
| **T1** | 모드 분기를 일부 자리에만 넣고 **소비 지점 목록을 안 만든다** |
| **T2** | 은퇴를 선언 없이 둬서 **죽은 몸이 살아있는 그물을 갖는다** → 「전 스위트 그린」이 과대평가된다 |
| **T3** | 소비자가 사라진 데이터 필드가 **거짓 손잡이**로 남는다 |
| **T4** | **주석이 계약인데 코드와 함께 안 늙는다** |
| **T5** | 파생 대신 복제 — **문구·좌표는 사본이 아니라는 무의식 예외** |
| **T6** | 실패를 로그 없이 삼킨다 |
| **T7** | 「임시 시드」 딱지가 그물을 안 세우는 면허로 쓰인다 |
| **T8** | 축이 1→N으로 늘 때 **표시부가 뒤처져 「쏘는 것 ≠ 보이는 것」**이 된다 |

개별 함정 — **v1에서 실제로 밟은 것들이고 엔진 층 문제라 v2에도 그대로 있다**:

- 🔴🔴 **화면 덮는 Control의 `mouse_filter`**: 기본값 STOP이 좌클릭을 다 먹어 **발사가 에러 없이 죽는데 전 스위트가 그린이다.** 통과시킬 배경·장식 = `mouse_filter = 2`(IGNORE) · 뒤를 막아야 하는 모달 뒷판 = STOP이 맞다. **헤드리스가 절대 못 잡는다** — 실게임 클릭 주입으로만 확정된다.
- 🔴🔴 **`.tres`는 두 가지로 다르게 죽는다**: ⓐ 스키마에 **없는 이름**은 조용히 무시되고 리소스는 산다 ⓑ 🔴 ***값* 파싱이 실패하면 리소스가 통째로 죽고 레지스트리가 말없이 건너뛴다**(v1에서 3인자 `Color` 하나가 룬을 두 세션 죽여 놨는데 전 스위트 그린이었다). ⇒ **"파일을 만들었다"를 완료로 치지 마라 — 실제로 로드되는지 개별 확인해라**(개수 합계만 재면 하나 죽고 하나 살아도 같은 수다).
- 🔴🔴 **「기능이 돈다」 ≠ 「플레이어가 거기 갈 수 있다」**: 패널을 직접 열어 재는 그물은 진입점을 안 지나서, 문이 닫혀 도달 불가가 된 내내 그린이었다. **새 UI를 붙이면 진입점에서 출발하는 도달 경로 그물을 따로 세워라.**
- 🔴 **enum 값이 연속이라고 가정하지 마라** — 은퇴 자리가 비어 있을 수 있다. **인덱스로 순회하지 말고 명시 리스트**를 써라.
- 🔴 **씬끼리 `PackedScene`으로 물지 마라** — 순환이면 **에디터가 조용히 빈 노드를 만든다.** 경로 상수 + 런타임 `load()`/`change_scene_to_file`을 써라. 헤드리스는 못 잡고 실게임 부팅에서만 드러난다.
- 🔴 **엔진 `ERROR:`·`push_warning`은 `SCRIPT ERROR` grep에 안 걸린다** — 이 리포 단골 침묵사다(T6).
- 🔴 **`StringName` 배열의 `sort()`는 사전순이 아니다** — 인터닝 순이라 실행마다 바뀐다. id 정렬은 `sort_custom`으로 `String()`을 감싸라. 항목이 적을 땐 안 드러나다가 목록이 길어지면 튄다.
- 🔴 **물리 콜백 한복판의 `add_child`** — 노드는 정상으로 붙지만 `Can't change this state while flushing queries.` 엔진 에러가 뜬다. `call_deferred`로 붙여라. ⚠ **스크립트 그물로는 못 가른다**(관측 가능한 차이가 로그 한 줄뿐) — 러너의 엔진 ERROR 집계가 유일한 감지기다.
- 🔴 **`queue_free`만으론 그룹에서 안 빠진다** — 같은 프레임에 그룹을 세면 죽은 노드가 잡힌다. `remove_child` 먼저 또는 `is_queued_for_deletion` 필터.
- 🔴 **`add_child`는 이름 충돌 시 요청 이름을 버린다**(`@Node2D@94`) — **노드 존재를 이름으로 재지 마라.** v1에서 그물이 두 번 거짓 그린을 냈다.
- 🔴 **배선이 맞아도 「반경 밖」이면 아무 일도 안 난다** — 반경을 쓰는 기능을 붙였으면 **좌표를 실측해라**(v1에서 간격 102px vs 연쇄 반경 90px라 한 번도 안 터졌다).
- ⚠ **`.tscn`의 `;` 주석은 에디터가 저장하면 날아간다** — load-bearing한 설명은 코드에 둬라.
- ⚠ **닫힌 invisible Control도 `_unhandled_input`을 받는다**(자기토글 숨은 패널이 이걸로 산다).
- ⚠ **테마에 PNG를 물면 침묵사한다** — StyleBox는 코드로 주입.

## 3. 검증 — 초록불을 근거로 쓰지 마라

**전체 스위트**(Bash에서):
```bash
./Godot_v4.7.1-stable_win64.exe --headless --path . -s res://tools/run_tests.gd
./Godot_v4.7.1-stable_win64.exe --headless --path . -s res://tools/run_tests.gd -- <이름필터>
```
러너가 `tests/`를 직접 훑어 목록을 만든다(손 목록이 아니라 안 낡는다).
🔴 **`_OK`와 `SCRIPT ERROR`를 둘 다 grep해라.** 실패 집계 형식은 **`TEST_*_FAIL`**이지 `fail=N`이 아니다.
🔴 **엔진 `ERROR:`는 따로 본다** — 러너가 세어서 요약에 얹는다(판정엔 안 넣는다). **기준선을 넘으면 새로 생긴 것이다.**

**헤드리스가 못 잡는 넷 — 실게임으로만 확정된다:**
① 클릭이 닿나(입력 주입) ② 보인다(스샷) ③ 소리가 난다 ④ 시간이 흐른다
⚠ **손맛 수치는 사용자에게 직접 해 보라고 넘겨라** — 헤드리스로 결론 내지 마라.

**뮤테이션으로 검출력 증명**(규칙·버그 수정이면 필수):
- 🔴 **되돌리기에 `git checkout`/`restore`/`reset`을 쓰지 마라** — 남의 미커밋 작업을 지운다. **`cp f f.bak` 백업 → 되돌린 뒤 md5 대조.**
- 🔴 **뮤테이션이 실제로 적용됐는지 `grep -c`로 확인하고 나서** "검출 0"이라고 말해라.
- 🔴 **「결과 값이 같다」는 「같은 길로 왔다」가 아니다.**
- 🔴 **그물은 「구현이 맞다」가 아니라 「구현이 일관되다」까지만 잰다** — 전제가 틀리면 그물이 그 틀린 것을 굳힌다. v1에서 적이 늘 뒷걸음질로 달리는데 전 스위트 그린이었고 뮤테이션 17건도 근거가 안 됐다(뒤집힌 기대치에 대한 검출력이라 부호가 반대여도 같은 숫자가 나온다).
- ⚠ **원상복구까지가 지시다.** 되돌린 채 두면 기능이 조용히 죽은 채 커밋된다.

## 4. 커밋 범위 — 이 리포는 세션이 여럿 돈다

🔴🔴 **기획 세션과 구현 세션이 같은 워킹트리를 동시에 만진다.** `git status`엔 늘 **남의 미완성**이 섞여 있다. 사용자 확정: *"자기가 작업한 것과 관련 없으면 커밋 안 하도록."*

- 🔴 **`git add -A`·`git add .`·`git commit -a[m]` 금지.** 경로를 하나씩 명시해라.
- **절차**: ① `git status --porcelain`으로 **워킹트리 전체**부터 본다 ② 이번 세션이 만진 것만 add — **기억나지 않으면 내 것이 아니다** ③ `git diff --cached --stat`을 **눈으로** 확인 ④ 남은 변경은 **그대로 둔다**.
- 🔴🔴 **같이 쓰는 문서**(`CLAUDE.md`·`DECISIONS.md`·`TODO.md`·`.gitignore`)는 두 세션이 같은 파일의 다른 줄을 쓴다. **add 전에 `git diff <파일>`로 내 줄만인지 봐라.**
- 🔴 **편집 위치도 골라라.** 남이 만진 줄 바로 옆에 쓰면 diff가 한 hunk로 묶여 갈라낼 수 없다(`-U0`도 인접 변경을 묶는다). 위치를 못 고르면 **남의 줄만 임시로 떼어 보관 → 내 줄만 커밋 → 원래 자리에 되삽입 → `git diff`로 복원 확인**.
- 🔴 **`git stash` 금지** — 남의 미커밋 작업을 통째로 들어올린다.
- ⚠ **diff가 0인데 `M`으로 뜨는 파일을 add하지 마라** — 개행(CRLF)만 바뀐 것이다.
- ⚠ **커밋 메시지도 내 작업만 말해라.**

## 5. 말하는 법

**결론부터 · 핵심만**(사용자가 세 번 확정했다). 안 물은 배경·경위·선택지 나열을 빼라.
🔴 **표·굵은 글씨로 지면을 채우는 것도 길게 말하는 것이다.**
🔴 **문서 규율을 근거로 앞세우지 마라** — 판단을 물으면 **판단으로** 답한다. 근거는 짧게 붙인다.
코드 주석은 **「왜」만** — 「무엇」은 코드가 이미 말한다. ⚠ 예외 = 조용히 깨지는 함정(T4). 그건 길어도 남긴다.
