# twodo — **나중에 할 것**

**저장소 뿌리에 있고, 이 폴더만 한국어로 쓴다.** (2026-08-30, 사용자)
⚠ 나머지 문서는 전부 영어라는 규칙이 `CLAUDE.md` 에 있다. **여기는 사용자가 직접 예외로 지정한 곳이다.**

## 무엇이 여기 사나

**지금 못 하는 것.** 대화에서 정해졌지만 이번에 손대지 않기로 한 일이 한 파일씩 들어온다.
⚠⚠ **여기에 안 적히면 다음 라운드는 이 결정을 모른다.**

## `docs/plan/tickets/` 와 무엇이 다른가

| | 무엇 |
|---|---|
| **티켓** | **이번에 만들 것.** 구현 계획이 안에 들어가고, `build-loop` 이 집어 간다 |
| **twodo** | **아직 티켓이 아닌 것.** 언제 할지 안 정해졌고, 계획도 없다 |

**할 때가 되면 티켓으로 옮기고 여기서는 지운다.**

## 이름 규칙

**`NN-무엇을-할것인가.md`.** 번호는 마지막 것에서 하나 올린다.

## 한 파일에 들어가는 것

- **무엇을 하기로 했나** — 사용자의 말 그대로
- **왜 지금 안 하나** — 미룬 이유
- **먼저 풀려야 하는 것** — 이게 안 풀리면 시작해도 소용없는 조건
- **정한 날짜**
