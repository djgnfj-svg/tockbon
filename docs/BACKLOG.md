## 1. 🔴 **"문양이 너무 빈다"** — 이번 주 목표의 핵심 난제 (사용자, 세션 7)

> **이번 주 목표는 하나다: 마법진을 만들어서 원하는 대로 출력하기.**
> 그 목표 안에서 지금 막힌 곳이 여기다.

### 진단 — 셋 중 문양만 **정체성이 없다**
| 부품 | 플레이어가 정하는 것 | 정체성 |
|---|---|---|
| 진 | 크기(잉크·마나·기점 배치) | 경계·규모 |
| 룬 | **4종 중 하나** (불·충격·물·바람) | **어휘가 있다** |
| **문양** | 방향·크기·개수·곡률 | **없다 — 연속값 파라미터일 뿐** |

문양은 "무엇을 그릴까"가 아니라 "얼마나·어디로 그을까"다. 그래서 **도안 설계의 재미가 룬 고르기에만
걸리고**, 문양은 조준 노동에 가깝다. 사용자 표현 그대로 **"빈다"**.

### 이건 GDD 리스크 2번이 그대로 현실화된 것이다
GDD §11: *"**화살표 시스템 깊이가 실제로 충분한가** — 프로토에서 도안 다양성 관찰"*.
**프로토를 만들어 봤고, 답은 '부족하다'로 나왔다.** 리스크가 관측된 것이므로 이제 대응해야 한다.

### 사용자 구상 — 문양에 **종류**를 둔다
> "문양이 종류가 있을 듯. 방향 문양이나 증폭 문양이나 이런 것들이 있을 듯"

**왜 자연스러운가**: GDD §4.4가 이미 예약해 둔 축이다 — *"EA 확장 예약: 문양(유도·지면설치·곡사·회전 등,
**그 기술을 쓰는 엘리트에게서 획득**)"*. 즉 **문양 = 탁본으로 배우는 두 번째 어휘**가 된다
(첫 어휘는 룬). 지식 습득 루프(GDD §6)가 룬 하나에만 걸려 있던 것도 분산된다 —
**GDD 리스크 4(룬 획득이 보스에 묶임)까지 같이 완화된다.**

### 후보 (미확정 — 이름·효과 전부 프로토에서)
| 문양 | 하는 일 | 비고 |
|---|---|---|
| **방향 문양** | 지금의 화살표 — 탄 1발을 그 방향·크기로 | 기본. 유일하게 구현됨 |
| **증폭 문양** | 다른 문양의 위력·크기를 키움 | **단독으로는 못 쓴다** — 다른 문양에 붙는 수식어. 잉크 예산을 위력에 몰아주는 선택지 |
| (예약) 유도·곡사·설치·분열·회전 | GDD §4.4의 EA 목록 | |

### 풀어야 할 설계 문제 (여기가 진짜 일이다)
1. **인식**: 문양이 여러 종류면 **문양끼리도 구별**해야 한다. 지금 문양 판정은
   "진을 뚫고 나가는가"(TECH_SPEC §6.1) 하나뿐 — 종류가 늘면 이 판정만으론 부족하다.
   룬처럼 $1을 태울지, 기하 피처로 가를지 미정
2. **작성 순서**: 지금은 진 → 룬 → 문양 3단계 강제(§6.2). 문양이 여러 종류면 문양 단계가
   내부적으로 갈리는가? 체크리스트는 어떻게 보이는가?
3. **증폭 문양의 결합 규칙**: 무엇에 붙는가(가장 가까운 문양? 전부?). "붙는다"를 그림으로
   어떻게 표현하는가 — v1.2의 "선=연결"을 여기서 되살릴 여지가 있다 (GDD가 EA로 이관해 둠)
4. **잉크 예산**: 증폭이 잉크를 먹는 만큼 발수를 줄인다 → **배분이 곧 설계**(GDD §4.4)라는
   원칙과 잘 맞는다. 이 축을 살릴 것

### 선행 조건
**곡선 궤적(2단계)이 먼저다.** 지금 문양은 곡률을 그려도 궤적에 반영되지 않는다 —
문양 하나도 아직 다 못 살렸는데 종류를 늘리면 어느 쪽도 안 익는다.

## 2. 보정 — "약간 보정이 필요한 듯" (사용자, 세션 7)

**⚠ 구체 항목 미정.** 사용자가 시험대를 만져 본 뒤 남긴 소감이라 정확한 대상을 확인해야 한다.
다음 세션은 **무엇의 보정인지부터 물을 것.** 후보:

- **인식 보정** — 룬 인식률은 세션 7에 96.7% → **99.5%**로 올렸다(불△ 감김 게이트 재설계 +
  충격> 타이브레이크 수정). 그래도 손맛이 안 맞을 수 있다. 자동보정 버튼의 유도가 약한지도 확인

  머물렀을 때 굵어지는 정도·속도가 손에 맞는지
- **거부 UX** — 순서 위반·인식 실패 시 획이 사라지는 게 답답한지 (잉크는 안 깎이지만)
- **캐스팅 손맛** — 마법진 연출 0.4초, 투사체 속도·크기 배율

## 3. 곡선 궤적 (2단계) — **결정 대기**

## 3.5 제작대(책 펼침) — 남은 조각 (세션 8 신설)

`src/drawing/forge_panel.gd`는 만들었고 시험대(`tests/test_forge.tscn`)에서 돈다. **본편 배선은 아직이다.**

  (옛 `drawing_room`). 이걸 forge 오버레이로 바꾸면 거점에서도 ESC 왕복이 된다.
  ⚠ **선행 조건이었던 무료 수리 버그(BUG-2)는 세션 8에서 고쳤다** — 이제 배선해도 안전하다

  그래서 지금은 마나 감면·내구 보너스가 붙은 상급 종이를 **의도적으로 쓸 방법이 없다**(GDD §5 무력화).
  왼쪽 페이지 상단에 종이 칸을 두는 게 자연스럽다
- 배선이 끝나면 `drawing_room.gd`·`test_drawing_main.gd`(옛 시험대 UI)와 `design_book.gd`(옛 한 줄 책자)를
