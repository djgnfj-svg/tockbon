# docs/design — 지금 만드는 것, 그리고 접은 갈래

**2026-08-22에 두 번 갈렸다.** 아침에 세포 게임의 개념 문서 열 개가 지워지고 접은 갈래 여덟만 남았고,
저녁에 **세포 게임 자체가 접히면서 그 갈래 여덟과 GDD도 같이 나갔다.** 전부 커밋 `62ff57d`에 있다.

**접은 갈래가 개념 문서보다 오래 사는 이유**: 개념 문서는 계속 바뀌는 게임을 서술하므로 삭고 거짓말이
된다. **접은 갈래는 이미 내려진 결정을 서술하므로 안 삭는다 — 뒤집힐 뿐이고, 뒤집힘은 같은 문서 위에
쓴다.** ⚠⚠ **다만 그것은 결정이 아직 이 게임에 닿아 있을 때의 이야기다** — 게임 자체가 없어져서
논증이 돌아올 자리가 없으면 남는 것은 문서가 아니라 짐이고, **2026-08-29 에 그런 다섯이 지워졌다.**

## 지금 만드는 것

**사람 회사가 섬 하나를 지키고 키운다.** 짐승이 배를 타고 쳐들어오는 쪽이고, 플레이어는 검사 부대다.
부대는 **판 위에서 언제든 명령한다.** 시간이 차면 보스가 오고, 다른 섬을 털러 나가는 것으로 섬이 는다.
**12월은 데모다.** ⚠⚠ **이 줄은 2026-08-26 하루에 두 번 뒤집혔다** — 아침에 「출시」가 됐다가 저녁에 사용자가 ***"12월 데모로 변경"*** 이라고 해서 되돌아왔다. **논쟁으로 정해지는 줄이 아니라 마지막에 말한 것이 답인 줄이다.**
⚠⚠ **2026-08-26에 진영이 뒤집혔다.** 그 전까지는 짐승이 되어 섬 여덟을 깨는 게임이었고, 지도 화면 ·
노드 걷기 · 노드 보상 · 섬 여덟 · 종족 카드는 **그날 코드에서 지워졌다.**
⚠⚠ **2026-08-29에 성장 고리가 통째로 지워졌다** — 보상 카드 화면과 정비 화면, 그리고 뽑는 기구가
같이 나갔다. **이긴 뒤에 무엇을 얻느냐가 지금 게임에 하나도 없다.**
⇒ **아래 갈래 문서들은 전부 그 뒤집히기 전 틀 안에서 쓰였다. 틀은 죽었고 논증은 남는다** — 그래서
문서마다 첫 줄의 `Status:` 가 무엇이 죽었는지 먼저 말한다.
⚠ **GDD가 없다.** 세포 GDD는 커밋 `62ff57d`에 있는데 **되살리지 않았다** — 먹기와 부위 조립을
전제로 쓰였고 **그 둘이 2026-08-22 저녁에 빠졌다.** 되살리면 틀린 것을 읽게 된다.
⇒ **무엇을 만드는가는 지금 `docs/plan/`에서 읽는다.**

## ⚠⚠ 2026-08-29 에 지운 다섯 — **그리고 그날 규칙이 뒤집혔다**

**사용자가 「죽은 거 다 삭제」라고 했다.** ⚠⚠ **2026-08-27 에는 같은 요청에 안 지웠고**, 그때 근거는
이 파일에 적혀 있던 **「한 번 지웠다가 되살린 것이라 다시 안 지운다」**였다. **나중에 말한 것이 답이다.**

⚠ **지운 다섯은 전부 `Status:` 줄이 「죽었다」고 말하던 것**이고, **「뒤집혔다」고만 말한 것은 안 지웠다** —
뒤집힘은 죽음이 아니라 같은 논쟁이 돌아올 자리다.

| 지운 것 | 왜 |
|---|---|
| 진 · 룬 · 문양 (199줄) | 마법진 낱말 셋을 시간으로 가른 정의. **마법진도 그 게임도 없다** |
| 진은 탑이 쏘는 걸 바꾼다 | **탑도 포탑도 마법진도 없다.** 남던 것은 논증 「모양」뿐이었다 |
| 몸은 코드가 그리는 선이다 | 세포 게임의 몸 그리는 방식. **2026-08-24 에 전부 뒤집혔고 지금 몸은 그림 파일이다** |
| 층마다 노드 하나, 두 줄이 아니다 | **지도 화면이 없다** — 층마다 노드를 고르는 자리 자체가 사라졌다 |
| 빌드는 물려받는 게 아니라 설계하는 것 | 전제(먹은 것이 빌드가 된다)가 2026-08-22 에 죽었고, **그 자리를 대신 가리키던 장비 카드와 정비 화면도 2026-08-29 에 지워졌다** |

**전부 `git log` 에 있다.** 되살릴 일이 생기면 지워진 커밋에서 꺼낸다.

## 이 폴더의 문서가 생긴 모양

**접은 갈래는 `Status:` 줄로 시작한다** — **살아 있는지 죽었는지를 한국어 한 문장으로 먼저 말하고**,
날짜와 누가 정했는지를 붙인다. ⚠ 영문 낱말 셋(`valid` · `REVERSED` · `partially reversed`)을 쓰라고
적혀 있던 시절이 있었으나 **그 규정을 지킨 문서가 하나도 없었다.** **뒤집힘은 기존 문서 위에 쓴다.
지워서 뒤집지 않는다.**
⚠⚠ **그 줄은 「뒤집힘」에만 걸린다.** **틀이 통째로 없어진 문서는 지운다** — 2026-08-29 에 그렇게 정해졌고,
무엇을 왜 지웠는지는 위의 표가 든다.

⚠ **`Implemented` / `Accepted` 두 축은 없다.** 세포 게임의 개념 문서를 재던 축이고 그 문서들이 없다.
**무엇이 지어졌나는 `src/`와 `tests/nets/`에서 읽는다.**
⚠⚠ **사용자의 판정을 들고 있던 `acceptance-debt`는 2026-08-26에 삭제됐다** — 사용자가 직접 그렇게
정했다. **지금 사용자가 무엇을 봤나를 적어 두는 자리는 없다.** 이 문단은 그 구멍을 가리키는 것이지
대체 경로를 가리키는 것이 아니다.
⇒ **무엇이 이걸 대신하나는 아직 안 정했다** — 지도의 안개에 있다.
