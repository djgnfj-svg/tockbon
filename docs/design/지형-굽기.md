# 지형 굽기 — 그림으로 그리고 텍스트로 굽는다

**한 줄**: 에디터에서 타일을 붓으로 그리고, 그걸 ASCII 텍스트로 구워서 게임이 읽는다.

**구현**: 완료 — 네 단계가 전부 돈다. ⚠ **왕복(내가 찍는 방향)은 아직 잠겨 있다**(아래 「왕복」)
**판정**: 통과 (2026-08-06) — 사용자가 312×126타일을 그렸고 게임에 그대로 떴다

⚠ **개념은 계속 살아 있고 폴더를 안 옮긴다.** 위 두 줄은 「지금 얼마나 도나」일 뿐이다 —
형식은 [README.md](README.md) 를 따른다.

🔴🔴 **맵은 고정이다**(2026-08-07, 사용자가 정했다. GDD 「던전 생성」).
절차 생성을 안 하므로 **이 파이프라인이 곧 레벨 디자인 도구고, 본편에 남는다.**

---

## 왜 이렇게 하나

지형을 **손으로 ASCII를 쓰는 것**과 **에디터에서 그리는 것** 사이의 선택이었다.

- ASCII만 쓰면 **312×126을 사람이 못 그린다.** 눈으로 안 보이니 형태를 잡을 수 없다
- 에디터 씬만 쓰면 **시뮬이 못 읽는다.** `src/sim/` 은 씬 트리를 모르는 게 계약이다

⇒ **그림으로 그리고 텍스트로 굽는다.** 사람은 그림을 보고, 시뮬은 텍스트를 읽는다.

🔴 **구운 결과가 단일 소스다.** `terrain_map_generated.gd` 의 `MAP` 을 게임도 그물도 읽는다.
⚠ 씬의 타일 레이어는 **편집용 원본**이지 게임이 읽는 것이 아니다 — 그리고 **굽지 않으면 게임에 안 나온다.**

---

## 네 단계

```
① 타일 팔레트 만들기      build_terrain_tileset.gd     재료를 늘릴 때만
② 에디터에서 그린다        stage.tscn 의 Terrain 레이어   ← 사람이 하는 일
③ 굽는다                  bake_terrain_editor.gd       Ctrl+Shift+X
④ 게임이 읽는다            terrain_map_generated.gd     자동
```

### ① 타일 팔레트 — `tools/stage/build_terrain_tileset.gd`

`src/stage/terrain_tileset.tres` 를 다시 만든다. **재료가 늘 때만 돌린다.**

```
Godot_v4.7.1-stable_win64.exe --headless --script tools/stage/build_terrain_tileset.gd
```

🔴 **`.tres` 를 손으로 고치지 마라.** 이 스크립트가 유일한 문이다.

**붓 그림은 `assets/stage/terrain_tiles.png`** — 96×32px 안에 32px 칸이 셋(돌·나무·기반암).
⚠ **이건 게임 그래픽이 아니라 에디터에서 보이는 견본이다.** 실제 화면은 셀 격자가 그리고,
색은 `cell_materials.DEFS` 의 `rgb` 에서 나온다.

🔴 **그 png를 만드는 스크립트가 없다**(2026-08-07 확인). 지금 색이 `DEFS` 와 맞는 것은
**손으로 맞춰 둔 것**이라, 재료 색을 바꾸면 **에디터 붓 색만 조용히 낡는다.**
⚠ 게임 화면은 안 틀리므로 **아무도 눈치 못 챈다** — 붓을 집을 때만 헷갈린다.

### ② 그린다 — `stage.tscn` 의 `Terrain`

Godot 에디터에서 `src/stage/stage.tscn` 을 열고 `Terrain`(TileMapLayer)을 고른다.

🔴 **그리고 반드시 씬을 저장한다**(Ctrl+S). ③은 **디스크에서 읽으므로 저장 전 상태를 안 본다.**
⚠ 안 저장하고 구우면 **에러 없이 옛 지형이 다시 구워진다.**

### ③ 굽는다

**에디터 안에서** — `tools/stage/bake_terrain_editor.gd` 를 스크립트 편집기에서 열고
우측 상단 실행(Ctrl+Shift+X).

**헤드리스로** — `Godot_v4.7.1-stable_win64.exe --headless --script tools/stage/bake_terrain.gd`

🔴 **둘은 같은 로직을 부른다**(`terrain_baker.gd`). 베낀 게 아니다.

### ④ 게임이 읽는다

`src/stage/terrain_map_generated.gd` 가 나온다 — `MAP`(ASCII 배열) · `MAP_W` · `MAP_H` · `MAP_CHARS`.
🔴 **자동 생성이다. 손으로 고치지 마라** — 다음 굽기가 통째로 덮는다.

## 🔴 재료를 하나 늘리면 고칠 곳이 넷이다

**물이 들어오는 날 반드시 걸린다.** 하나라도 빠지면 조용히 어긋난다.

| 어디 | 무엇 | 빠뜨리면 |
|---|---|---|
| `cell_materials.gd` 의 `DEFS` | 재료 자체 | 그 앞이 다 막힌다 |
| `assets/stage/terrain_tiles.png` | 붓 그림 32px 칸 하나 | **에디터에 붓이 안 생긴다** |
| `build_terrain_tileset.gd` 의 `TILES` | atlas 좌표 ↔ 재질 | 붓은 보이는데 **재질이 안 붙는다** |
| `terrain_baker.gd` 의 `CHAR_BY_MAT` | 재질 ↔ ASCII 글자 | 굽기가 **짖고 멈춘다**(이건 안전하다) |

🔴🔴 **그리고 다섯째가 하나 더 있는데, 이쪽은 조용하다.**
`terrain_baker.gd` 가 뱉는 `MAP_CHARS` 줄이 **문자열 리터럴로 박혀 있다** —
`CHAR_BY_MAT` 에서 파생되지 않는다. ⇒ **`CHAR_BY_MAT` 을 늘리고 그 줄을 안 늘리면
구운 맵에 새 글자가 들어 있는데 게임이 그 글자를 모른다.**
⚠ 2026-08-07에 이 문서를 쓰다 발견했다. 물이 들어오기 전에 파생으로 고쳐야 한다.

## 왕복 — 내가 찍는 방향

**2026-08-07, 사용자가 정했다: 맵의 타일은 사용자가 디자인하고 클로드가 찍는다.**

지금 파이프라인은 **한 방향뿐이다**(그림 → 텍스트). 클로드가 찍으려면 반대가 필요하다:

```
클로드가 ASCII 를 쓴다  →  타일 레이어에 심는다  →  사용자가 에디터에서 보고 다듬는다  →  굽는다
```

🔴 **심는 도구가 이미 있다** — `tools/stage/paint_terrain_from_map.gd` 가 정확히 그 일을 한다.
⚠ **다만 「일회성 마이그레이션」으로 만들어져 `Terrain` 노드가 이미 있으면 거부한다.**
한 번 쓰고 잠긴 상태다. ⇒ **그 잠금을 풀면 왕복이 된다.**

⚠ 그리고 지금은 `Stage.MAP`(= 구운 결과)을 읽으므로 **자기가 구운 것을 다시 심는다.**
클로드가 새 맵을 주려면 **입력을 갈아 끼울 자리**가 필요하다.

## 함정 — 실측으로 배운 것

🔴 **그린 영역을 스스로 찾는다**(`TileMapLayer.get_used_rect()`). 원점에서 고정폭을 안 읽는다.
⚠ **실측**: 사용자가 312×126타일을 그렸는데 옛 방식(고정창 64×36)이 그 바깥을 조용히 건너뛰어
**구운 결과가 통째로 빈칸**이었다. 음수 좌표(원점 위·왼쪽)도 잡아서 0부터 시작하게 옮겨 담는다.

🔴 **격자 용량을 넘으면 짖고 멈춘다.** 시뮬 격자(`CellGrid.W`·`H`)가 셀 단위로 고정이라
그린 영역이 그보다 크면 **잘라서 구멍 난 지형을 만드는 대신 굽기가 실패한다.**
지금 용량은 **512 × 126타일**이고 그린 것이 312 × 126이라 **세로가 꽉 찼다** — 더 아래로 그리면 걸린다.

⚠ **씬 저장 안 하고 굽기** — 위 ②. 제일 자주 나는 실수고 에러가 안 난다.

## 그물이 이걸 재나

`tests/nets/net_tables.gd` 의 `_wood_clumps` · `_stage_map` 이 **구운 결과를 직접 잰다**
(나무가 여러 덩어리로 끊겨 있나 · 덩어리 사이가 점화원보다 넓나 · 맵 글자가 실재 재료인가).

🔴 **그래서 굽기를 새 이름으로 만들면 안 된다** — 그 그물이 「실제로 도는 지형」이 아니라
**죽은 곁가지를 재게 된다.** `terrain_baker.gd` 주석이 그 이유를 든다.

⚠ **그리고 그물은 「굽기가 맞게 도나」는 안 잰다.** 재는 것은 **구워진 결과의 성질**이다 —
붓 팔레트가 낡았는지 · 씬을 저장 안 하고 구웠는지는 **아무도 안 잡는다.**
