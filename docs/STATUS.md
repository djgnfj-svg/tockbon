## ✅ 세션 8-forge = F1 해결 — 화살표 조이기 + 명시적 맺힘 (전 16스위트 그린)

> 사용자: *"화살표를 만들어보자 지금 너무 이상함"* → *"멋대로 화살표다, 그리지도 않았는데 완료되는 게 띠꺼움"*(TRUTH §4 F1).
> 선택 ③(둘 다) + 맺힘 시점 = **전용 확정 키/버튼**(AskUserQuestion 2회).

**한 것:**
1. **① 탈출 조이기** (`recognizer.gd`): `ARROW_ESCAPE_R` 1.05→1.20 · `GAIN` 0.12→0.25. `classify_stroke`
   재구조화 — **진이 있으면 화살표는 오직 관통(detect_escape)으로만**, 직진성 게이트는 has_circle 아닐 때만
   (진 안 곧은 획·살짝 스친 획이 화살표로 새던 창구 폐쇄). 소속 판정용 `CIRCLE_CONTAIN_R=1.05` 분리(중첩 트리 보호).
2. **② 자동완성 제거** (`drawing_canvas.gd`): 첫 완성의 종이소모·`design_created`·클라이맥스를 `commit_design()`으로
   이동. 완성 조건=**초안**(확정 대기), Enter/버튼으로 맺힌다. `can_commit`/`is_committed`/`commit_state_changed` 신설.
   이미 맺힌 종이의 이후 고쳐 그리기는 자동 `design_updated`(기존 유지).
3. **③ UI**: checklist(확정 대기/맺힘 2상태) · copy(COMMIT_PROMPT/BUTTON/READY_TO_COMMIT) · forge_panel(Enter+✓버튼) ·
   **test_drawing_main = 라이브 이젤에도 Enter+버튼**(거점은 아직 drawing_room을 씀) · test_forge(F6 힌트).
4. **④ 테스트**: 자동완성 의존 테스트에 `commit_design()` 삽입 + 짧은 화살표를 관통 길이로
   (test_drawing·canvas·paper·forge·glyph). **전 16스위트 그린.**

**추가 — 문양 본보기 회전 = 고무줄 겨눔** (사용자: *"오른쪽[클릭]하고 휠이 어렵다"* → 마우스로 돌리자):
옛 "우클릭 누른 채 휠 = 회전"을 폐지하고 **누른 채 끌기**로 교체. 진 위에서 누른 곳=시작(꼬리), 끄는 쪽=방향,
끄는 거리=세기 → 떼면 앉는다. 한 동작으로 위치·방향·길이를 다 정해 충격파 배치가 쉬워졌다. 룬 본보기는
방향이 없어 회전 안 함(중심 앉힘 + 휠=크기 유지). 우클릭=취소로 단순화. `drawing_canvas`(`_begin/_update/_finish_trace_aim`·
`_aiming_trace`) · copy(`TRACE_HELD_ARROW`) · forge_panel 안내 · test_drawing_canvas(`_aim_trace` 헬퍼).

**추가 — 자동 화살촉 제거** (사용자: *"자동으로 화살표 끝이 생성되는게 끔찍함… 내가 직접 화살표 그릴꺼임"*):
코드가 획 위에 덧그리던 **화살촉(촉)을 세 군데서 전부 제거** — 내가 그린 획(drawing_canvas `_draw`),
밑그림 트레이스(`_draw_trace_arrow`·`_draw_heading_arrow` 삭제, `TRACE_HEAD` 삭제), 책자 아이콘(forge_book `_arrow_head` 삭제).
🔴 **화살표는 룬·문양과 똑같이 "그린 그대로"만 렌더된다** — 촉을 그리면 촉이 나오고, 밋밋하게 그으면 작대기다.
인식(classify_stroke)은 촉 달린 획도 그대로 ARROW로 받는다(회귀 없음). 순수 렌더 변경 — 전 16스위트 그린.

> ⚠ **부분 반전 (2026-07-15, 사용자 재요청: "문양 보이는 걸 화살표 모양으로"):** 위 셋 중 **② 본보기·③ 책자
> 아이콘에는 화살촉을 되살렸다** (`GlyphTemplates.head_barbs` — 순수 장식, 인식 불변). **①「내가 직접 그리는 획」은
> 그대로 촉 없음** — "내가 화살표를 직접 그린다"는 유효하다. 즉 *가이드(책·본보기)는 화살표로 보여 주되, 플레이어가
> 실제로 긋는 획엔 코드가 촉을 얹지 않는다.* 다음 세션이 이 둘을 **혼동해 통째로 되돌리지 말 것.**

**추가 — 시험대 무한 잉크** (사용자: *"테스트할때는 잉크무한으로 해"*): `drawing_canvas.set_ink_unlimited(true)`로
잉크 상한 무시(종이 등급·소모·완성 판정은 그대로, 상한만 없앰). forge_panel 포워딩 + **F6 test_forge가 켜 둠**
