# 판때기를 3D 에 세우는 기법 스물한 장, 2026-08-31

**개발지식 01 의 실험대를 그대로 돌려서 찍었다.** 조작만 키보드에서 촬영 반복문으로 바꿨고,
**기법 코드는 한 글자도 안 건드렸다** — 사진이 실험대와 다른 것을 보여 주면 그것부터가 거짓말이다.

**한 장에 스위치 하나만 켰다.** 같은 카메라 · 같은 바닥 · 같은 몸 셋. 왼쪽은 스위치를 안 받는
대조군이고 가운데가 스위치를 받는다.

| 파일 | 무엇 |
|---|---|
| `00_none.png` | **대조군.** 전부 꺼져 있다 |
| `y_axis` · `pitch_lock` · `facings` · `nearest` · `alpha_cut` · `ortho` · `feet` · `shadow_disc` · `real_shadow` · `shaded` · `outline` · `stretch` · `lean` · `depth_push` · `breathe` · `separate` | **기법 하나씩 열여섯 장** |
| `ZV_shipped.png` | **지금 게임이 실제로 켜고 있는 일곱** |
| `ZW_good.png` | **권하는 것 전부** — 14 번(나쁜 예)과 16 번(빛)을 뺀 열넷 |
| `ZY_all_but_bad.png` | 14 번만 뺀 열다섯 |
| `ZZ_all.png` | **열여섯 전부**, 나쁜 예까지 |

## 이 촬영이 잰 것 셋

**하나. 12 번 기준점을 발에가 실험대에서 몸을 지우고 있었다.** 12 번만 켠 장에 몸이 한 명도 없다.
`centered = false` 와 `offset = -높이` 가 겹쳐서 두 번 내려간 것이고, **그림자 원판은 제자리에
있었으므로 세계가 아니라 몸만 사라진 것이다.** 실험대는 그날 고쳤고 여기 사진은 고친 뒤의 것이다.
⚠ **게임 코드는 안 틀렸었다** — 틀린 것은 실험대뿐이었다.

**둘. 16 번 빛을 받게 하기는 이 그림체에서 몸을 하얗게 날린다.** `ZZ_all` 과 `ZY_all_but_bad` 에서
몸이 거의 흰색이다. 빌보드의 법선이 카메라를 보니 해가 정면으로 때리고, **진영을 말하던 색이 같이
날아간다.** `look.gd` 가 이미 같은 것을 실측해 두고 껐다.

**셋. 대조군과 `ZW_good` 의 차이가 이 문서의 요점이다.** 대조군은 **허리까지 땅에 묻힌 채 그림자
없이 떠 있고**, `ZW_good` 은 **발로 서서 원판을 깔고 외곽선으로 배경에서 떨어져 나온다.** 기법 하나
하나는 작지만 열넷이 겹치면 다른 그림이 된다.

## 어떻게 다시 찍나

실험대를 켜서 눈으로 보는 쪽이 먼저다.

```
.\Godot_v4.7.1-stable_win64.exe --path . --script res://docs/개발지식/01-2D-판때기를-3D에-넣기/lab.gd
```

**↑↓ 로 고르고 스페이스로 켠다. A 전부 켜기, Z 전부 끄기.** 이 스물한 장은 그 스위치를 순서대로
켜고 끈 것뿐이다.
