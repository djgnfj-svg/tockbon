## 이번에 잰 것 셋

**하나. 외곽선 1.10 은 21 px 짐승에 너무 두껍다.** 2 px 테두리가 20.9 px 늑대를 통째로 먹어서
**털이 안 보이고 검은 덩어리로 읽혔다.** 검사(27 px, 납작한 단색)는 그 두께를 견뎠다.
⇒ **이 숫자는 몸의 비율이라 몸의 그려지는 크기가 바뀌면 같이 움직인다.**

**둘. 24 번 깊이 밀기는 옮기는 게 아니라 깊이 편향이어야 한다.** 카메라 축으로 몸을 옮기면
정사영이라 화면에서는 아무 일도 안 나는데, 카메라가 기울어 있어서 **월드 Y 가 같이 움직인다.**
`net_fx_view` 의 「그림틀 아래끝이 땅보다 아래다」가 한 라운드 만에 빨개졌다.
⚠ **외곽선은 여전히 그 축으로 민다** — 뒤에 서는 게 목적이고 땅을 안 밟는다.

**셋. 23 번 눕히기는 빌보드에서 무효다.** `BILLBOARD_FIXED_Y` 는 엔진이 기저를 다시 만들어서
노드 회전이 버려진다. **그림에 눕힘을 그려 넣거나 빌보드가 아닌 판을 쓰거나 둘 중 하나**이고,
상수 한 줄이 아니다.
