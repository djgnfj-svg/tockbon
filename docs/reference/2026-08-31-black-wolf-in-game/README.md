# Five wolves stood in the real game, 2026-08-31 night

**One camera, one moment, one size — only the four facing files changed between shots.** The shell was
driven from the title to 26 seconds of fight, zoomed ten notches and turned three, so every picture is
the same frame of the same run with a different animal in it.

⚠ **The wolf is drawn at 0.85 here**, which is a **20.9 px** animal against the swordsman's 26.8. That
is the whole point: a candidate that reads beautifully at 512 px is routinely mush at the size it ships
at, and this folder is the only place the question was actually asked.

| Shot | What it is |
|---|---|
| `g5_now.png` | **what the game ships today** — pixellab, grey. Reads brown on screen; the tint is why |
| `c03_black.png` | pixellab, from the same night's batch as `g5`. Dark, but **still shifts brown** — it is a dark grey, not a black |
| `k1_pure.png` · `k2_muzzle.png` · `k4_ink.png` | the local free pull, three of sixteen. **Flat black silhouettes** |

## What the five measured

**The flat blacks read as wolves more clearly than the grey they replace.** On pale sand a black
silhouette has the highest contrast on screen, and at 20.9 px there is no room for interior shading to
do any work — the outline carries the whole animal.

⚠⚠ **`c03_black` is the control that proves the tint, not the art, is the problem.** It was pulled as a
black wolf on the same route as `g5` and it still arrives brown, because its fur is a dark grey the
0.45 gain still has room to bend. **Only fur near actual black is immune** — see the arithmetic in
`.candidates/wolf/2026-08-31-local-prompts.md`.

⚠ **Nothing was chosen here.** The pictures went to the user; the choice is theirs and lands in the
ticket that asked for it.
