# docs/reference — **밖에서 들어온 자료가 사는 곳**

**두 가지가 산다.** 사용자가 보내 온 **그림**, 그리고 `research` 에이전트가 밖을 뒤져서 남긴 **조사 노트**.
⚠⚠ **둘 다 「다시 안 찾으려고」 남기는 것이다.** 말로 두 라운드 걸리던 것이 그림 두 장으로 끝난 적이
있고, 같은 검색을 두 번 한 적도 있다.

## 이름 규칙 하나

**`YYYY-MM-DD-무엇인가.md` 또는 `.png`.** ⚠ `image copy 2.png` 로는 두 주 뒤에 아무도 못 찾는다.

## 그림

| | 무엇 |
|---|---|
| **무엇을 남기나** | ⚠⚠ **판정이 걸린 것만.** 사용자가 그것을 보고 무언가를 정했으면 남기고, 아니면 지운다 |
| **언제 옮기나** | **`wrap-up` 이 마무리할 때.** 세션 중에는 저장소 뿌리에 그대로 둔다 |
| **누가 정하나** | **`wrap-up` 이 세어서 물어본다.** 혼자 안 지운다 |

⚠ **저장소 뿌리의 `image*.png` 는 `.gitignore` 가 통째로 막는다.** 여기로 옮기면서 이름을 바꾸므로
그 규칙에 안 걸리고 정상적으로 커밋된다.

## 조사 노트

**`research` 가 쓴다.** 한 파일이 질문 하나에 답하고, **줄마다 출처 링크를 단다.**

| | 무엇 |
|---|---|
| **무엇을 남기나** | **읽는 데 실제로 품이 든 것.** ⚠ 한 번 보고 마는 조회는 안 남긴다 — **다음 라운드가 이걸 또 검색할 것 같은가**가 기준이다 |
| **티켓과의 관계** | ⚠⚠ **결론은 티켓에, 자료는 여기에.** 표를 통째로 티켓에 넣으면 티켓을 못 읽게 되고, 아무것도 안 남기면 다음 라운드가 다시 검색한다 |
| **틀린 것이 나오면** | ⚠ **고쳐 쓰지 않는다.** 맨 위에 틀렸다는 줄을 붙이고 그대로 둔다. 새 날짜는 새 파일이다 |

⚠⚠ **여기에 목록 표를 만들지 않는다.** 파일 이름에 날짜와 주제가 들어 있으므로 폴더를 보면 되고,
**손으로 관리하는 목록은 반드시 어긋난다.**

⚠ **게임에 쓰는 그림이 아니다.** 게임 에셋은 `assets/` 이고, 여기는 **읽고 판단하는 자료**다.
