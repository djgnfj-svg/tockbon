# docs/reference — **사용자가 보내 온 그림이 사는 곳**

**말로 두 라운드가 걸리던 것이 그림 두 장으로 끝난 적이 있다** (2026-08-27, 배드노스 화면).
⇒ **그 그림들은 버리는 것이 아니라 남기는 것이고, 여기가 그 자리다.**

## 규칙 넷

| | 무엇 |
|---|---|
| **이름** | **`YYYY-MM-DD-무엇을-보여주는가.png`.** ⚠ `image copy 2.png` 로는 두 주 뒤에 아무도 못 찾는다 |
| **언제 옮기나** | **`wrap-up` 이 마무리할 때.** 세션 중에는 뿌리에 그대로 둔다 |
| **무엇을 남기나** | ⚠⚠ **판정이 걸린 것만.** 사용자가 그것을 보고 무언가를 정했으면 남기고, 아니면 지운다 |
| **누가 정하나** | **남길지 지울지는 사용자가 정한다** — `wrap-up` 이 후보를 세어서 물어보고, 혼자 지우지 않는다 |

⚠ **저장소 뿌리의 `image*.png` 는 `.gitignore` 가 통째로 막는다.** 여기로 옮기면서 이름을 바꾸므로
그 규칙에 안 걸리고 정상적으로 커밋된다.

⚠⚠ **게임에 쓰는 그림이 아니다.** 게임 에셋은 `assets/` 이고, 이 폴더는 **읽고 판단하는 자료**다.
