# The swarm is a mixture, not one uniform organism

**Status**: valid

## What was decided

Clones carry **different parts from each other**. What the swarm is made of is itself part of the build,
rather than one trait applied to every cell at once.

## What wasn't chosen

| Rejected | Why |
|---|---|
| Host evolves, clones are plain copies | Simple, but the swarm is visually one thing repeated — no composition to read |
| A trait applies to the whole swarm ("alien organism") | Strongest single screenshot, and it makes regrouping pointless: nothing is carried per-cell |
| Host is a queen that only breeds | Highest tension, but the host stops fighting and the hands go idle |

## What's tied to it

The harvest loop only means something because a clone carries *its own* experience, and the visible
difference between cells is what makes losing a fat clone hurt.

## Conditions to reopen

If dozens of visually different cells read as noise on screen rather than as a build.
