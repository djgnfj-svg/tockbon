# Parts appear by chance, not by purchase

**Status**: valid

## What was decided

Species experience is earned deterministically, but **which parts of that species appear among the three
level-up candidates is random**, weighted so strong parts are rare. Cost is a second lock, and a missed
part's chance rises for next time.

## What wasn't chosen

| Rejected | Why |
|---|---|
| Deterministic purchase — save up, buy the part you want | Every run converges on the same best part. The user named cheetah legs as exactly this failure |
| Pure random drop on each kill | No plan survives it; hunting a specific animal stops being a strategy |
| Price alone as the gate | No randomness at all, so the order of a run is fixed and every run reads the same |

## What's tied to it

The claim that hunting is the real build decision. It only holds because experience is certain while the
part is not — remove the certainty and hunting becomes a slot machine.

## Conditions to reopen

If the rising-chance rule makes late runs feel deterministic anyway, the weights move before the structure
does.
