# The swarm grows by a key, not by levelling

**Status**: valid

## What was decided

`F` held splits the host **and every clone** in half at once, so the swarm doubles; `V` absorbs every clone
inside a radius in one press. The rule itself is in *Splitting and absorbing* in `stages-and-evolution`.

It filled the hole the card price left: cards became parts-only, which killed the prototype's guaranteed
growth card, and nothing had replaced it.

## What wasn't chosen

| Rejected | Why |
|---|---|
| **+1 clone per level-up** (the GDD's rule) | The hands do nothing. Growth arrives on a timer you cannot refuse, and the level-up already carries the card pick |
| **Doubling on level-up** | Reaches the pool cap in a handful of levels, and every level after that stops growing the swarm — the reward goes quietly dead mid-run |
| **A one-way split with no way back** | The cheap version: press it and the body is decided for the rest of the run. The user's first correction was that `F` has to be pressable again and again |
| **Absorption on contact, automatic** | The prototype's rule. Rejected on sight once absorbing kills the clone — walking through your own swarm must not spend it |
| **Absorbing one clone per press** | Forty clones, forty presses. The user raised this against their own proposal before it was written down |
| **`G` for absorb** | Purely ergonomic: the finger travels too far from `F`. `V` sits beside it |
| **Absorb as a fourth swarm command** | `1` `2` `3` are orders given to the swarm; absorbing is what the host's own body does. Mixing them blurs both |
| **A rule that refunds force on regrouping** | Unnecessary — halving already conserves the total. What a split costs is **concentration**, not force, so there is nothing to pay back |
| **Splitting the host alone** | Not rejected — **deferred by the user**: "you cannot split only yourself, for now" |

## What's tied to it

- **Force stopped being parts-only.** A bare level-1 host would have nothing to halve, so the body carries a
  base force that rises with level. Reverse this and that base has no reason to exist
- **Starting force is 1, and 1 cannot be split**, which makes the first level-up the thing that opens `F`.
  The onboarding is the rule, not a tutorial line
- **The GDD's "absorption does not shrink the swarm" is dead.** It existed to protect the forty-blob picture
  at every harvest; the picture is now rebuilt by hand with `F`
- **The 128 pool cap lost its grounds.** Headcount comes from force now, not from level

## Conditions to reopen

Play showing that `F` is pressed on reflex every time it is available — a key with no reason to refuse it is
the +1 clone rule wearing a keycap.
