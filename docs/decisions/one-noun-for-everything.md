# Not everything is a magic circle — the tower is built, and the circle goes into it

**Status**: valid (2026-08-12)

## What was decided

For one stretch of the conversation, **every noun was collapsed into the magic circle**: soldiers, turrets
and buildings were all going to be the same object with different pieces in it. That was taken and then
**dropped in the same conversation.**

The final shape has **three things, not one** — soldiers summon themselves out of a circle, **towers are
built**, and **circles are fitted into towers to change the bullet.** See
[Core defense is off](defense-shelved.md).

The reason it collapsed: with everything a circle, the user reported **"it just became castle-defending"**
and the thing they had wanted from the start — **a circle you combine and it goes off** — had nowhere to
happen. The unification removed the very object the combining was supposed to act on.

## What wasn't chosen

| Rejected | Why |
|---|---|
| One noun, one verb ("assemble a circle and put it down") | Left nothing for the assembly to change. The tower had been dissolved, so a fitted circle had no host |
| Turrets as circles | The user kept returning to the tower on their own: **"my eye keeps going to the tower."** Building it is what they wanted |
| Buildings as circles | Same act as the turret, so it died with it |
| Soldier simulation — population, supply, per-unit management | **"If the game is minimal, they just fight and die."** Weighed and rejected in the same breath |
| An NPC / companion system | Deferred at first — *"too long"* — then **taken**: workers build the towers. See [Core defense is off](defense-shelved.md) |

## What's tied to it

- **[The circle modifies the tower](circle-modifies-the-tower-not-fires.md) came back.** It had been marked
  reversed by the one-noun idea; the user walked back to it themselves
- The summoning circle **survives the collapse.** Soldiers still come out of a drawn circle — that half was
  never in dispute
- **What the player does during a wave is still open**, and it is now the last unfilled hole in the design

## Conditions to reopen

None foreseen. It was tried and abandoned inside one conversation.
