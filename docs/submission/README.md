## 1번 — 빌드와 소스

**`.exe`는 받지 않는다.** 요강 원문: "보안 상의 이유로 PC 실행 파일(.exe 등) 직접 제출은 받지 않습니다."
⇒ **웹 빌드가 정답이다.** 이미 나와 있다.

```powershell
New-Item -ItemType Directory -Force build\web
.\Godot_v4.7.1-stable_win64.exe --headless --export-release "Web"
```

산출물 `build/web/` — 약 39MB (`index.wasm` 37.7 + `index.pck` 1.5).
**스레드 없는 빌드**라 COOP/COEP 헤더 없이 GitHub Pages에서 그대로 돈다.
로컬 확인은 `python -m http.server 8123 --directory build\web`.

### 배포한 방식 (재현용)

`gh-pages` **orphan 브랜치**에 `build/web/`의 내용만 올린다. `.nojekyll`을 넣어야
Jekyll이 파일을 건드리지 않는다.

```powershell
git worktree add --detach C:\temp\ghp
cd C:\temp\ghp; git checkout --orphan gh-pages
# 내용을 비우고 build/web/. 를 복사, .nojekyll 생성
git add -A; git commit -m "웹 빌드 배포"; git push -f origin gh-pages
gh api repos/<user>/<repo>/pages -f "source[branch]=gh-pages" -f "source[path]=/"
git worktree remove --force C:\temp\ghp; git worktree prune
```

**워크트리는 반드시 지운다** — 자동 정리는 거의 안 걸린다(하룻밤에 700MB, 실측).

### 요강이 요구하는 저장소 조건 — 전부 충족

- **전체 소스 코드를 같은 저장소에 포함** — `main` 브랜치
- **커밋 기록 유지** — 123개 커밋. squash하지 않았다
- **공개(public)** — 전환 완료. 심사 계정 초대 불필요

### 공개 전 시크릿 검사 (완료)

`.mcp.json`에 PixelLab API 키가 평문으로 들어 있어서 **전체 히스토리를 훑었다.**

```bash
git rev-list --all | xargs -n 50 git grep -lE "Bearer [a-f0-9]{8}-|gho_|ghp_|sk-[A-Za-z0-9]{20}"
```

**결과 0건.** 과거에 커밋된 `.mcp.json`은 godot·aseprite만 있던 버전이고,
PixelLab이 추가된 뒤로는 gitignore에 걸려 한 번도 올라가지 않았다.

## 2번 — **30~60초** 영상

요강 원문: "30~60초 분량으로, **실제 게임 플레이 장면을 중심**으로 제작해 주세요."
"**AI를 이용한 조작·합성이나 타인 영상의 도용은 불가**합니다. 실제 플레이 화면 그대로 담아야 합니다."

⇒ **하네스 화면이나 개발 과정을 넣을 자리가 없다.** 60초 전부 플레이 화면이다.
AI 이야기는 4번 문서가 전담한다.

### 60초 구성안

| 시간 | 화면 |
|---|---|
| 0:00–0:12 | **`퍼짐→폭발`과 `폭발→퍼짐`을 연달아.** 같은 글리프, 순서만 바꿔서. 자막 두 줄만 |
| 0:12–0:25 | 지형이 4px 단위로 파이고, 그 구멍으로 물이 쏟아지고, 불이 나무에만 붙는다 |
| 0:25–0:40 | 나무벽에 막힘 → 구덩이 → 황소 → **불 룬 획득** → 벽을 태우고 통과 |
| 0:40–0:55 | 거대 닭 보스, 물이 차오르는 탈출 |
| 0:55–1:00 | 게이트 통과 |

**첫 12초가 전부다.** 순서가 결과를 바꾸는 것이 이 게임에서 한 눈에 보이는 유일한 차별점이다.
설명하지 말고 화면 둘을 붙여서 보여준다.

**공개 또는 일부 공개(링크 공유)로 업로드.** 심사 종료까지 접근 가능해야 한다.

- **몬스터가 맵에 한 마리도 배치돼 있지 않다.** 디버그 키로만 나온다 —
  ⇒ **황소가 없어 불 룬을 못 얻고, 나무벽을 못 태우고, 진행이 성립하지 않는다.**

  **마감 전에 반드시 고칠 것 — 문서로 메울 수 없는 구멍이다**
- **웹 빌드가 실제로 돌아가는지 아직 아무도 확인하지 않았다.** HTTP 200과 파일 크기까지만 봤다.
  **이게 안 되면 1번 제출물이 통째로 무효다.** 제일 먼저 열어볼 것

  심사자에게 개발 콘솔을 보여주는 셈이다

  **문서에는 "아직 없다"로 정직하게 적어 뒀다** — 고치면 문서도 같이 고칠 것
- **사망 시 자동 재시작이 없다.** 체력 0이면 쓰러진 채로 남고 `R`을 눌러야 리셋된다.

- **넷 3개가 빨갛다** — `net_water_rain`, 물 총량 보존.
