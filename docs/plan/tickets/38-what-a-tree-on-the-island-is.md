# 섬 위의 나무는 무엇으로 만드나

⚠⚠ **아직 아무것도 정해지지 않았다.** 프로토타입 한 벌이 서 있고 사용자가 그것을 봤지만, 채택도
기각도 하지 않았다.

> ***"음 나무가 살짝 음... 일단 이렇게 그냥 할까... 뭐 오늘할껀 아니긴해서"***
> — *"hmm the tree is slightly, hmm... shall we just leave it like this for now... it is not a today
> thing anyway."*

⚠ **이 티켓은 로드맵 1 주 표에 행이 없다.** 장식은 이번 주 어디에도 안 적혀 있었고, 2026-08-29 의
이 라운드가 통째로 표 바깥에서 일어났다.

## 무엇을 만들어서 보여줬나

**`prototypes/props/lab.gd`** — 진짜 게임을 열고, 외딴 섬 위에 나무 다섯 그루를 세운다.
**`src/` 는 한 줄도 안 건드렸다.**

```
Godot_v4.7.1-stable_win64.exe --path . -s prototypes/props/lab.gd
Godot_v4.7.1-stable_win64.exe --path . -s prototypes/props/lab.gd -- shoot
```

**나무 한 장이 전부다.** 종류는 하나고 크기만 1.6~3.6 미터에서 굴린다 (사용자: 「종류가 많이 있을
필요도 없어. 하나에서 사이즈만 막 왔다 갔다 하면 돼」).

**그림은 픽셀랩에서 뽑고 모양만 남겼다.** 잎 무늬·하이라이트·두 톤 크라운을 전부 버리고 단색
실루엣으로 눌렀다 (사용자: 「너무 표현해. 단순하게 단색으로 거의」).

| 붙어 있는 것 | 어떻게 |
|---|---|
| **빛** | 실루엣에서 구운 노멀맵. 카드는 평면 하나지만 잎 뭉치마다 볼록해서 해를 받는다 |
| **그림자** | 바닥에 눕힌 원반이 곱하기로 빛을 뺀다. 판의 캐스트 섀도우가 아니다 |
| **테두리** | 어두운 복사본을 1.022 배로, 카메라 축을 따라 뒤로 밀어 한 번 더 그린다 |
| **바람** | 크라운만 기울고 발치는 0 이다. 나무마다 위상이 다르다 |

## 무엇이 세 번 틀렸나 — **다시 밟지 않으려고 적는다**

⚠⚠ **잉크를 월드 좌표에서 아래로 밀면 안 된다.** 카메라가 기울어 있어 아래가 곧 뒤가 아니고, 나무
절반이 새까맣게 나온다. **카메라는 직교라 그 forward 축으로 밀면 깊이만 움직이고 화면 위치는 안
변한다.** 매 프레임 다시 겨눠야 한다 — Q/E 로 돌리면 옛 축이 어긋난다.

⚠⚠ **바람으로 카드의 원점을 밀면 나무가 통째로 미끄러진다.** 정점을 밀어야 하고, 발치 가중치는 0 이다.

⚠ **큰 카드는 픽셀랩이 배경을 안 뚫어 준다.** 64px 은 투명하게 오는데 208~288px 은 배경이 통째로
불투명하다. 테두리에 닿은 배경색만 골라 뚫어야 같은 색 잎이 안 지워진다.

⚠ **카드가 자기 그림자를 품고 오기도 한다.** 넓은 나무에 바닥 타원이 그려져 있었고, 침엽수는 풀밭에
서 있었다. 둘 다 잘라야 바닥 웅덩이와 겹치지 않는다.

## 남들은 어떻게 하나

**결론 한 줄: 아무도 카드 자신의 면으로 빛을 받지 않는다. 전부 노멀을 갈아 끼운다.**

- **노멀은 진짜 3D 메시를 렌더해서 굽는다** — SpeedTree, 에픽의 임포스터(포트나이트의 모든 나무)
- **아니면 손으로 구·돔 노멀을 씌운다** — 게릴라(Horizon Zero Dawn)
- ⚠⚠ **여기서 쓴 실루엣 팽창은 2D 스프라이트 도구의 기법이고, 틀리게 보인다는 측정이 있다** — 원본
  보다 훨씬 덜 충실하고, 그림에 없는 부분을 지어내며, 안으로 파인 곳을 못 만든다
- **그림자는 전부 별개 물체다** — 게릴라는 그림자용 메시를 따로, SpeedTree 는 위에서 본 카드를 한 장
  더 갖는다. 러스트의 변경 기록에 「나무 임포스터 그림자 방향 수정」이 있다
- **반대로 간 곳** — 파이어워치는 나무 스물셋을 전부 3D 로 만들었다

⚠ **고정 각도로 도는 카메라는 임포스터에 나쁜 조건이 아니라 가장 좋은 조건이다.** 구워야 할 각도
범위가 좁다.

## 사용자가 답할 것

**1. 이 방식으로 가나.** 픽셀랩 그림을 단색으로 눌러 카드로 세우는 것 — 아니면 리서칭이 말하는 대로
**블렌더로 나무 메시를 굽고 그것을 렌더해서 카드로 만드나.** 이 저장소는 이미 섬을 블렌더로 굽는다.

**2. 나무가 어떤 모양이어야 하나.** 사용자가 말을 꺼내다 멈췄다 — ***"위에 입만 흔들여야할듯하고 그
가능하면 입을 좀더 줄여주고 위로 길게"*** (*"only the leaves at the top should sway, and if possible
cut the leaves down more and make it taller"*). **지금 나무는 옆으로 퍼져 있고, 크라운 전체가 한
덩어리로 기울어진다.**

**3. 그림자 웅덩이가 땅보다 커도 되나.** 외딴 섬이 2x2 조각인데 3 미터 나무의 웅덩이가 물 위로 번진다.
