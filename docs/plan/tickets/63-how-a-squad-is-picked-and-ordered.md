# 한 무리를 어떻게 집고 어디로 보내나 — **방법이 미정이다**

**티켓 02 를 둘로 가른 것 중 하나다** (2026-08-30, 사용자: 「한무리를 움직이는건 아직 방법미정」).

## Question

**여러 몸을 한꺼번에 집어서 한 조각으로 보내는 것을, 화면에서 어떻게 하나?**

## ✅ 이미 정해져 있고 다시 안 묻는 것

| 무엇 | 답 |
|---|---|
| **무리 단위인가 한 마리씩인가** | **무리 단위** (2026-08-25, 사용자: 「베드노스도 무리로 조절하더라고」) |
| **얼마나 자주** | **아무 때나.** 쿨타임도 횟수 제한도 없다 |
| **명령하면 화면에 무엇이 뜨나** | **이동선이 뜬다** — 티켓 11 이 든다 |

## ⚠⚠ 지금 코드가 하는 것

**왼쪽으로 조각을 누르면 가장 가까운 검사 하나가 거기로 걷는다.** 무리가 아니라 몸 하나다.
**부대라는 것이 코드에 없다** — 2026-08-27 에 사용자가 「칸단위 부대는 따로 없음 아직」이라고 했고,
그 뒤로 안 생겼다.

## 정해야 하는 것

1. **어떻게 집나** — 몸을 누르나, 상자로 끄나, 숫자키로 도나
2. **집힌 것이 화면에서 어떻게 보이나** — 발밑 고리인가, 실루엣 테두리인가
3. **무리를 쪼개고 합치는 것이 여기 붙나** — 3 주 표에 그 줄이 따로 있다

## ⚠ 남들은 어떻게 하나 — **정찰이 이미 들어와 있다**

**Bad North**: 병사 몸을 **왼쪽 클릭으로 집고**, 갈 조각을 **오른쪽 클릭으로 확정**한다. 두 단계의
개별 클릭이지 드래그가 아니다. 숫자키 1~4 와 Q/E 로도 부대를 돈다. 집힌 부대는 **발밑에 주황 링과
실루엣 흰 테두리**를 쓴다. ⚠ **명령을 시작하면 시간이 멈추지 않고 아주 느려진다.**
**전문은 티켓 02 에 있다.**

## ⚠ 이것과 같이 안 붙는 것

**무리의 전투 성향을 고르는 것** — 2026-08-25 에 사용자가 「알고리즘도 내가 조정할 수 있게」라고 했다.
**아직 아무 티켓도 안 들고 있다.**
