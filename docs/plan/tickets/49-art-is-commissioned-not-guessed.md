# 그림은 발주하는 것이지 짐작하는 것이 아니다 — **스킬 하나가 없다**

⚠ **게임이 아니라 하네스다.** 사용자가 만들라고 해서 여기 있다.

## 어디서 왔나

**2026-08-30**, 늑대 여덟 벌을 묻지도 않고 뽑은 직후:

> ***"일단 나랑 대화를 통해서 조금 더 어떻게 만들지 텍스트로 정하고 했어야 되지 않을까?
> 토큰이 무한하지 않은데? 앞으로는 내가 이미지 뽑아달라고 하면은 그 이미지에 대해서 그릴링할 수
> 있도록 스킬을 업데이트하든가 해야 될 듯. 이렇게 계속 네 멋대로 토큰 쓰면 안 되고 돈 드는 거니까."***

**실측**: 「늑대 리스트업해줘」한 마디에 **여덟 장이 나갔다**. 무엇을 뽑을지는 한 번도 안 물었고,
**고른 축이 결국 크기 하나뿐**이었다 — 여덟 중 일곱이 같은 물음에 답하고 있었다.

## ⚠⚠ `prototype` 이 이것을 못 든다 — **사용자가 직접 갈랐다**

> ***"프로토타입 말고 이미지 뽑는 거는 또 따로 뺐으면 좋긴 하겠는데. 프로토타입은 이미 다른 3D...
> 보고 싶은 거를 프로토타입으로 만든 거여서 그거랑은 좀 다른 결이거든."***

| | `prototype` | 없는 스킬 |
|---|---|---|
| **무엇을 세우나** | **코드로 짓는 것을 여러 방법으로** | **바깥 생성기가 뽑는 그림** |
| **값** | **돈이 안 든다** | ⚠⚠ **장당 돈이 나간다** |
| **되돌리기** | 지우면 그만 | **쓴 장수는 안 돌아온다** |

## 이 스킬이 반드시 해야 하는 것

1. ⚠⚠ **뽑기 전에 캐묻는다.** 무엇을 · 몇 벌 · 무슨 축으로 갈라서 · 얼마나 크게
2. ⚠⚠ **돈이 드는 생성은 사용자가 답한 뒤에만 돈다**
3. **갈릴 축을 먼저 적는다.** 여덟 벌이 한 축만 물으면 일곱 장이 버려진다
4. **남은 장수를 먼저 재서 말한다**
5. **결과는 사용자가 볼 수 있는 곳에 놓는다** — ⚠ **모바일에서 본다.** 아티팩트 한 장이 맞았다
6. **뒤에 깔 바탕은 게임의 진짜 색이다** — 흰 바탕에서 고르면 게임에서 다르게 보인다
