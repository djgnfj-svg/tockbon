# 몸이 움직인다 — **절반은 지어졌고 일곱이 남았다**

**앞 지도에서 옮겨 왔다** (2026-08-26 정리). 앞 지도는 지웠고 여기가 이 일의 유일한 자리다.

## Question

**무는 순간에 화면에서 무슨 일이 일어나야 하나, 그리고 그중 몇 개가 그림 없이 되나?**

## 어디서 왔나

**2026-08-25, 사용자가 게임을 직접 돌리다가**:

> ***"명령 반응도 있고, 타격감 그리고 공격할 때 이렇게 쓱쓱하고 뭔가 애니메이션이 있어요. ...
> 지금 너무 재미없어 그냥 붙어서 그냥 벌렁벌렁하는 거밖에 없어가지고"***

⚠⚠ **사용자가 「쫄깃하게 움직인다」의 셋을 다 짚었다: 명령 반응 · 타격감 · 공격 동작.**

## ✅ 2026-08-25 에 지어진 것

- **런지 · 넉백 · 플래시 · 맞은 고리는 원래 있었고 안 보이고 있었다** — 전부 계산 반지름에 매달려
  있는데 그림은 49px 이었다. 크기를 그림에 맞춰 키우니 보인다
- **화면 흔들림은 사용자가 거절해서 지웠다** (***"이게 화면이 흔들릴 필요는 없을듯?"***)
- **붙어서 정지하던 것을 고쳤다** — 걸음 위상이 이동 거리에 매달려 있어서 **제일 집중해서 보는
  자리인 붙어 있는 두 몸이 화면에서 유일하게 완전히 정지한 물체**였다
- **프레임을 넘기는 장치가 생겼다** — 몸마다 시계 둘, 걷기는 시간으로 돌고 시작 위상을 흩는다.
  **종 이름 분기가 한 줄도 없다**
- **늑대 그림 열여섯 장을 로컬 GPU 로 뽑았다** — 유료 도구를 안 썼다.
  ⚠⚠ **캔버스가 프레임마다 다르면 몸이 뛰고 떠오른다** — 열여덟 장 전부 74×40 한 캔버스로 맞췄다

## ⚠ 아직 안 된 것 일곱

1. ⚠⚠ **명령 반응** — [티켓 02](02-hands-move.md)가 서야 생긴다
2. **한 장 0.12 초는 화면을 안 보고 정한 값이다**
3. **가만히 선 몸도 다리를 계속 굴린다** — 제자리 걷기가 미끄러지는 것처럼 읽힐 수 있다
4. **서 있기 전용 동작이 없다**
5. **무는 것 0.48 초가 런지 0.18 초보다 길다** — 몸이 돌아온 뒤에도 입이 벌어져 있다
6. **나머지 종은 프레임이 없다** — 사용자가 ***"일단은 늑대 쪽으로"*** 라고 했다
7. **줄서기 22 초** — 못 나아가는 몸이 정지 화면이 아니게 됐을 뿐 **서 있는 시간 자체는 그대로다**

⚠ **몸 크기가 또 바뀔 수 있다** — 판이 블렌더로 넘어가면서 한 조각의 화면 크기가 다시 정해진다.
