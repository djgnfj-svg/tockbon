# 물 잔주름이 얼마나 끊겨야 하나

## 무엇이 되면 끝인가

**사용자가 후보 넷을 모니터에서 보고 하나를 고른다.**

## 왜 이 티켓이 있나

**후보 넷을 이미 나란히 뽑아 뒀는데 사용자가 모바일이라 화면에서 차이가 안 보였다** (2026-08-26).
**지금 박혀 있는 값은 추천이자 임시**이고, 아무도 눈으로 고른 적이 없다.

| 후보 | 값 |
|---|---|
| 1 안 끊김 | 0.0 |
| 2 토막 | 1.4 |
| ⏳ **3 더 짧게** | **2.6 — 지금 박혀 있는 값** |
| 4 짧고 굵게 | 2.6 + 결 굵기 0.55 |

## 사용자의 말

> ***"이건 모바일로는 잘 안 보인다 어디에다가 기록하고"*** (2026-08-26)

## 어디에 그림이 있나

앞 라운드가 찍어 둔 넉 장이 그대로 남아 있고, 물을 찍는 실행을 다시 돌리면 새로 뽑힌다.
