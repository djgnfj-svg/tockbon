# 배가 찾지 않아도 저절로 화면에 들어온다

## The design says one thing and the build does another

**2026-08-30 the user cut the arrow and the alarm**: *"Not noticing is the right answer... you turn the
camera, you see it, and then you go."* The player is meant to FIND the boat.

⚠⚠ **Measured on screen: with the camera never touched, the boat slides into the default frame on its own
at about t=20s and parks at t=23s.** The crossing is 18 seconds. **So the build does not make you find it
— it hides 14 seconds of the crossing and hands you the last three.**

## And the hunting itself was measured

- **The empty blue is boring, not tense** — no waves, no horizon, no landmark, and ⚠ **you cannot tell
  which stretch of sea you have already searched.** `06-fleck` went in the same day and may have moved
  this; it has not been re-judged.
- **Nothing on the island changes in the first twenty seconds.** Untold, a player concludes the island is
  idle and stops looking.

## The fork

- **Make it truly hidden** — the boat stays outside any reachable framing until it is close, so finding it
  is a real act. ⚠ **Then it has to be findable**, which the empty sea currently is not.
- **Let it come** — accept that the boat arrives in frame, and cut the crossing so the dead time goes.
  ⚠ **Then 18 seconds is the wrong number** and the sailing is decoration rather than warning.
- **Give one signal back** — ⚠ this reopens a decision the user already made once.

⚠ **Sound is not available as an answer**: the user put sound outside the December demo.

## Already true, does not need re-deciding

**Bad North, the stated bar, gives ~30 seconds of crossing, a player-driven camera, a horn, and no edge
arrow.** Of those four this game now has the camera; the crossing is 18 seconds.
