## 1. 한 줄 정체성

**2D 탑다운 익스트랙션 로그라이트.** 낮에는 숲에서 사냥하며 글자를 탁본하고, 밤에는 마법진을 **손으로 그린다.**
게임 이름 = 핵심 루프: **조립한 마법진을 손으로 탁본해 마법을 쓴다.**

## 2. 코어 재미 — 마법을 "그리는 것"

🔴 **심장은 마법을 만드는(그리는) 행위다. 발사·전투는 부수적이다.**
새 기능의 판단 기준은 언제나 **"그리는 재미를 키우나?"** 이다.

- **손으로 그려야 정체성이 확정된다** — 조립이 정답을 숨은 선(밑그림)으로 깔고, 그 위를 사람이 손으로 긋는다.
  채점 = **완성도 × 정밀도**. 맨손 = 보정 0(그린 대로). 펜 등급이 보정을 판다.
- ❌ **모양 인식 채점(제스처 자유)은 되살리지 마라** — 불안정하고 손맛이 나빠 이미 폐기된 길이다.
  자유는 **"아무렇게나 그려도 알아맞힘"이 아니라 "무엇을·어떻게 조합하나"**에서 온다.

## 3. 마법 모델 — 조립 → 탁본 (확정 방향)

**파밍한 「문양-고리」를 진의 층에 조립 → 조립본이 통째로 밑그림(탁본 원판)이 됨 → 그 전체를 손으로 한 번에 따라 긋기(완성도×정밀도=위력) → 해석돼 발사.**

이게 문자 그대로 **탁본**이다: 조립한 마법진 = 새겨진 원판, 손으로 잉크 대고 뜨는 게 탁본.

1. **파밍** — 원정에서 **문양-고리**(예: "파괴 ×5방향"이 그려진 동그란 고리)를 줍는다. 종류를 많이 뿌린다.
2. **조립** — 내 진의 층(밴드)에 고리들을 쌓는다 → 나만의 마법진. (이쁨 + 조합 자유)
3. **탁본화** — 조립본이 통째로 밑그림/가이드가 된다.
4. **그리기** — 그 전체를 손으로 한 번에 따라 긋는다. (손맛·정체성·실력)
5. **발사** — 탁본을 해석(수식 계산)해 마법이 나간다.

🔴 **조립(자유)과 그리기(손맛)는 싸우지 않고 순서로 이어진다** — 조립을 많이 할수록 그릴 게 많아진다.
세13부터 붙들던 「조립 vs 그리기」 진동이 여기서 화해했다.

> 구현 상태: **확정된 설계**(세68). 최소 슬라이스 구현·실측 완료(세70). 확장 진행 중.
> 정본 상세 = `docs/takbon-design/takbon_model.md`.

## 4. 세 축 — 진 · 룬 · 문양

| 축 | 무엇 | 얻고/짓는 법 |
|---|---|---|
| **진** | 날아가는 **모양 + 힘** + **층(밴드) 수** + **룬 자리 배치**. 그릇이다. | 지팡이/파밍. 지팡이 = 진이 박힌 인챈트(다른 지팡이 = 다른 진). |
| **룬** | **속성** (불·물·바람…) | 파밍/해금. 탁본 단계에서 **손으로 그린다.** |
| **문양** | **특성** = 착탄 성질 (파괴·확산…) | **문양-고리로 파밍** → 조립. |

- **룬 자리 = 진 모양이 정한다** (동그라미=중앙 1칸·세모=꼭짓점 3칸·새=날개 2칸) → **복합 룬이 공짜로 온다.**
- **문양 = 착탄 특성 하나로 통합** — "나갈 때 vs 맞을 때" 2단계로 안 쪼갠다(인지 부담).
- **표현 = 지팡이(진) × 내가 그린 룬·문양.** (memory `takbon-magic-grammar-rune-glyph-circle`)

## 5. 마법진 = 수식 (은유)

**그린 게 날아가는 그림이 아니라, 써놓은 식이 계산돼 마법이 나온다.**

- **크게 그리기 = 기각 · 궤적 그대로 날아감 = 기각.** 기호는 작고 조밀한 게 맞다.
- "자잘함"의 해결 = 크기가 아니라 **의미**. 배치만 바뀌어도 결과가 통째로 달라진다(`a²+b` vs `(a+b)²`).
- **감싸기(동심) = 연산 순서** — `확산(파괴(불))` = 맞으면 크게 터져 퍼지는 불.

## 6. 왜 나가나 — 익스트랙션 원정

- **장르 = 원정(익스트랙션).** 나가는 이유 = **새로 그릴 것을 얻으러**(새 룬·문양-고리·진 = 코어 재미 확장).
- **긴장 = 가방(원정 중 획득은 전부 가방에 · 죽으면 증발)·귀환.**
- **루프 = 마을 허브 → 원정(챕터 보스방) → 보상 → 마을.** 즉시 보상 축(돈·상점)과 코어 보상(룬·진·문양)이 함께.
  (경제·보상 상세 = `docs/takbon-design/dopamine_design.md`)

## 7. 설계 원칙

- 🔴 **"주지 말고 얻게"** — 보상은 재료 쳇바퀴가 아니라 **새로 그릴 것**으로 흐른다.
- 🔴 **다르게 그리면 전투가 "종류"로 달라져야 한다** — 스칼라(세기)만 바꾸는 축은 자유도가 아니다.
- 🔴 **회귀 위험을 구조로 0** — 기존 계약(발사·저장·해금 사슬)을 안 건드리는 설계를 우선.
- **데이터 주도** — 가능하면 "새 X = .tres 한 장." 단일 소스를 늘리지 마라.
- **손맛·밸런스는 설계가 아니라 사용자 튜닝** — 플레이하며 조인다.
- 🔴 **생명체·프롭은 도형 플레이스홀더 금지** — 진짜 도트 스프라이트(VFX·가이드선은 예외).
