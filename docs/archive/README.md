# archive — closed work, kept as it stood

**Read, don't update.** Everything here is a record of a moment that has passed. Its claims were true
on the day they were written and the code has moved since; correcting them would destroy the record
and would not help anyone.

⇒ **Nothing here is a source of truth about the game.** `docs/GDD.md`, `docs/design/` and
`docs/plans/` are. If a doc here contradicts one of those, the other one is right.

| Folder | What |
|---|---|
| `nan2026/` | The NAN 2026 preliminary submission — the five deliverables, the adversarial reviews that shaped them, the video cut list, the risk list as it stood at the deadline, **and the tools that baked it all** |

**Everything for one contest lives in one folder, tools included** (decided by the user). The PDF converter,
the screenshot capture and the two figure scripts moved out of `tools/` to sit beside what they produce, and
their output paths are relative to their own folder — **move the folder again and they follow.**

⚠ **They still write into the sealed folder.** Re-point the output before running any of them for a later
round, or the record of what was submitted gets overwritten with today's game. Each one says so in its header.

**When something closes and its docs would only rot in place, it moves here** — not deleted, because
"why did we do it that way" is answered by the record and by nothing else.
