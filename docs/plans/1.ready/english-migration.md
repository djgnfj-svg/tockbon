# 영어 전환 — 하네스와 문서를 영어로, 대화는 한국어로

**상태**: ready — 사용자가 신호를 줄 때 시작한다. 지금은 아무것도 안 바꾼다
**한 줄**: 프롬프트·문서·주석을 영어로 바꾼다. **사용자에게 하는 말은 계속 한국어다.**

## 왜

사용자가 정했다. 모델이 읽는 것은 영어가 더 정확하게 걸린다.

**사용자는 영어를 못 읽는다.** 그래서 전환은 **모델이 읽는 쪽에만** 걸린다.

## 절대 안 바뀌는 것

| 무엇 | 언어 |
|---|---|
| **사용자에게 하는 모든 답변** | **한국어** |
| 사용자가 쓰는 명령·질문 | 사용자 자유 (영어로 쓰겠다고 했다) |
| 커밋 메시지 | **미정 — 물어라** |
| 게임 안에 보이는 글자(재료 이름, HUD) | **미정 — 물어라** |

**이 규칙이 죽으면 전환 전체가 실패다.** CLAUDE.md 를 영어로 옮길 때
`Always respond to the user in Korean.` 를 **맨 위에** 둔다. 묻히면 안 된다.

## 순서와 이유

```
1단계 하네스  →  2단계 문서  →  3단계 주석
```

**1단계를 먼저 하는 이유**: 하네스가 영어가 되면 그때부터 새로 쓰는 문서가 저절로 영어로 나온다.
문서를 먼저 옮기면 **한국어 하네스가 계속 한국어 문서를 낳는다.**

**단계 사이에 그물을 돌린다.** 3단계는 `.gd` 를 건드리므로 특히 그렇다.

## 함정

**용어를 먼저 고정한다.** 안 하면 파일마다 다른 말이 된다. 이 리포는
같은 값을 두 곳에서 세다가 갈라진 적이 있다.

| 한국어 | 영어 (제안 — 확정 아님) |
|---|---|
| 진 | circle |
| 룬 | rune |
| 문양 | glyph |
| 그물 | net |
| 파면 | burn slot |
| 청크 재우기 | chunk sleep |
| 바닥 채우기 | floor fill |
| 판정 | acceptance check |
| 사면 | expected-error amnesty |

**코드 식별자는 이미 영어다** (`glyph_defs`, `CIRCLE_ROUND`, `carve_r`).
**주석의 용어를 코드 식별자에 맞추면 표가 저절로 정해진다.**

**한글 파일명 넷을 어떻게 하나** — `docs/design/` 의 `물.md` · `몬스터.md` ·
`배경.md` · `지형-굽기.md` · `마법진-그림.md` · `진-룬-문양.md` · `마을.md`.
**바꾸면 가리키는 링크를 전부 고쳐야 한다.** 이 리포는 그걸 매번 흘렸다(CLAUDE.md).
⇒ **파일명은 마지막에 한 번에 바꾸고, 바꾼 직후 링크 검사를 돌린다.**

**「사용자가 정했다」를 지우지 마라.** 영어로 옮겨도 그 권위 표시는 남는다
(`decided by the user`). 그게 없으면 다음 세션이 뒤집는다.

## 판정

1. 답변이 여전히 **한국어**로 나온다 — 전환 후 첫 턴에 확인
2. 죽은 링크 0 — 파일명을 바꿨으면 특히
3. 그물이 전환 전과 **같은 통과 수**를 낸다 (3단계 뒤)
4. `docs/design/README.md` 표와 각 문서 머리의 값이 여전히 일치한다
5. 새로 만든 문서가 영어로 나온다 — 하네스가 실제로 걸렸다는 증거

## 미정

- **커밋 메시지 언어** — 지금은 한글 한 문장이다(`wrap-up`)

  화면에 나오므로 전환 대상인지 사용자가 정해야 한다
- **한글 파일명을 바꾸나**
- **`docs/plans/3.done/` 을 정말 안 옮기나**
