# 탁본 기획 문서 (takbon-design)

`takbon-design` 스킬로 리드가 사용자와 대화하며 확정한 **기획·설계 문서의 영구 보관소**다.
새 설계는 여기 `<주제>_design.md`로 착지한다. (구현 보고·architect 리뷰는 **일회성**이라 **`docs/_reports/`**(gitignore)에 쓰고 반영 뒤 지운다 — 여기 두지 않는다.)

> 🔴🔴 **세106에 「현역」과 「휴지통」을 물리적으로 갈랐다**(사용자 확정 — *"다한문서 정비하고 · 클리어한거랑 아닌거랑 구분이 필요"*).
> **구현이 끝난 설계는 `_archive/`로 내린다 — 지우지 않는다.** 그전엔 상태 이모지(🟢/📄)로만 갈라서
> **표가 낡으면 구분 자체가 사라졌다**(세106 실측: `enemy_perception_design`이 **세105에 전량 구현됐는데
> 표는 「📄대기 · 구현 미착수」**로 적고 있었다 — 그걸 읽고 착수했으면 **이미 있는 기능을 다시 짠다**).
> 🔴 **내리기 전에 「딸린 미결」을 먼저 건져라** — 세106에 `jin_interpretation`의 **M3 착수 킷**이 통째로
> 휴지통에 들어갈 뻔했다(BACKLOG에 항목이 **0개**였다 → `BACKLOG M3`로 승격) ·
> `glyph_data`의 **「새 문양 = 2곳」 레시피**도 같은 자리였다(→ `PROGRESSION §5`).
> **절차 정본 = `takbon-docs` 에이전트.**
