# 탁본 기획 문서 (takbon-design)

`takbon-design` 스킬로 리드가 사용자와 대화하며 확정한 **기획·설계 문서의 영구 보관소**다.
새 설계는 **`planned/<주제>_design.md`**로 착지한다. (구현 보고·architect 리뷰는 **일회성**이라 **`docs/_reports/`**(gitignore)에 쓰고 반영 뒤 지운다 — 여기 두지 않는다.)

> 🔴🔴 **2026-07-29(세109)에 3단계 보관으로 갈랐다**(사용자 확정 — *"기획만 한것과 현재 개발중인 기획과 개발 완료된 기획이 나눠져서 보관 되었음면 좋겠음"*).
> **자리가 곧 상태다.** 세106엔 「현역/휴지통」 둘이었고 그전엔 상태 이모지(🟢/📄)로만 갈랐는데,
> **표가 낡는 순간 구분 자체가 사라졌다**(세106 실측: `enemy_perception_design`이 **세105에 전량 구현됐는데
> 표는 「📄대기 · 구현 미착수」**로 적고 있었다 — 그걸 읽고 착수했으면 **이미 있는 기능을 다시 짠다**).
> 폴더로 가르면 표가 낡아도 **`ls` 한 번이 진실을 말한다.**

| 폴더 | 무슨 뜻인가 | 누가 옮기나 |
|---|---|---|
| **`planned/`** | 설계는 착지했고 **구현은 아직 0**이다 | `takbon-design` 스킬(리드)이 여기로 착지시킨다 |
| **`building/`** | **구현 중**이거나 **부분 구현**이다 | 리드가 구현 축에 넘길 때 옮긴다 |
| **`done/`** | 구현이 끝났다. 🔴 **지운 게 아니다** — 「왜 그렇게 지었나」를 캘 때 연다 | `takbon-docs` 에이전트 |

🔴 **`planned`에서 곧장 `done`으로 뛴 문서가 있으면 「중간 상태를 아무도 안 옮겼다」는 뜻**이다.
⚠ **세110에 폴더 접두사(`1_`·`2_`·`3_`)를 걷었다**(`37679e9`) — 옛 기록·설계문서가 `1_planned`·`2_building`·`3_done`으로 적은 것은 **같은 폴더**다.
🔴 그 커밋이 **`tools/docs_audit.py`와 이 파일의 헤딩을 안 고쳐 단계 폴더 둘이 「없는 폴더」가 돼 있었다**(세110 실측 `DOCS_AUDIT_FAIL:32`) — **폴더 이름을 바꾸면 검사기·헤딩·`CLAUDE.md`·스킬·에이전트가 한 덩어리다.**
🔴 **내리기 전에 「딸린 미결」을 먼저 건져라** — 세106에 `jin_interpretation`의 **M3 착수 킷**이 통째로
휴지통에 들어갈 뻔했다(할 일 목록에 항목이 **0개**였다 → `TODO.md` 「진 해석 남은 셋」으로 승격) ·
`glyph_data`의 **「새 문양 = 2곳」 레시피**도 같은 자리였다(→ `PROGRESSION §5`).
**절차 정본 = `takbon-docs` 에이전트.**

## 🔴 인덱스 규율 — 이 표가 `ls`와 갈라지면 그 자체가 버그다

| 검사 | 식 |
|---|---|
| **planned** | 아래 「planned」 표 줄 수 == `ls docs/takbon-design/planned/*.md` |
| **building** | 아래 「building」 표 줄 수 == `ls docs/takbon-design/building/*.md` |
| **done** | 아래 「done」 표 줄 수 == `ls docs/takbon-design/done/*.md` |

🔴🔴 **검사기가 이걸 자동으로 잰다 — `python tools/docs_audit.py`.** 표 셋 + **단계 폴더 밖에 굴러다니는 `.md`** + 죽은 경로 참조까지 본다.
⚠ **헤딩에서 폴더명을 빼지 마라** — 검사기가 `planned`·`building`·`done`이라는 **글자로 표를 찾는다.** 빼면 그 표가 통째로 「없는 것」이 돼 전량 빨강이 난다.
⚠ **개수를 문장으로 적지 마라** — 세96에 헤더의 「전 10개」가 먼저 낡았다. 표만 유지한다.
🔴🔴 **이 규율은 이 파일 자신이 네 번 어겼다** — 세96 `visual_language`(453줄) · 세101 `ring_as_gear` ·
세105 `vision_occlusion`(421줄)이 **표에서 통째로 빠졌고**, 세106엔 `enemy_perception`의 **상태가 거꾸로** 적혀 있었다.
**문서를 더하거나 지우거나 옮기면 여기부터 고쳐라.**

🔒 = 잠긴 `docs/GDD.md`가 가리키는 문서라 **경로를 바꾸면 GDD도 같이 고쳐야 한다**(사용자 허락 필요).
