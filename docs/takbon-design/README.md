# 탁본 기획 문서 (takbon-design)

`takbon-design` 스킬로 리드가 사용자와 대화하며 확정한 **기획·설계 문서의 영구 보관소**다.
새 설계는 여기 `<주제>_design.md`로 착지한다. (구현 보고·architect 리뷰는 일회성이라 리포 루트 `scratch_*.md`에 쓰고 반영 뒤 지운다 — 여기 두지 않는다.)
