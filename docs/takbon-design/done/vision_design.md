**세110 장르 전환 D8 — 시야를 통째로 걷는다.** 사용자가 선택지에서 **「전부 걷는다」**를 직접 골랐다.

🔴 **이 기능이 장르를 갈아엎은 사유의 1순위였다.** 실측한 느림의 출처 넷 중 첫째가
*"시야 부채꼴 100° + 주변시 110 — 앞이 안 보이니 천천히 간다"*였다.
⇒ **수치를 조이는 게 아니라 걷는다.** 걷히면 세104가 만든 어둡기 예외도 사라져
**세73 「밝게 유지 + 빛 웅덩이만」으로 완전히 돌아간다.**

⚠ **죽기 전에 이미 두 번 정정됐다** — 세105가 수치 셋을 뒤집었고(주변시 220→110 · 부채꼴 120°→100° · 상한 0.35 그물 은퇴),
