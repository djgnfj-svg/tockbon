## 왜 죽었나 — 한 세션 만에 뒤집혔다

- **세105**: 사용자 *"바위뒤에 숨을 수 있어야할꺼같아 시야도 막히고 나무도 시야가 막히는게 중요할듯함"*
  → 선분↔원 교차 판정 + 원뿔 그림자 셰이더 + 그물을 셋 같이 세웠다.
- **세107**: **같은 사용자가 F5로 걸어 보고 뒤집었다** — *"구지 나무나 돌맹이에 시야가 가려지지 않도록"*.
  판정·셰이더·그물을 **셋 같이 걷었고** 맵에서 바위 프롭도 뺐다(프롭 108→59 · 씬·PNG는 남겼다).
- **세110 D8**: 시야 자체가 폐기됐다 — 차폐를 되살릴 무대가 없어졌다.

정본 = `docs/DECISIONS.md` 「비주얼」 첫 항목 · 장르 쪽 = `docs/takbon-design/planned/genre_pivot_design.md`.
