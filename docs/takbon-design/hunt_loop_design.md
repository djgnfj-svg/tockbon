## 0. 왜 (문제 진단)

사용자 진술: *"게임이 재미가 없어 몬스터를 잡으러갈 흐름을 만들어야할듯"* ·
*"시작해서 마법만들고 가서 얻는것도 없고 마법진을 그려서 쏴도 기쁘지가 않고 뭔가 게임이 살짝 암것도 없음"*

좁힌 결과 = **잡아도 얻는 게 없다 · 뭘 해야 할지 모르겠다 · 터지는 게 밋밋하다 · 쏠 상대가 없다.**

**데이터로 확인한 실제 상태** (느낌이 아니라 사실):

| 사슬 | 현재 |
|---|---|
| 잡몹 처치 | **5종 전부 `coin`만** 떨군다 (1~4닢) |
| coin 소비처 | 상점에 **잉크 2종뿐** → 잉크는 세83 그리기 폐지로 **의미 상실** |
| 조립 부품 | 룬 6 · 진 3 · 고리 5 → **거의 전부 시작부터 지급**(codex 12키 + 완성 도안 3장) |
| 챕터 보상 | `ch1.reward_unlock = gr_radiate5` **하나뿐** — ch2·ch3는 **빈 문자열** |
| 보스 재료 | 공방으로 → **펜·종이·잉크**(전부 그리기 폐지로 의미 상실) |
| 무대 | 보스방 **단칸방 1200×1040**, ch2·ch3는 `mob_spawns`가 **비어 있어 잡몹 0마리** |
| 잡몹 5종 중 | `hound`·`mist`·`vine`은 **스폰되는 곳이 0곳** |

**진단: 게임이 시작하자마자 조립 부품을 다 줘버렸고, 사냥으로 버는 돈·재료는 전부 폐지된 축(그리기)으로 흘러간다.** 획득의 즐거움이 구조적으로 0이다.

⚠ CLAUDE.md가 이걸 예고해 뒀다 — *"임시 시드가 누적돼 있다… 관문을 붙이는 세션은 해당 시드 줄을 같이 지워야 관문이 조용히 안 죽는다(세58)"*. **이 설계가 그 세션이다.**

### 「터지는 게 밋밋하다」에 대하여

절반은 이펙트가 아니라 **터뜨릴 무리가 없어서**다. 조립의 핵심(층 = 연산 순서 · 확산 = 복제 산개 · 폭발 = 융합 광역)은 **여럿을 상대할 때만 차이가 보인다.** 1:1 보스전에서는 확산이든 응축이든 그냥 데미지 숫자다. 이 설계가 잡몹 무리를 깔면 절반이 풀린다.
**나머지 절반(착탄 VFX·광역 처치감·피격음 3종)은 이 설계 범위 밖 — 별도 세션(§11).**

if dist > _param("aggro_range", <기본>):

### 13-7. 두루마리 픽업 배선 (§3-B-2 · 구현 4단계)

`DropPickup.setup(item_id, count, scatter_angle)`가 현재 시그니처(`drop_pickup.gd:116`).
`unlock_id` 경로를 얹을 때 **반드시 같이 고칠 것**:

```gdscript
func _collect_at(at: Vector2) -> void:
    if _collected or item_id == &"":     # ← 🔴 여기서 _collected를 안 세우고 return한다
        return
    _collected = true
```
자석 도착 경로(`:286~288`)가 `_collect_at`을 부르고 **아무 일도 안 일어나면 다음 프레임에 또 부른다** → 픽업이 플레이어에 **붙은 채 영원히 안 사라진다**(에러 없이).
지금은 유일 생성자(`forest_enemy._die`)가 항상 `item_id`를 채워서 무해하지만, **`unlock_id` 픽업이 이 함정을 연다.**

`_apply_color`(`:134`)도 같이 본다 — `Db.get_item`이 null이면 **마름모 `Polygon2D` 폴백**(세54 도형 금지 위반)이라, `unlock_id` 경로가 `scroll_glyph_ring.png`를 찾아가게 해야 한다.
