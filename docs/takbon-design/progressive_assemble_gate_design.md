# 설계: 점진적 조립 + [그리기 시작] 게이트 + 탁본 종이 결과

> 산출물 = takbon-dev/리드가 받는 **구조 설계**. 게임 디자인 = 확정(AskUserQuestion — 재논의 없음).
> 범위 = **책 UI(`ring_forge_panel` + `ring_book`) 내부 흐름만.** base·발사·core·저장 계약 무변경 목표.
> 전제 = `book_redesign_design.md`(세70/71 「조립 후 통째 트레이스」)가 이미 구현돼 있다. 이 문서는 그 위에
> **① 점진 조립(선택된 조각만 밑그림) ② 조립↔그리기 단계 분리 게이트 ③ 결과=탁본 종이 연출**을 얹는다.

---

## 목표 / 왜

사용자 관찰: *"진을 누르면 진만 떠야 하는데 왜 가운데 룬이 같이 뜨지?"*

원인 = `ring_forge_panel.gd:143` `_sel_rune := RingBoard.RUNE_FIRE`가 **기본 불로 항상 세팅**돼,
진만 골라도 `compose_guide`가 가운데 불 룬(삼각형)을 합성해 넣는다. 지금 모델은 "다 골라 놓고 통째로
따라 긋기"라 룬이 미리 차 있는 게 의도였지만, 사용자는 **점진적으로 쌓이는 느낌**을 원한다.

바꿀 것 = 조립을 **진→룬→층 순서로 쌓고**(고른 것만 밑그림에 등장), 다 쌓았으면 **[그리기 시작]으로
조립을 잠근 뒤** 손으로 긋고, 결과를 **'탁본 종이'**로 보여준다.

핵심 재미 잣대(`takbon-core-fun-drawing`) = "그리는 재미를 키우나?" → **조립이 밑그림으로 자라나는 걸
눈으로 보고, 조립을 맺은 뒤 온전히 그리기에 집중**하게 하므로 그리는 행위를 또렷하게 만든다. ✅

## 새 흐름 (3단계)

패널에 **단계 상태**를 추가한다: `ASSEMBLE`(조립) → `DRAW`(그리기) → `RESULT`(탁본 종이).
(현재 패널엔 명시적 단계 변수가 없고 트레이스가 상시 열려 있다. 이 상태기계가 이 설계의 뼈대다.)

### A. ASSEMBLE — 조립 단계 (손 긋기 잠금, 조립만)
- **진→룬→층 고정 순서**로 탭이 열린다:
  - 시작: **진 탭만 활성**, 룬·층 탭은 잠김(회색·클릭 무시).
  - 진 고름 → 밑그림에 **진 윤곽만** 그려짐 + **룬 탭 열림**.
  - 룬 고름 → 밑그림 가운데에 **룬 채워짐** + **층 탭 열림**.
  - 층(문양-고리) 끼움(선택) → 밑그림에 **밴드 나타남**.
- 밑그림 = `compose_guide(shape, 선택된 룬, 선택된 밴드, …)` — **아직 안 고른 조각은 빼고 합성.**
  - 🔴 지금은 룬을 무조건 넣는다. 바꿀 것 = **룬을 아직 안 골랐으면 룬 없이 진 윤곽만** 합성.
  - 🔴🔴 **구현 못박음(리뷰①)**: `compose_guide` **시그니처를 바꾸지 마라** — static 단일 소스이자
    헤드리스 관측점이고 호출자가 셋(`ring_forge_panel`·`assembly_slice_panel`·`test_assembly_slice_auto`)이다.
    내부 룬 섹션을 `if rune_type >= 0:`로 감싸고, 패널이 룬 미선택 시 **센티넬 -1**을 넘긴다.
    슬라이스 패널·테스트는 `RUNE_FIRE`(0)를 그대로 넘겨 **무변경**.
- 이 단계에서 **왼쪽 판 손 긋기 입력은 잠근다** — 조립만 만지고 그림은 아직.
  - 🔴🔴 **구현 못박음(리뷰②)**: 새 보드 플래그 만들지 마라 — **이미 있는 `board.mouse_filter` 토글
    재사용**(`_spread_open`이 이미 IGNORE↔STOP을 씀). ASSEMBLE에서 `board.mouse_filter = IGNORE`면
    좌클릭·우클릭·휠이 `_gui_input`에 안 들어와 한 번에 잠긴다. **게이트는 `_gui_input`(마우스) 경로에만**
    걸린다 — 공개 API `trace_stroke`는 헤드리스 테스트가 직접 부르므로 절대 막지 마라(mouse_filter 방식이
    이걸 자동 만족).

### B. [그리기 시작] 게이트
- **진+룬이 모두 선택돼야 버튼 활성**(층은 선택 사항).
- 누르면 **이 순서로**(🔴🔴 리뷰③ — 안 지키면 "본 것 ≠ 그은 것 ≠ 쏜 것"이 갈리는 세26-인접 침묵 분기):
  1. 룬 확정 전환(센티넬 -1 → 실제 룬) → **② recompose(룬 포함 full 가이드 = 진+룬+밴드)**
  2. `enter_combined_trace(full)` — 채점 가이드가 최종 조립본과 일치
  3. 조립 잠금(진·룬·층 탭 회색) + `board.mouse_filter = STOP`(손 긋기 열림) → 단계 `DRAW`
  - "밑그림 확정" = 이 recompose를 가리킨다. 문구: *"이제 이 밑그림을 손으로 따라 그으세요."*
- **[다시 조립]** 버튼으로 게이트를 풀고 `ASSEMBLE`로 복귀(획 리셋·`board.mouse_filter = IGNORE`). 안전장치.

### C. DRAW → RESULT (탁본 종이)
- 손으로 따라 긋기(현행 `enter_combined_trace`/COMBINED 트레이스 그대로) → **[분석 ▶]**.
- [분석 ▶] → 점수 계산(현행 `trace_scorer`·`ring_power`) → 단계 `RESULT`.
- 결과를 **'탁본 종이' 연출**로: 내가 그은 획 + 종합 점수/등급이 종이 위에 찍힌 모습.
  - 최소 구현 = 기존 `_draw_report`(분석 리포트)를 **종이 질감/획 프리뷰가 있는 결과 카드**로 다듬기.
    (완전 새 시스템 아님 — 리포트에 "내가 그은 획 미리보기 + 종이 톤"을 얹는 시각 개편.)
- **[마력 주입]**(맺기)으로 슬롯 장착 — **현행 유지**(`design_committed` → base가 받음). 미달이면 펑(`commit_rejected`).

## 회귀 안전

- 발사 경로: 룬 필수라 `_sel_rune`는 [그리기 시작] 시점에 항상 유효 → `to_assembly()`의 rune 계약 유지.
- `compose_guide` 룬 생략은 **ASSEMBLE 단계 표시 전용** — DRAW로 넘어가면 룬이 확정돼 있으므로 채점·발사에
  쓰이는 최종 가이드는 지금과 동일(진+룬+밴드).
- 결과 = 탁본 종이는 **연출 개편**이지 결과 데이터 구조 변경 아님 → 저장·슬롯 무영향.

## 검증 (그물 + 실게임)

- 헤드리스(`test_assembly_slice_auto` 계열 확장):
  - 🔴 **점진 합성**: `compose_guide(shape, -1, …)` = 진 윤곽만(룬 점 0), `compose_guide(shape, RUNE_FIRE, …)` = 룬 포함. 뮤테이션(센티넬 가드 `if rune_type>=0` 제거하면 -1도 룬 그림 → 빨감)으로 검출력 확인.
  - **단계 전이 계약**: 진+룬 없으면 [그리기 시작] 비활성(게이트), [다시 조립] 시 ASSEMBLE 복귀·획 리셋. 게이트 시 룬 포함 recompose(리뷰③) — 최종 가이드 = 진+룬+밴드.
  - **탭 순서 잠금**: 선택-파생 상태로 잰다(진 안 골랐을 때 룬 탭 닫힘, 진 고르면 열림).
  - 🔴 **`test_base_auto` reject 절 재작성**(리뷰④): 드로잉 잠금이 상호작용 순서를 바꾼다 — reject 절이 **게이트 통과 후 부분 그림→close→commit_rejected 1회**를 재도록 고친다(안 하면 coverage=0으로 그물이 자명 통과).
  - **`test_assembly_slice_auto`**: 센티넬 채택이라 **무변경**(뮤테이션으로 검출력만 재확인).
  - 발사 계약 무변경: `build_assembly`가 여전히 score/rings/rune/jin 싣음(세26 to_assembly 그물).
- 🔴 **실게임 MCP 필수**(세25·세50): 새 클릭 타깃(**[그리기 시작]·[다시 조립]·잠긴 탭**)·점진 밑그림 렌더·게이트 후 손 긋기 열림·탁본 종이 결과 겉보기·[다시 조립] 되돌림은 헤드리스가 못 잡는다. `push_input`으로 실제 클릭 밀고 F5로 손맛 확인.
