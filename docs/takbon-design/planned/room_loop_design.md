# 방 루프 — 장르 전환의 첫 조각

> 🔴 **이 문서는 `genre_pivot_design.md` §7이 미뤄둔 「첫 조각」이다.** 장르는 거기서 정해졌고, 여기서 정하는 것은
> **그 장르를 처음으로 코드에 얹는 한 사이클의 범위**다.
>
> 🔴🔴 **이 문서의 `R1…R9`는 여기서만 유효한 번호다.** `genre_pivot`의 `D1…D11`과 **다른 체계다** —
> 특히 그쪽 **D8(시야·인지 폐기)**과 이 문서의 R번호를 섞어 부르지 마라.
>
> 📅 2026-08-01 (세112) · 확정 라운드 9회 왕복.

## §A 게임 기획

### 1. 무엇을 · 왜

**세110이 장르를 갈아엎었는데 코드는 한 줄도 안 옮겼다.** `genre_pivot`은 D1~D11로 **무엇을 만들지**를 정하고
*"첫 조각은 다음 세션에 고른다"*로 끝났다. 그 사이 두 세션이 문서만 만졌다.

⇒ **이 조각의 목적은 기능이 아니라 「재는 것」이다.** 새 장르의 가장 큰 미지 —
🔴 **「방으로 끊으면 실제로 호쾌한가」** — 를 F5로 한 번 본다. 그 답이 나와야 방 개수·한 판 길이·던전 안 조립 같은
남은 미결들이 짐작이 아니라 실측 위에서 정해진다.

⚠ **그래서 이 문서는 「완성」이 목표가 아니다.** 보스도, 챕터 연쇄도, 던전 안 조립도 이번엔 안 한다(R9·§8).

### 2. 플레이어가 겪는 것

```
【마을】 진 ◎ 고르고 · 룬 🔥 갈아끼우고 → 숲길 게이트 [E]
                                          ⚠ 챕터 선택 화면은 사라진다 (genre_pivot D9)
【런 — 방 5~6개】
  [방 1]  화면 1.5~2배 크기 · 카메라가 따라간다 · 🔴 안개도 부채꼴도 없다. 적이 처음부터 다 보인다
            ↓ 적을 다 쓴다
          방 가운데 【상자】가 뜬다 → [E]로 연다 → 문양 + 재료
            ↓
          문이 2~3개 열린다. 🔴 각 문 위에 「그 너머에서 얻을 것」이 아이콘으로 보인다
            ┌─[🌀 문양]
            ├─[⚒ 재료]
            └─[🌀 문양]
            ↓ 골라서 들어간다
  [방 2] … [방 5~6]
            ↓
  마을로 돌아간다 → 책상에서 주운 문양을 마법진에 끼운다
  ⚠ 「던전 안에서 그 자리에 끼우기」는 다음 사이클이다
```

### 3. 왜 재밌나 (탁본 잣대)

**잣대 = "조립의 선택지가 늘어나나 / 다르게 조립하면 전투가 종류로 달라지나"**(GDD §2).

- 🔴 **문 고르기가 조립 계획이 된다.** 문 위 아이콘이 보이므로 *"지금 내 마법진에 확산이 없으니 저 문"*이 성립한다.
  **이번 사이클에서 이미 성립한다** — 끼우는 자리가 마을이라 한 박자 늦을 뿐, **고르는 근거는 던전 안에 있다.**
- 🔴 **템포가 폐기 사유였고, 이 조각이 그 넷을 정면으로 친다**(`genre_pivot` D2 — 아픈 곳은 **오직 템포 하나**였다):

  | 실측된 느림의 출처 | 이 사이클이 하는 것 |
  |---|---|
  | 시야 부채꼴 100° + 주변시 110 (앞이 안 보여 천천히 간다) | **지운다**(R3) |
  | 2400×2200을 걸어서 훑는다 | **방 ~1600×1000**(R2) |
  | 낱개 드롭을 걸어가 줍는다(세101에 **일부러** 만든 무방비 시간) | **상자 하나**(R5) |
  | 3초 꾹 탈출 | **걷는다**(R1) |

- ⚠ **안 건드리는 것도 근거가 있다** — `bag_lost`·긴장 장치는 `genre_pivot` D2가 *"아프다고 하지 않았다"*로 못 박았다.

> 🔴 줄마다 **사용자 발언 근거**를 붙인다(하드 게이트 ②). 근거가 「선택지 선택」인 줄은 그렇게 표기했다.

| # | 결정 | 사용자 발언 근거 |
|---|---|---|
| **R1** | **첫 조각 = 걷어내기 + 방을 문으로 잇기.** 시야·인지·탈출 홀드·출구 여럿·챕터 선택·지점을 걷고, 그 자리에 방 연결을 세운다 | 선택지 「걷어내기 + 방 둘을 문으로 잇기 (추천)」 선택 |
| **R2** | **방 크기 = 화면 1.5~2배(≈1600×1000) · 카메라 추적** | 선택지 「화면 1.5~2배」 선택 |
| **R3** | 🔴 **시야·인지를 코드째 지운다** — 스위치로 끄지 않는다 | 선택지 「전부 지운다」 선택 |
| **R4** | **한 판 = 방 5~6개** | *"방 5~6개 이고"* |
| **R5** | **방 보상 = 방 가운데 상자 하나.** 마지막 적이 죽으면 뜨고 [E]로 연다 | 선택지 「방 가운데 상자 하나 (추천)」 선택 + 세66 뒤집기 *"쏟아지지말고 상자단위면 좋겠는데"* |
| **R6** | **문 2~3개 + 보상 아이콘까지 이번에 만든다**(문 프롭 그림 + 보상 아이콘) | 선택지 「문 2~3개 + 아이콘까지」 선택 |

| **R8** | 🔴 **네임드(`hound_alpha`)를 이번 사이클에서 뺀다** — 위상을 몬스터 카탈로그 사이클에서 정한다 | 선택지 「이번엔 뺀다」 선택 (*"네임도쪽 다시 정하자 / 미니보스격인건가?"* 뒤) |
| **R9** | **마지막 방을 깨면 마을로 돌아간다.** 보스·챕터 연쇄는 이번에 안 한다 | 선택지 「마을로 돌아간다 (추천)」 선택 |
| **R10** | 🔴 **「마법 소리 = 위력」(`_on_cast_heard`)도 인지와 같이 죽인다** | 선택지 「같이 죽인다 (추천)」 선택 — architect가 *"§5 표에 없는데 같이 죽는다"*로 올린 뒤 |
| **R11** | 🔴 **상자를 열면 낱개가 흩어지지 않고 바로 가방에 들어온다.** 세46 「순간이동 드롭」 각하를 뒤집는다 | 선택지 「바로 가방으로」 선택 |

🔴🔴 **R11은 「근거가 사라진 각하」를 뒤집은 것이다.** 세46이 그것을 각하한 이유는 *"익스트랙션의 스테이크스"*였고
**그 장르가 세110에 폐기됐다**(`genre_pivot` D1). ⇒ **되살리려면 그 장르가 돌아와야 한다** — 「세46이 각하했다」만 보고 되돌리지 마라.

#### R8에 딸린 실측 — 「네임드 고유 행동 = 돌진」은 취소됐다

세션 중 리드가 **「고유 행동 하나 → 돌진」**까지 받았으나, 그 직후 실측에서 **전제가 무너졌다**:

| | `hound` | `hound_alpha` |
|---|---|---|
| `ai` | `charge` | 🔴 **`charge` — 같다** |
| HP | 26 | 140 (5.4배) |
| `charge_speed` | 330 | 380 |
| `charge_trigger_range` | 120 | 160 |
| 스프라이트 | `hound.png` | ⚠ 같은 그림에 **보라 tint만**(세102 지적) |

⇒ **돌진은 이미 둘 다 갖고 있다.** 네임드를 구별하는 것은 **HP·크기·tint·드롭** 넷뿐이고 **전부 스칼라**라
세43 진단(*"축이 세기만 바꾸면 재미가 없다"*)에 정면으로 걸려 있다. 사용자가 이 실측을 받고 **R8(뺀다)**을 골랐다.

🔴 **이 표를 지우지 마라** — 네임드 위상을 다시 정할 때 출발점이 이것이다.

#### 5-2. 방 전환 = 같은 씬 안 재배치 (architect 판정)

🔴🔴 **씬 교체를 고르면 방마다 만HP/만마나가 된다.** `boss_room.gd _ready` 첫 세 줄이
`reset_player_hp()`·`restore_mana_full()`·`in_expedition = true`고, `takbon-rules` §2가 이걸 **「출격 = 만HP/만마나」의 단일 소스**로 못 박았다
⇒ **방을 넘을 때마다 완전 회복**이라 「방을 이어서 깬다」의 소모가 통째로 사라지는데 **에러가 0이다.**
덧붙여 `change_scene_to_file`은 인자를 못 실어 **GameState 신설 3~4개(= core)**가 붙고 §6의 「세이브 무변경」 약속이 깨진다.
그리고 방마다 씬 로드 = **판당 5~6번 히치** — 폐기 사유가 템포였는데 **측정 대상 위에 잡음을 심는다.**

✅ **재배치의 유일한 비용(teardown)은 이미 그룹으로 다 잡혀 있다**:
`enemies`·`props`·`landmarks`·`drop_pickups`·`enemy_projectiles`·`player_projectiles`·`blasts`·`pillars`·`interact_zones`.

🔴 **재배치가 밟을 자리 넷 — 전부 에러 0**:
1. 🔴🔴 **teardown·rebuild 전체가 `call_deferred`여야 한다** — 방아쇠가 「마지막 적 사망」이라 **물리 flush 한복판**이다(↓ §6).
2. `_spawn_props`가 `add_child(holder)`를 해서 **재호출하면 `Props` 홀더가 방마다 쌓인다.** ⚠ `_tree_holder`는 **씬 노드라 free하지 말고 자식만 비워라.**
3. `_cleared`는 방마다 리셋한다. ⚠ **`_leaving`은 판 전체 수명으로 남겨라**(귀환·사망 이중 전환 가드).
4. 🔴 **`_ready`를 `_enter_room(idx, tag)`로 쪼갤 때 「판 1회」와 「방마다」를 갈라라** — 왼쪽을 오른쪽으로 흘리는 순간 위 사고가 재배치안에서도 그대로 난다:

| 판 1회(`_ready`) | 방마다(`_enter_room`) |
|---|---|
| 🔴 `reset_player_hp` · `restore_mana_full` · `in_expedition` | `_fill_tiles` · `_spawn_props` · `_spawn_mobs` |
| `_chapter` 해석 · `_apply_chapter_tint` · caster 배선 · EventBus connect | Player 자리 · 목표 줄 · Chest/Door 정리 · `_cleared = false` |
