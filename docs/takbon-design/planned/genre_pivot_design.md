## §A 게임 기획

### 1. 무엇을 · 왜

**익스트랙션 로그라이트(세35)를 폐기하고, 방을 이어서 깨는 마법 액션 로그라이크로 간다.**

폐기 사유는 **오직 하나 — 템포다.** 라운드 1에서 넷을 놓고 물었을 때 사용자가 고른 것은 「템포가 느리다」 하나뿐이었고,
🔴 **나머지 셋을 안 고른 것이 그만큼 중요한 정보다**:

| 안 고른 것 | 그래서 아는 것 |
|---|---|
| 「죽으면 다 잃는 게 스트레스」 | `bag_lost`는 아프지 않았다 → **긴장 장치 자체는 문제가 아니다** |
| 「싸우는 게 손해다」 | 탈출이 목표라 전투를 피하게 되는 것도 아니었다 |
| 「돌아와야 쓴다가 답답」 | 마을↔던전 왕복의 **길이**도 아니었다 |

⇒ 🔴 **아픈 곳은 루프의 구조가 아니라 「던전 안에서 걷는 리듬」이었다.** 실측한 느림의 출처 넷:
시야 부채꼴 100°+주변시 110(앞이 안 보이니 천천히 간다) · 2400×2200을 걸어서 훑는다 ·
낱개 드롭을 걸어가 줍는다(세101에 **일부러** 만든 무방비 시간) · 3초 꾹 탈출.

### 2. 플레이어가 겪는 것

```

                ↑ 이번 판의 「무기」 (세피리아의 무기 6종 자리)

【런】
  [방1] 적을 다 쓴다 → 문이 2~3개 열린다
          ┌─[🔥 불 문양]
          ├─[⚒ 강화]      ← 보상이 문 위에 미리 보인다. 골라서 들어간다
          └─[💀 위험·큰보상]
  [방2] … 주운 문양을 그 자리에서 마법진에 끼운다 → 마법이 바로 달라진다
  [보스] 챕터1 보스 → 🔴 마을로 안 돌아간다. 바로 챕터2로

```

### 3. 왜 재밌나 (탁본 잣대)

**잣대 = "조립의 선택지가 늘어나나 / 다르게 조립하면 전투가 종류로 달라지나"**(GDD §2).

- 🔴 **조립이 던전 안으로 들어온다.** 지금은 조립(코어 재미)이 마을 책상에만 있고 던전은 순수 소비인데,
  이 전환 뒤엔 **방을 깰 때마다 마법진이 한 칸씩 자란다** — 「조립을 잘한 게 화면에 보이나」가 **한 판 안에서** 계속 회수된다.
- 🔴 **문 고르기 = 조립 계획 세우기.** 보상이 문 위에 미리 보이므로 *"지금 내 마법진에 확산이 없으니 저 문"*이 된다.
  선택지가 늘어나는 게 아니라 **선택 자체가 게임 루프가 된다.**
- 🔴 **진행 = 어휘 개방**이라 `takbon-design`이 경고한 *"조립이 유일한 재미 축이라 부품 어휘가 얇으면 곧 얕아진다 —
  어휘 확장이 최우선 기획 축"*을 **진행 시스템이 직접 떠맡는다.** 챕터를 깰 때마다 조립 어휘가 넓어진다.

**참조작 = 세피리아**(TEAM HORAY · 던그리드 개발사 · 스팀 압도적 긍정 96%). 그 게임의 심장인
「인벤토리 공간 배치 퍼즐」(아티팩트 + **석판이 놓인 자리 기준으로 주변 아티팩트 레벨을 올리거나 내린다** ·
좋은 효과일수록 배치 제약이 빡세다)은 **탁본의 마법진 조립과 같은 물건**이다 —
탁본엔 이미 **층(밴드) = 연산 순서 · 감싸기(동심) = 연산 순서**라는 공간 규칙이 있다(GDD §5).

### 6. 계약 · 회귀 위험

- 🔴🔴 **발사 계약은 안 건드린다.** 조립 결과가 `to_assembly()`로 흐르는 경로는 그대로다 —
  바뀌는 건 **조립을 어디서 하나**뿐이다(`takbon-rules` §3 계약 무변경).
- 🔴 **`is_unlocked(&"")` 함정이 D7의 급소다.** 스키마가 *"빈 값 = 항상 보유"*라 규약하는데
  `is_unlocked(&"")`는 false다 → 빈 키 고리가 생기면 **개방이 도달 불가**가 되고 **에러 0**이다(세95 실측).
- ❌ ~~**엔딩 조건이 D7로 비로소 성립한다.** 기념비의 *"되찾은 문양만큼 불이 든다"* = **개방된 문양 종류 수**.
  세101이 캔 *"문양엔 해금 게이트가 없어 「전종 회수」의 잴 대상이 0이었다"*가 여기서 해소된다.~~

  기념비를 채우는 것은 **문양이 아니라 챕터마다 주는 「마법문 조각」**이고 **개수는 미정**이다.
  ⚠ **D7 자체는 안 죽는다** — 「진행 = 어휘 종류 개방」은 그대로다. 죽은 것은 **그것을 분모로 재활용하려던 안**뿐이다.
  ⇒ 기념비의 실소유자는 `gate_restoration_design.md`(봉납 창구·진행도 UI) 하나다.
- ⚠ **세이브 계약**: D7의 개방 상태가 새 저장 항목이다. D10(죽으면 처음부터)이라 **런 상태는 저장 안 해도 된다.**

  (특히 **대사 줄이 비는 경로에서 마을 밖으로 못 나가는 소프트락**). **뺄 때도 그 표 ⓐ~ⓓ를 보고 빼라.**

2. **걷어내기만** — 가장 작다. 「템포가 얼마나 달라지나」를 먼저 재고 방 크기를 그 답으로 정한다
3. **던전 안 조립부터** — 코어 재미를 먼저. ⚠ 방이 없으면 「방마다 하나씩 자란다」 리듬을 못 재본다

🔴 **한 사이클에 다 하지 마라.** 조각마다 `takbon-design` → architect → 구현 → F5를 돈다.
