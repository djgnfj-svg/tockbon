- **방향**: 48px·소프트 도트·세69 입체(망토가 거의 순검정이라 림 절제). 다프레임이라 aseprite `run_lua_script`.

## 🔴 핵심 연출 = 망토 "펄럭임" (사용자의 진짜 목표)

🔴 **반응형이다** — idle 잔잔한 흔들림이 아니라 **이동·마법 시전 시 망토/후드가 확 펄럭이는** 것(사용자 확정). 스타일리시 전투의 핵심.
- **실루엣 = 긴 흐르는 망토/케이프** (사용자 확정) — 뒤·옆으로 흐르고 밑단이 넓게 펄럭. 다리·발은 앞쪽 밑단으로 살짝. (1차 짧은 스커트+뜬 부츠 = "하반신 이상함"으로 반려.)
- **두 방식을 F5로 비교** 후 채택:
  - **셰이더 방식** (takbon-shader, ⭐반응형에 더 맞음): canvas_item 셰이더가 **플레이어 속도를 uniform으로 받아** 망토 파형 진폭·방향을 키우고, 시전 시 펄스로 확 펄럭. 세63 히트플래시 셰이더 선례(material per-instance).
  - **애니 방식** (takbon-art): 망토 펄럭 프레임을 직접 그림(걷기·시전 flare). 셰이더 없이 확실하지만 반응형(속도 비례)이 어렵고 프레임↑.
- 손맛(어느 쪽이 더 "펄럭이나")은 헤드리스로 못 잰다 → **F5 비교로만** 정한다.
- ⚠ 채택안이 셰이더면 sprite에 ShaderMaterial(per-instance) + player 속도/시전을 uniform으로 넘기는 배선 = 소폭 코드/씬 변경. 애니면 SpriteFrames에 애니 추가 + 상태 전이.
