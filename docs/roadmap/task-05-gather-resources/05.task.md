## What is on screen when this task ends

**부대를 캐러 보내면 나무·돌·철·물고기가 들어오고, 밭에 심은 것이 자란다.**

## Which line it moves

**「부대를 조종하고 지어서 몬스터를 잡는 게임」의 「지어서」.** 캐기 전에는 지을 것이 없다.

## ✅ 정해진 것

| 무엇 | 정해진 것 |
|---|---|
| **누가 캐나** | **병사가 캔다** — 일꾼은 따로 없다 |
| **몸이 갈리나** | **NO — 몸은 한 종류다.** 손에 든 것과 특성이 무엇을 잘하나를 정한다 |
| **요리를 누가 하나** | **건물.** ⚠ 요리사라는 몸은 없다 — 요리사는 특성이다 |
| **작물 수** | **둘** — 감자와 밀 |
| **농사의 값** | **자리 AND 시간.** 둘 다지 하나가 아니다 |
| **농사의 단계** | **밭 만들기 → 밭 매기 → 심기 → 물 주기 → 자람** |
| **밭의 크기** | **블록 하나** — 고원에 11 개, 1층에 59 개가 들어간다 |
| **물 긷기** | **우물을 지으면 없어진다.** 비가 오면 그동안 공짜다 — ⚠ 비는 안 정해졌다 |
| **Bad North** | **안 베낀다.** ⚠ Bad North 에는 채집이 아예 없다 — 실측 |

⚠⚠ **요리가 있어야 둘째 작물을 심을 이유가 생긴다.** 요리가 없으면 농사는 올라가는 숫자일 뿐이고, 그것은
식량이 한 번 잘렸던 이유다.
⚠ **우물은 여섯째 건물이다** — 용어집의 다섯(성채·집·탑·창고·성벽)에 없다.
