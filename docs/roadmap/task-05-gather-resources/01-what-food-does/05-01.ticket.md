## ⚠⚠ Why this is a decision and not a build

**Nothing about the link exists.** `src/sim/` returns **zero hits** for 나무 · 돌 · 철 · 식량 · 채집,
and 「부대」 is not there either. **There is no number to attach a buff to and no place to put it.**

**And a 몸's numbers are a single row in a table**: `UNITS` gives 검사 its HP, damage, period, range and
speed, and **a 몸's type is data, not a type in code.** ⇒ **Whatever food does, it does it by moving one
of those five, or by adding a sixth column.** Which one changes what the game plays like:

- **체력** — 오래 버틴다
- **공격력** — ⚠ 지금 damage 5.0 과 period 2.4 는 초당 2.083 으로 **일부러 맞춰 둔 값이다.** 하나만 건드리면 그 균형이 깨진다
- **수** — ⚠⚠ **강화는 병사 수를 늘리는 쪽이라고 2026-08-30 에 이미 정해져 있다** (등급을 물리면서)
