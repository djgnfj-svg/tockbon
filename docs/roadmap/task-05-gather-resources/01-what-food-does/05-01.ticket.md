## ⚠⚠ Why this is a decision and not a build

**Nothing about the link exists.** `src/sim/` returns **zero hits** for 나무 · 돌 · 철 · 식량 · 채집,
and 「부대」 is not there either. **There is no number to attach a buff to and no place to put it.**

**And a 몸's numbers are a single row in a table**: `UNITS` gives 검사 its HP, damage, period, range and
speed, and **a 몸's type is data, not a type in code.** ⇒ **Whatever food does, it does it by moving one
of those five, or by adding a sixth column.** Which one changes what the game plays like:

- **체력** — 오래 버틴다
- **공격력** — ⚠ 지금 damage 5.0 과 period 2.4 는 초당 2.083 으로 **일부러 맞춰 둔 값이다.** 하나만 건드리면 그 균형이 깨진다

## ⚠⚠ Added 2026-09-01 — **the question got sharper and the food got a source**

**⚠ The ticket was called 「낚시가 병사를 어떻게 세게 하나」 until this round.** It was renamed because
**food no longer comes only from fish** — 농사 came back beside 낚시, and **요리 is now what food passes
through.** The file name never moves; only `Name:` did.

### What is settled around it now

- **요리가 농사의 이유다** — *"With just one dish you actually do not need to farm a variety."* ⇒ **cooking
  is what makes a second crop worth planting**, and whatever eating does, **a cooked dish is what does it**
- **작물은 둘** · **요리는 건물이 한다** · **요리사는 특성이지 몸이 아니다**
- **병사와 일꾼을 안 가른다** — ⚠⚠ **the question this ticket flagged as blocking is ANSWERED.** One body
  gathers and fights, so a body out gathering is a body not defending, and feeding has a price to sit on
- **주인공은 없다** — every body is its own character and grows in its own direction

### 🔍 The socket, measured this round

**뽑기 already runs and TIME is its whole price**: `MUSTER_PERIOD_SEC := 20.0` turns out one 검사, and
`MUSTER_CAP := 9` is the ceiling. **`rules.gd` says it on the line** — *「나무·돌·철·식량 appear nowhere in
the sim, so there is nothing else to spend, and a resource cost is task 05」*.

⇒ **There is exactly one empty socket in the repository that a resource cost drops into**, and it is
this one. ⚠ **`Battle.elapsed` and `muster_left` both run**, so a time-shaped answer also has somewhere
to attach.
