## What this ticket builds
**A net can go missing from a round without the round saying so.** 이 티켓은 그것을 재고, 그중 막을 수
있는 구멍 하나를 막는다.

## 무엇을 봤나
**전체 라운드 셋 중 하나에서 `net_hand` 프로세스가 시작하다 죽었다.**

| 무엇 | 숫자 |
|---|---|
| 죽은 것 | **프로세스**, 시작할 때 — 안의 검사가 아니다 |
| 종료 코드 | **-1066598273** = `0xC06D007F`. ⚠ **디코딩 안 했고 추측도 안 한다** |
| stdout | **75 바이트** — 엔진 배너뿐 |
| stderr | **0 바이트** — 내려가면서 아무 소리도 안 냈다 |
| 라운드 총계 | **91 이 사라졌고, 그것이 `net_hand` 전부다** |
| 혼자 돌리면 | **초록, 통과 91** |

⚠ **`net_hand` 은 트리를 안 건드리고 프레임도 안 돌린다.** 무엇이 죽였든 넷은 시작도 안 했다.
⚠⚠ **같은 모양이 다른 넷 둘에서도 나왔다** — 특정 넷의 결함이 아니라 어느 프로세스에나 걸리는 사고다.
**남은 단서 하나는 열여섯 프로세스가 `.godot/` 캐시 하나를 같이 읽고 쓰는 것이다.** 단서지 결론이 아니다.

## 프로세스가 죽었을 때 러너가 하는 것 — **모양 셋**
| 모양 | 라운드가 하는 것 | 잡히나 |
|---|---|---|
| **0 아닌 코드로 죽는다** | 빨간 줄, 래퍼 종료 1. ⚠ 다만 **실패 칸에 0 을 더하고 통과에서 제 몫을 통째로 뺀다** | 빨강으로는 yes, 숫자로는 no |
| **0 으로 끝나면서 아무것도 안 찍는다** | 통과 0 · 실패 0 · 소음 없음 · 시간 초과 아님 ⇒ **회색 줄과 초록 래퍼** | ⚠⚠ **막았다** |
| **파일이 스캔에서 빠진다** (이름 바뀜 · 삭제) | 폴더 스캔이 하나 덜 셀 뿐. 유일한 경비는 **「넷 파일이 다섯 미만」** 인데 지금 스물다섯이다 | ⚠⚠ **NO, 그냥 뒀다** |

**모양 1 은 일부러 그대로 뒀다** — 검사를 하나도 안 돌린 넷에 실패 수를 지어내면 아무도 안 잰 숫자가
실패 칸에 앉는다.
**모양 3 도 그대로 뒀다** — 바닥값 5 를 16 쪽으로 올리면 넷 하나를 얻고 아무도 안 옮길 숫자를 남긴다.

### 모양 2 를 막은 방법
- **판정은 「검사를 하나도 안 돌렸다」다**, 러너 제 요약줄의 검사 총수로 읽는다
- ⚠ **「`[net]` 줄이 없다」가 아니다** — 요약줄은 끝까지 간 모든 경로에서 찍히고, 이 저장소가 실제로
  당했던 사고는 `[net] 0 passed` 를 **종료 코드 0 으로** 찍었다
- ⚠ **통과 수도 아니다** — 검사가 전부 실패한 넷도 통과 0 이고, 그것을 「안 돌렸다」로 빨갛게 하면
  라벨이 거짓말이 된다
- ⚠⚠ **`-Serial` 에서는 배치 단위로만 걸린다** — 한 프로세스가 배치 전체를 돌고 요약을 하나만 찍어서,
  배치 안에서 넷 하나가 사라지는 것은 안 보인다. **실측: 넷 둘을 한 프로세스에 넣고 하나의 클래스를
  못 찾게 했더니 `[net] 21 passed` 를 종료 코드 0 으로 찍었고 91 개가 조용히 사라졌다**
- **실패 칸은 안 건드린다** — 줄만 빨개지고 이유가 그 줄에 찍힌다
