**Four things are looked at.**

**1 — On screen, in the running game.** W held pans north and keeps panning for as long as it is held;
the four keys make eight directions; the pointer in the bottom 28 px pans south and stops the moment
it leaves the band; **nothing moves while the window is alt-tabbed away.**

**2 — The five rows the deleted net's own tombstone specifies**, rebuilt in `net_shell`:

- the camera keeps moving **across frames** from one press, not one step per event
- the **release** stops it
- an OS auto-repeat **echo adds no second direction**
- **two keys held make a diagonal**, and letting one go leaves the other running
- a key **held into the roam ring stops at the bound** instead of running out to sea

⚠⚠ **`_key_edge` has to be rebuilt before a single one of those can be written.** `net_shell`'s `_key`
builds `pressed = true` and nothing else — **no release edge and no `echo` flag** — so a WASD row
written against it measures the press half and stays green over a camera that never stops.

**3 — One frame, one `pan_by`.** A row that holds a key AND parks the pointer in the band, and reads
the frame's travel as **one** summed velocity rather than 1800 px/sec.

**4 — `tools/look/capture_boat.gd` reads `Look.CAM_PAN_KEY_PX_PER_SEC`**, and the repo holds **one** 900.
