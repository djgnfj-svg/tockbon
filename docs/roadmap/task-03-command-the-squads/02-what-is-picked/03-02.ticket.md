## What stands in the code
- **`Names.LIST`** — 옛 한국 이름 마흔, 겹치지 않게 뽑아 `Army.names` 에 붙는다
- **`Army.aptitudes`** — 몸마다 다섯, 태어날 때 0~3, 군대가 가진 RNG 로
- **`Army.hunger`** — 100 에서 시작하고 **아직 아무것도 안 깎는다** (05-07)
- **`Run.seed`** — 판이 열릴 때 뽑고 시작 넷보다 먼저 심는다. ⚠ **08-01 이 이것을 읽는다, 새로 안 뽑는다**
- **`Rules.defense_of`** — 모든 몸에 0.0

⚠ **아무 규칙도 적성과 방어력을 아직 안 읽는다.** 판은 저장된 값을 그대로 찍는다.
