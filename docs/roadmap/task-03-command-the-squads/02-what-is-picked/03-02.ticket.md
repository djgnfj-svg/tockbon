### What `net_panel.gd` measures

- `Names.LIST.size() == 40`, no duplicate, every entry two Hangul syllables.
- `Names.next([])` is `LIST[0]`; forty calls feeding back the taken list yield forty different names; the

  `names.size() == type_id.size()` after both.
- **Treed**: a `PanelSpy extends HudView` overriding `_paint_panel` / `_paint_line` to record arguments,
  `bind(battle)`, `set_picked([])`, `pump_frames` → zero paints. `set_picked([id])` → one `_paint_panel`
  and exactly four `_paint_line`; line 0 text is `"이름 " + army.name_of(id)`; line 2 is
  `"체력 %d/%d"` with the battle's live hp; lines 1 and 3 are the bare labels.

- `set_picked([id])` on two consecutive frames with `battle.soldier_hp[id]` lowered between them → the
  second frame's line 2 carries the lower number (the panel follows the fight, not the pick).
- `bind(other_battle)` after a pick → the next frame paints nothing until `set_picked` is called again.
- The loaded `PANEL_TEX` has size `Look.PANEL_SIZE_PX`; every recorded baseline lies inside
  `Rect2(Vector2.ZERO, Look.viewport_size_px())` and inside the plate's rect; the plate's origin equals
  `Look.panel_origin_px(Look.PANEL_SIZE_PX)` and each line's `at` equals
  `Look.panel_line_baseline_px(origin, i, font.get_ascent(Look.PANEL_FONT_PX))` (hook argument vs pure
  function); each `_paint_line` carries `size_px == Look.PANEL_FONT_PX` and `col == Look.COL_PANEL_TEXT`.
- Mutations the net must catch: `_paint_line` body emptied → the `net_draw_leaf` row goes red; the shell
  never calling `set_picked` → the treed `Game._ready()` + one `_process` frame with a filled hand paints
