### The sim half — exactly what `hand.gd` becomes

**`_build_reach(battle)`**

```
var n := grid.w * grid.h
var seen_all := PackedByteArray(); seen_all.resize(n); seen_all.fill(1)
for k in ids.size():
    var t := _tile_of(battle, int(ids[k]))
    var seen := _flood_from(grid, t)          # today's BFS, cut out whole; t < 0 → all zeros
    for i in n: if seen[i] == 0: seen_all[i] = 0
# then today's filter: _standable over seen_all == 1 → reach, _in_reach, reach_blocks, _in_reach_block
```

- `_flood_from(grid: Grid, seed: int) -> PackedByteArray` is today's loop body — the 8-way `can_step`
  BFS from one seed — returning the `seen` array. **A seed of -1 returns all zeros**, so a body off the
  board empties the 부대's reach (it cannot happen after `pick_many`'s ASHORE filter; it is the guard).
- ⚠ **Per-body floods, NOT a 「same component」 test from one flood.** `Grid.can_step` reads the
  shoulders at the FROM level on a diagonal, so it is not symmetric across a level change; two bodies
  can each reach a 조각 the other cannot. Nine floods once at pick is the price, and it is paid once.
- **`_standable`, `_seats`, `_walk_holds`, `routes`, `order` are untouched.** `_walk_holds` reads
