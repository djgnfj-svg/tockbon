## Done when

- 몸을 누르면 그 몸이 골라지고, 다른 몸이 대신 답하지 않는다

- 회전하고 확대·축소해도 선이 몸의 발에서 나오고 굵기가 읽힌다

### ⚠⚠ 검사가 초록인 채로 틀려 있던 것 넷

**이 티켓이 남기는 값의 절반이 이것이다.**

1. **판이 바닥 자국을 통째로 가리고 있었다** — 깊이가 아니라 투명 정렬. **판이 켜지면 몸 그림자까지
   사라졌다.** 자국을 반 조각 띄워도 소용없었고 `render_priority` 만이 정한다
2. **셰이더가 `ALPHA` 를 쓰면 반투명 경로로 가서 불투명 스프라이트 뒤에 아무것도 안 그린다** —
   스프라이트의 값이 전부 맞는데 화면에만 없었다
3. **이동선 첫 점과 나머지가 반 조각 어긋나 있었다** — 모든 검사가 「어느 조각」만 묻고 「세계 어디」를
   안 물어서 아무도 안 잡았다. **사용자가 화면에서 잡았다**
4. **고르기와 명령이 만나는 자리를 아무도 안 쟀다** — 몸이 선 조각을 누르면 몸 판정이 누름을 먹었다

⇒ **넷 열다섯 줄이 그 빈 자리에 들어갔다.**

### ⚠⚠ 사용자가 봤다 — 다섯 번 켜서 직접 만졌다

**이 티켓의 모든 뒤집힘이 화면에서 나왔다.** 넷이 아니라 눈이 잡았다.

| 언제 | 사용자의 말 | 무엇이 됐나 |
|---|---|---|
| 처음 | *"When you press a character it gets selected and its information comes up and then it moves ... And it only moves when you press TAB."* | 고르기가 생겼다. ⚠ TAB 은 이미 있던 판 보기 키였다 |
| 그다음 | *"Without tab — you just press a character and the 칸 it can move to light up ... And I'd like the movement line to show beforehand."* | TAB 이 빠지고 이동선이 생겼다 |
| | *"Work on it so it's extensible, so what's selected can be a character or a group ... because later a group will be treated as one."* | 고른 것이 목록이 됐다 |
| 켜 보고 | *"When it moves, then the move-related stuff should turn off."* · *"Does ESC cancel the selection?"* | 명령하면 놓고, ESC 가 생겼다 |
| 켜 보고 | *"When you press a character, a slight white outline on the one I pressed — it has to be obvious which one I pressed."* | 흰 테두리가 생겼다 |
| 켜 보고 | *"You can move onto a 조각, right? Onto the same 조각? That's a little awkward. Unless I press ESC it should be movement-first."* | 쥐면 이동이 우선이 됐다 |
| 켜 보고 | *"It seems a bit odd when I rotate ... it looks like it comes from the middle of the block. The mouse wheel can go down as well as up, so that always has to be considered."* | 반 조각 어긋남·무리 오프셋·줌 굵기 셋이 고쳐졌다 |
| 끝에 | ***"This is good enough."*** | **합격** |

⚠ **인용은 영어로 옮겼다** — `CLAUDE.md` 의 규칙이다. 한국어 원문은 결정 로그에도 안 남는다.

**어떻게 다시 보나** : 게임을 켜고 섬이 열리면 **섬에 선 몸을 누른다.** 흰 테두리와 켜진 판이 보여야
하고, 커서를 옮기면 이동선이 따라와야 한다. **켜진 조각을 누르면 그리로 걸어가고 판이 꺼진다. ESC 는
아무것도 안 하고 손만 놓는다.**
