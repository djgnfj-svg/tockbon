# Task 08 — 섬이 판마다 새로 생성된다

## What is on screen when this task ends

**새 판을 열면 지난 판과 다른 섬이 뜬다.** 걸을 수 있고, 계단이 서 있고, 성채가 고원 위에 해안에서 3 칸
떨어져 서 있고, 나무 칸·돌 칸·철광석 칸이 보이고, 눈으로 봐서 손으로 그린 것과 구별되지 않는다.

## Which line it moves

**로그라이크의 「매번 다르다」가 이 게임에 아직 하나도 없다.** 섬이 하나고, 그 하나가 파일이라 **모든
회차가 같은 땅에서 벌어진다.** 12 월이 얼리액세스 출시로 바뀌면서 「판이 점점 세지는 것」이 얇은 다섯에
들어갔는데, **같은 섬 위에서 적만 늘리는 것은 그 다섯 중 하나를 절반만 하는 것이다.**

## ⚠⚠ 왜 이것이 큰 태스크인가 — **섬은 지금 코드가 아니라 파일이다**

**`tools/blender/island_build.py` 한 번이 둘을 같이 쓴다** — 게임이 그리는 `island.glb` 와 게임이 걷는
`island.json`. **둘은 어긋날 수 없다. 하나만 쓰는 것이 없기 때문이다.**
⇒ **판마다 새로 만든다는 것은 이 관계를 끊는다는 뜻이다.** 블렌더는 게임이 도는 동안 안 돈다.

⚠⚠ **그런데 길이 이미 반쯤 나 있다.** 2026-08-29 에 **섬이 조립식이 됐다** — 열린 변으로 갈리는 여섯
종을 층마다, **부품 열두 벌**이 `assets/terrain/pieces.glb` 에 따로 서 있고 섬은 그 부품으로 세운다.
**부품이 이미 파일이면, 판마다 바뀌는 것은 배치지 메시가 아니다.**

## ✅ 정해진 것 — 2026-09-02, 사용자가 답했다

**전부 08-01 티켓에 사용자 말 그대로 적혀 있다.** 여기는 줄 하나씩이다.

- **윤곽 · 나무 · 돌 · 성채 자리가 판마다 다 바뀐다**
- **첫 판부터 생성한다.** 손으로 그린 섬은 잣대와 검사용 파일로만 남는다
- **크기는 판마다 같다.** 지금보다 넓고, 몇 칸인지는 태스크 06 의 숫자다
- **시드를 둔다.** 규약은 고정이고 시드가 그 안에서 하나를 고른다
- **성채는 고원 위, 모든 변에서 3 칸 이상**
- **항구는 없다.** 짐승은 아무 변에서나 온다 — ✅ **배는 이미 그렇게 뜬다**, 섬 파일의 `H` 는 테두리 글자일 뿐이다
- **자원은 칸이다** — 나무 칸 1~3 · 돌 칸 1~3 · 철광석 칸 1~2, 섬에 붙고, 막히고, 옆에서 캔다
- **계단 1~3 · 고원 1~2 · 모든 고원에 계단**

⚠ **뒤집힌 것 둘** — 철광석이 「떨어진 블록에 하나」에서 「섬 위에 1~2」로 (티켓 05-06 이 이것으로
녹았다), 그리고 용어집의 「섬에 하나」.
