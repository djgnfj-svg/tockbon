## What this ticket builds

**An island that is different every run, walkable, and that nobody drew.**

⚠⚠ **`Type: grilling` and not `task`** — **what「different」 means has not been decided**, and a
generator built before that answer builds the wrong island. **This ticket asks first.**

### Where it came from

> The user, 2026-09-02: ***"And we need an algorithm where the map is always newly generated."***
> (「그리고 맵이 항상 새롭게 생성되는 알고리즘 필요함」)

### ⚠⚠ What stands in the way, read out of the code 2026-09-02

| What | Where | Why it matters |
|---|---|---|
| **The island is a FILE, not code** | `src/sim/islands.gd` — *"READ FROM A FILE, not written here"* | The letter grid was deleted from the game on 2026-08-26 **on purpose**, because the user is the one drawing islands |
| **One Blender run writes BOTH halves** | `tools/blender/island_build.py` → `island.glb` (drawn) + `island.json` (walked) | *"They cannot disagree, because nothing writes one without the other."* ⚠⚠ **Generating at runtime breaks exactly this guarantee** |
| **The mesh is 5 MB** | `assets/terrain/island.glb` | Baked ahead of time. **Blender does not run while the game does** |
| **But the island is already ASSEMBLED from parts** | `assets/terrain/pieces.glb`, 8 KB | 2026-08-29: six kinds split by open edge, per storey, **twelve sets**. ⇒ **what changes per run is the ARRANGEMENT, not the geometry** |

⇒ **The shape of the answer is: generate the letter board, then stand the existing parts on it.**
⚠ **This does not put the letter grid back into `islands.gd`** — that reversal was the user's and stands.
**A generator writes a board; it does not hard-code one.**

### ⚠⚠ What the generated board must satisfy — **these are not preferences**

- **Walkable as one piece.** ⚠ 03-14's first defect is measured proof that a split island seats bodies
  on ground they cannot reach — **a generator that makes two islands makes that bug every run**
- **A stair between every storey.** A body crosses **one notch** (`Rules.MAX_CLIMB_LEVELS` is 1), so a
  plateau with no stair is a plateau nobody reaches
- **Storeys are EVEN levels, stairs are ODD.** Writing the plateau as `1` breaks the island in silence —
  `islands.gd`'s own header carries this warning
- **A harbour** (`H`) the boats can sail from, or nothing lands
- **Two storeys and no third** (용어집: 「3층은 없다」)
- **The outline only bends by 칸**, never by 조각

### ⚠ What is NOT decided — **the user answers these before anything is built**

**What varies** — only the outline, or also the trees and rocks, or also where the 성채 stands.
**How much it varies** — a different outline at the same size, or the size too.
**Whether the drawn island survives** — the one standing now is the only island the user has approved by
eye (2026-08-30: 「이번 주에 하기로 했던 맵은 끝났어」). ⚠⚠ **A generator that replaces it throws away
the one thing on screen that passed.**
**Whether a run can be replayed** — a seed, or not.

## What is NOT in this ticket

- **The Blender pipeline.** `island_build.py` keeps writing the hand-drawn island
- **Raiding other islands.** A second island is a different subject
- **New part meshes.** This stands the twelve that exist

## Done when

- **The user opens two runs and sees two different islands**
- **Every generated board is one walking piece, with a stair to every storey and a harbour** — a net
  drives the generator with `.new()` and asserts this over hundreds of boards, not one
- **The user looks at a generated island and says it passes**, the same bar the drawn one had to clear
