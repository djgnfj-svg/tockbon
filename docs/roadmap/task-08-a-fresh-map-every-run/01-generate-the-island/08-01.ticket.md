### The user's own question, answered in the round

> ***"Is this a random seed? Or is it that some rules are set and it builds itself automatically?"***
> (「이게 랜덤 시드인가? 어느정도 규약을 정하고 자동으로 만들어지는건가?」)

**Both.** The rules below are fixed. The seed is one number, drawn when a run opens, that picks one island
among all the islands the rules allow. **The same number gives the same island**, which is what lets an
island that looked wrong on screen be brought back and fixed.

### ⚠⚠ What stands in the way, read out of the code 2026-09-02

| What | Where | Why it matters |
|---|---|---|
| **The island is a FILE, not code** | `src/sim/islands.gd` — *"READ FROM A FILE, not written here"* | The letter grid was deleted from the game on 2026-08-26 **on purpose**, because the user is the one drawing islands |
| **One Blender run writes BOTH halves** | `tools/blender/island_build.py` → `island.glb` (drawn) + `island.json` (walked) | *"They cannot disagree, because nothing writes one without the other."* ⚠⚠ **Generating at runtime breaks exactly this guarantee** |
| **The mesh is 5 MB** | `assets/terrain/island.glb` | Baked ahead of time. **Blender does not run while the game does** |
| **But the island is already ASSEMBLED from parts** | `assets/terrain/pieces.glb`, 8 KB | 2026-08-29: six kinds split by open edge, per storey, **twelve sets**. ⇒ **what changes per run is the ARRANGEMENT, not the geometry** |

⇒ **The shape of the answer is: generate the letter board from the seed, then stand the existing parts on it.**
⚠ **This does not put the letter grid back into `islands.gd`** — that reversal was the user's and stands.
**A generator writes a board; it does not hard-code one.**

### ⚠⚠ What the generated board must satisfy — **these are the rules the seed picks within**

- **Walkable as one piece.** ⚠ 03-14's first defect is measured proof that a split island seats bodies
  on ground they cannot reach — **a generator that makes two islands makes that bug every run**
- **1~2 plateaus, and a stair into every one of them.** A body crosses **one notch**
  (`Rules.MAX_CLIMB_LEVELS` is 1), so a plateau with no stair is a plateau nobody reaches
- **1~3 stairs in total**
- **Storeys are EVEN levels, stairs are ODD.** Writing the plateau as `1` breaks the island in silence —
  `islands.gd`'s own header carries this warning
- **Two storeys and no third** (용어집: 「3층은 없다」)
- **The outline only bends by 칸**, never by 조각
- **The 성채 stands on a plateau, at least 3 칸 from every coast**
- **Trees 1~3 · rocks 1~3 · ore 1~2 — as 칸, on the island, and each one blocks**
- **No harbour letter.** Beaches are whatever `beach_ring` finds
- **The same size every run.** The number is task 06's; until it is given, today's 71 칸 of land is the
  floor, not the target
