## 이 폴더가 놓인 모양

```
docs/roadmap/
  README.md                 ← 이 파일. 지도 그 자체
  log.md                    ← 왜 그렇게 됐나. 인용은 전부 여기
  task-01-<영문이름>/
    01.task.md              ← 이 태스크가 끝나면 화면에 뭐가 있나, 한 문장
    01-<영문이름>/           ← 티켓 하나 = 하루치. 폴더다
      01-01.ticket.md       ← 무엇을 짓나, 화면, 끝난 기준, 구현 계획, 답
      <스크린샷·측정값>       ← 이 티켓이 어떻게 됐는지 남은 것
    02-<영문이름>/
      01-02.ticket.md
  task-02-<영문이름>/
    02.task.md
    ...
```

- **태스크 폴더는 이 폴더 바로 밑에 선다.** ⚠ 사이에 `tasks/` 같은 칸을 하나 더 두지 않는다
- ⚠⚠ **파일 이름에 번호가 들어간다.** `TASK.md` · `TICKET.md` 로 두면 **열어 놓은 탭이 전부 같은 이름**이라 어느 태스크인지 분간이 안 된다
- ⚠⚠ **티켓도 폴더다.** `.ticket.md` 가 설명이고, **그 티켓이 어떻게 됐는지 남은 것은 같은 폴더에 쌓인다**
- **티켓은 자기 태스크 폴더 안에서만 살고**, 태스크마다 **`01` 부터 다시** 번호가 붙는다
- **티켓은 두 겹으로 부른다** — 태스크 `03` 의 둘째 티켓은 **03-02**. 「티켓 02」는 답이 아니다
- **파일 안에도 번호와 이름이 같이 적힌다** — 맨 위 제목과 `Ticket:` · `Name:` 줄
- ⚠⚠ **티켓 하나는 하루치다.** 하루에 안 끝나면 티켓 둘이고, **어디서 쪼갤지는 사용자가 정한다**
- **`task-00-example/` 은 형태일 뿐 일이 아니다.** 베끼되 짓지 않는다

**티켓 파일 맨 위가 그 티켓의 전부다**

```markdown
Ticket: 03-02           ← 두 겹 번호. 파일 이름과 같다
Name: 배가 남쪽에도 온다   ← 번호와 이름은 절대 떨어지지 않는다
Task: 03 — 짐승이 오고 싸운다
Type: grilling          ← grilling(결정) · task(작업)
Status: open            ← open · claimed · resolved
Blocked by: 01, 03      ← ⚠ 같은 태스크 안의 짧은 번호. 없으면 이 줄을 뺀다
```

⚠⚠ **파일은 폴더 사이를 옮겨 다니지 않는다.** 상태는 파일 안의 줄이다.
