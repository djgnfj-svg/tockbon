# 로드맵 — 12 월 얼리액세스 출시까지

**도착지** : 섬 하나를 지키는 한 판이 이기고 끝나고, 그 얇은 판을 12 월에 판다.

⚠⚠ **이 파일은 지금 참인 것만 담는다.** 지나간 라운드, 뒤집힌 결정, 누가 무슨 말을 했는지는 안 적는다.
끝난 티켓은 표의 ✅ 한 칸으로만 남고 파일은 지운다.

**상태 넷** : ✅ 끝남 · ⏳ 하는 중 · ⬜ 안 시작 · ⏸ 접힘

## 이 폴더가 놓인 모양

```
docs/roadmap/
  README.md                 ← 이 파일. 지도 그 자체
  task-03-<영문이름>/
    03.task.md              ← 이 태스크가 끝나면 화면에 뭐가 있나, 한 문장
    02-<영문이름>/           ← 티켓 하나. 폴더다
      03-02.ticket.md       ← 무엇을 짓나, 화면, 끝난 기준, 구현 계획
```

- **태스크 폴더는 이 폴더 바로 밑에 선다.** 사이에 `tasks/` 같은 칸을 하나 더 두지 않는다
- **파일 이름에 번호가 들어간다** — `TASK.md` 로 두면 열어 놓은 탭이 전부 같은 이름이다
- **티켓도 폴더다.** 스크린샷과 실측은 그 티켓이 열려 있는 동안만 거기 쌓인다
- **티켓은 두 겹으로 부른다** — 태스크 03 의 둘째 티켓은 **03-02**
- **티켓은 하루치가 아니다.** 주당 태스크 둘이고, 태스크 하나가 드는 티켓 수는 일이 정한다
- ⚠⚠ **티켓이 끝나면 폴더째 지운다.** 남기는 것은 위 표의 상태 칸 하나뿐이다
- **`task-00-example/` 은 형태일 뿐 일이 아니다**

**티켓 파일 맨 위가 그 티켓의 전부다**

```markdown
Ticket: 03-02
Name: 고른 것의 정보가 화면에 뜬다
Task: 03 — 부대를 조종한다
Type: grilling(결정) · task(작업)
Status: open · claimed · resolved
Blocked by: 01
```

⚠⚠ **파일은 폴더 사이를 옮겨 다니지 않는다.** 상태는 파일 안의 줄이다.
