## ✅ What is decided

- **Buildings are placed per 조각**, not per 칸
- **A barricade is a building the player can place**, and its job is to block the beasts' path
- **Beasts come from any side** (08-01, row 7), so blocking is where the player makes the choke point

## ⚠ What is NOT decided — **the user answers these before anything is built**

**Is it the 성벽?** The island file's `builds` knows five — 성채 · 집 · 탑 · 창고 · 성벽 — and only the 성채
stands. 「One of the buildable buildings」 does not say whether the barricade IS the wall or sits beside it.
**Does it block bodies too, or only beasts?** A wall that stops the player's own 부대 is a different game
from one that only stops wolves.
**Does it break?** If a beast can hit it, it has hit points and a 피격; if not, it is terrain.
**What does it cost?** Wood is the obvious answer and task 05 is where wood comes from — **placing before
gathering exists means it costs nothing that week.**
**What does it look like?** ⚠⚠ **Made, never typed** — Blender for the shape, and a 시안 round before it
stands.
