## What is on screen when this task ends

**플레이어가 조각 하나를 골라 그 위에 건물을 세우고, 바리케이트를 세우면 짐승이 그 조각으로 못 지나간다.**

## Which line it moves

**「부대를 조종하고 지어서 몬스터를 잡는 게임」의 「지어서」.** 지금 서 있는 건물은 성채 하나고 플레이어가
짓는 것은 없다. ⚠ **항구가 없어져서 짐승이 아무 변에서나 오는데** (08-01), 길목을 만드는 것이 이것이다 —
사용자: 「섬을 더 넓히고 바리게이트를 지어서 오는걸 막아야할듯」.

## ⚠⚠ 정해진 것 — 2026-09-02, 사용자 말 그대로

| 무엇 | 사용자 |
|---|---|
| **건물은 조각 단위로 짓는다** — 칸이 아니다 | 「내가 건물을 짓는건 조각단위로 해야할듯 ㅇㅇ」 |
| **바리케이트를 지어서 오는 것을 막는다** | 「바리게이트를 지어서 오는걸 막아야할듯」 |
| **바리케이트는 지을 수 있는 건물 중 하나다** | 「지을 수 있는 건물중에 하나일듯」 |

⚠ **「조각 단위」는 명령 단위와 어긋난다.** 명령은 2026-09-01 에 칸 단위가 됐고 (03-08), 자원도 칸이다
(08-02). **건물만 조각이다** — 사용자가 그렇게 말했고, 이유는 안 물었다.

⚠ **섬 파일의 `builds` 에는 성채·집·탑·창고·성벽 다섯이 있다.** 바리케이트가 그중 성벽인지 여섯째인지는
**「지을 수 있는 건물 중 하나」까지만 답이 왔다** — 09-01 이 묻는다.
