# Task 09 — 건물을 조각 단위로 짓고, 바리케이트로 길을 막는다

Task: 09
Name: 건물을 조각 단위로 짓고, 바리케이트로 길을 막는다
Status: ⏳ 하는 중 — 바리케이트는 지어졌다 (서고 · 양쪽 다 막고 · 갇힌 늑대가 부순다).
⚠⚠ **게임에서 세울 방법이 없다** — 짓기 모드가 창고에만 닿는다. 열린 티켓 둘
Chunk: **안 붙었다**
Days: **안 정해졌다** — 사용자가 정한다

## What is on screen when this task ends

**플레이어가 조각 하나를 골라 그 위에 건물을 세우고, 바리케이트를 세우면 짐승이 그 조각으로 못 지나간다.**

## Which line it moves

**「부대를 조종하고 지어서 몬스터를 잡는 게임」의 「지어서」.** 지금 서 있는 건물은 성채와 창고뿐이다.
⚠ **항구가 없어서 짐승이 아무 변에서나 온다** — 길목을 만드는 것이 이것이다.

## ✅ 정해진 것

- **건물은 조각 단위로 짓는다** — 칸이 아니다
- **바리케이트를 지어서 오는 것을 막는다**
- **바리케이트는 지을 수 있는 건물 중 하나이고, 성벽과 같은 것이다**

⚠ **「조각 단위」는 명령 단위와 어긋난다.** 명령도 자원도 칸인데 **건물만 조각이다** — 사용자가 그렇게
말했고 이유는 안 물었다.
⚠ **포탑은 안 들어간다.** 돌아온다면 이 태스크의 티켓이지 따로 서지 않는다.
