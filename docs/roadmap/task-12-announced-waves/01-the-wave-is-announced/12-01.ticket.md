## What this ticket builds
**A warning that goes up before every wave, the first one included: what is coming, and how long is
left.** Until it rings the player is free to be somewhere else.

### Where it came from
> The user: *"Before a wave comes, give a clear signal. So the time left can be spent
> outside farming."* (「웨이브가 오기 전에 확실한 신호를 주자. 그래서 남은 시간 동안 나가서 파밍할 수
> 있도록」)
>
> And on the first wave: *"Not wolves just turning up out of nowhere at the start either — you are
> farming, and it says a pack of wolves arrives in one minute."* (「처음에도 무작정 늑대가 오는 게 아니라
> 처음에 파밍하다가 일 분 뒤 늑대의 무리가 옵니다 하면 되잖아」)

## ✅ What is decided
- **Every wave is announced, the first included** — there is no unannounced attack
- **The announcement carries a clock** — 「in five minutes」, 「in one minute」 were both said
- **It names what is coming** — 바이킹, 늑대 무리. Not just 「something」
- **It is heard, not found.** ⚠ This is the reversal above: the player no longer has to spot a hull
- **A wave is not a broadside.** Its boats arrive slowly, spread over time — the user:
  *"Rather than several at once, I think they will come slowly, spread out over time."*
  (「여러 척이 한 번에 온다기보다는 천천히 시간을 두고 올 거 같아」)

## ⚠⚠ 실측 — what stands today
- **`BOAT_FIRST_SEC` 5.0 · `BOAT_INTERVAL_SEC` 30.0**, and the interval is deliberately one number
  rather than a band (「일정하게」)
- **`BOAT_SPEED_TILES` 1.2 exists because there was no alarm** — 22 조각 makes an 18.3 s crossing so a
  panning player could still find the boat. **With an alarm that reason is spent**
- **The HUD draws no clock at all.** The one clock that existed — 20 s auto-recruit — was deleted
- **A boat is not a wave.** Boats launch one at a time forever; nothing in `battle` groups them

## ✅ 한 판의 시계 — **the whole clock the run runs on**
**The user handed over every number in one round.** ⚠⚠ **They are FIRST numbers, not balance** —
the user: 「처음에는 한 시간을 잡고 갈 듯」 (*"For a start I think we hold it at one hour."*)

| What | The number | The user's words |
|---|---|---|
| **A run** | **one hour at most** | 「일단은 한판에 한 한 시간은 돼야 되듯 ... 최대 한 시간이고」 |
| **First wave** | **8 분** | 「처음 웨이브는 팔 분」 |
| **Every wave after** | **every 8 분** — seven in an hour | 「팔 분마다」 |
| **First boss** | **24 분** | the recommendation, taken |
| **Every boss after** | **every 24 분** — two in a run | the recommendation, taken |
| **Winning** | **kill the second boss** | the recommendation, taken |
| **The warning** | **3 분 before** | 「예고는 3분전」 |

⚠ **The warning is ONE number and does not split by where the player is.** The recommendation offered
1 분 at home and 5 분 away — both numbers the user had said before — and the user replaced both with a
single 3 분.

⚠⚠ **보스는 주기적으로 온다** — the user: 「보스가 주기적으로 오기 때문에」.
⚠⚠ **NO TICKET HOLDS THE BOSS CLOCK.** 태스크 12 owns the wave alarm; the boss belongs to 8 주 and has no
태스크 number at all. **The four boss numbers are written here only because there was nowhere else to
put them.** ⚠ **Where the boss ticket is cut is the user's call, never this file's.**

⚠⚠ **HOW MANY BOATS A WAVE IS STAYS OPEN, AND IT IS DELIBERATELY NOT A FORMULA.** The recommendation
was one boat rising by one per wave; the user refused the shape, not the number: 「그건 웨이브마다
설계해야할듯」 (*"I think that has to be designed per wave."*) ⇒ **a hand-written table of seven rows.**
The user then deferred writing it: 「웨이브표는 다음에」 (*"the wave table next time"*).
