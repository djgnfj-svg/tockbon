### 검사 detect — **3.0 조각**, a new number

**A 칸 is 2 조각, so its diagonal is 2.828, and 3.0 is that rounded up.** A 검사 notices anything
standing on a 칸 that touches his own, **and nothing further**. The order has spoken in 칸 since
2026-09-01, so *one 칸 out* is the smallest radius that answers the complaint.

- **It is half the 늑대's 6.0, so the hunter always notices first** — the asymmetry the unit table
  already writes down
- **3.0 < 8.06**, the gap the existing out-of-reach control stands its pair at, so that fixture's three
  rows stay green and this number costs the suite nothing
- ⚠⚠ **`detect_of` must NOT add `REACH_BONUS`.** `reach_of` is the ONE place that sum is written;
  mirroring it makes the 늑대's detection **7.75** with nothing on screen or in the table saying so
- ⚠ **Distance is 3D and a 층 is 1.0 조각 of height**, so at 3.0 a 검사 on the 눈금 2 plateau notices a
  늑대 2.83 조각 away on the flat below. **Noticing across a height is allowed by this ticket** —
  ticket 02-01 already left body-against-body strikes across that gap in scope for a later round, and
  the walk that would refuse it belongs to 07-02

### 늑대 detect — **6.0, and it stands unchanged**

**It is the only detect number any design in this repo ever wrote.** Changing it in the same edit that
gives it its first reader would make the result unattributable — the same argument the unit table
already makes about the beasts' other columns.

⚠⚠ **Say out loud what 6.0 means: it is THREE 칸.** Every 늑대 within three 칸 of a 검사 diverts off
the 성채, and **that has never been played.** The 성채's 120 HP was sized against **undefended** boats,
so these two numbers are coupled — a wave that never reaches the house is the failure this radius can
produce, and it is judged on screen, not in the table.

### ⚠⚠ The beast's half is ONE edit and cannot be cut smaller

**Today ANY non-`TARGET_NONE` target stops a 늑대's walk.** So widening its target choice alone
**freezes every 늑대 six 조각 short of the 검사 it just noticed** — and it stops walking at the 성채 at
the same time, which is a board-wide freeze.

⇒ **Widening the target choice and changing the movement gate are one edit**, and **the game does not
run between the two halves.** A 늑대 whose target is a 검사 must walk at that 검사; only `TARGET_KEEP`
and a body already inside 1.75 keep the stand-still branch.

⚠ **The two prose blocks this reverses are rewritten, never deleted** — the unit table's *"NO_DETECT
