### What was measured, in code

| What | Number |
|---|---|
| **성채 자리** | 섬 파일의 (10, 12), 2x2, **네 조각 전부 눈금 2** |
| **성채를 두른 1층 자리** | **여덟 개, 전부 고원 가장자리에 붙어 있다** |
| **1층에서 2층 성채 조각까지** | 평면 1 조각 · 높이 1 조각 → **1.414** |
| **대각선으로 붙어도** | **1.732** |
| **늑대 사거리** | **1.75** (사거리 칸 0 + `REACH_BONUS`) |
| **계단** | **네 조각뿐 — (6,6)·(7,6)·(6,7)·(7,7)**, 성채 반대편이다 |
| **해변에서 이기는 판** | **61 중 24 에서 계단을 안 밟고 이기고, 그쪽이 세 배 빠르다** |

⇒ **성채를 두른 1층 여덟 자리 전부에서 닿는다.**

⚠⚠ **It is not that height is ignored.** `keep_gap` already squares the height difference in and
measures 1.414 correctly — **the reach is simply longer than that.**

### ⚠ Why the reach value cannot be the fix

**1.75 was chosen by measurement so a body on a 계단 can strike an enemy one 눈금 above it.** Lower it and
nobody can strike from a 계단 at all — **26 of 162 runs were lost that way when it was tried.**
`rules.gd`'s own comment already says the fix belongs where the height is known.
