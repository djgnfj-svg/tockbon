# tools/lab — **개발지식의 실험대**

**`docs/개발지식/` 의 문서에 적힌 기법을 화면에서 하나씩 켜고 끄는 곳이다.**
문서는 「이렇게 하면 된다」고 말하고, **여기는 그게 정말인지 눈으로 보여 준다.**

## 띄우는 법

```
.\Godot_v4.7.1-stable_win64.exe --path . --script res://tools/lab/billboard_lab.gd
.\Godot_v4.7.1-stable_win64.exe --path . --script res://tools/lab/hit_lab.gd
.\Godot_v4.7.1-stable_win64.exe --path . --script res://tools/lab/move_lab.gd
```

⚠ **`--headless` 로는 볼 것이 없다.** 창을 띄워야 한다.

## 손

| 키 | 무엇 |
|---|---|
| **↑ ↓** | 기법 고르기 |
| **스페이스** | 고른 기법 켜고 끄기 |
| **A · Z** | 전부 켜기 · 전부 끄기 |
| **오른쪽 드래그 · Q E** | 돌리기 |
| **R F** | 기울기 |
| **휠** | 확대 |
| **Esc** | 끝 |

**실험대마다 자기 키가 더 있다.** 화면 아래에 적혀 있다 — 02 는 `B`(여덟이 한꺼번에), 03 은
`T`(자동으로 돌기) · `S`(한 명 세워 두기) · 왼쪽 클릭(그리로 가라).

## ⚠⚠ 조합은 만드는 게 아니라 켜는 것이다

**스위치 열여섯이면 볼 수 있는 화면은 65536 가지고, 코드는 열여섯 덩어리다.**
하나만 켜 보고, 둘씩 켜 보고, 전부 켜 보는 것이 전부 같은 코드로 나온다.

**대조군이 늘 옆에 있다.** 01 은 왼쪽 몸, 02 는 왼쪽 한 쌍이 스위치를 안 받는다 —
**「원래는 이랬다」를 기억으로 대지 않게** 하려는 것이다.

## ⚠⚠ 그림은 자리표시다

**`art/` 의 아홉 장은 게임에 안 들어간다.** 기법을 눈으로 보려고 세워 둔 것이고, 파이썬이 픽셀을
직접 찍어서 만든다. **게임에 들어가는 그림은 블렌더나 픽셀 도구로 만든다** — `CLAUDE.md` 의 규칙이다.

⚠ **음영이 없다.** 이 게임의 그림은 단색이다 (2026-08-29, 사용자: 「그림에 음영이 없어」).

## ⚠⚠ 아직 화면에서 한 번도 안 돌려 봤다

**이 셋은 고도가 없는 곳에서 쓰였다.** 문법과 이름은 정적으로 훑었고 — `Look` 의 상수 전부, 자기
함수 호출 전부, 들여쓰기 전부 — **그래도 화면에서 돈 적은 없다.**

**안 뜨면 볼 곳 셋**

1. **글자가 안 보인다** → 창 크기. 목록은 왼쪽 위, 도움말은 아래쪽 640 픽셀 자리에 있다
2. **몸이 자홍색 네모로 뜬다** → `art/` 의 그림을 못 읽은 것이다. `python tools/lab/make_art.py` 를 다시 돌린다
3. **스위치를 켜도 아무것도 안 바뀐다** → 그 기법이 이 실험대에 안 붙은 것이다. 문서의 기법 번호와
   화면의 번호를 대 보면 된다 — **붙은 것만 목록에 있다**
