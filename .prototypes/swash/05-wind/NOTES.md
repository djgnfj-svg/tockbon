# 05-wind — The waves come from one direction

Pictures: `../out/05-wind_*.png`

**Buys** — shelter that does not wander. The gradient dotted with a fixed heading tells every stretch
whether it faces the weather, so the windward shore is windward all game. 01's quiet patches drift,
which means the calm side of the island is a different side every minute; this one has a lee because it
has a shape.

**Costs** — two extra samples, and a heading that has to agree with whatever else on screen implies a
wind.

**Cannot** — ⚠⚠ **be reconciled with the glossary as written.** 해안선 is defined there as the line
**"whose thickness does not change wherever the wind blows from — because the water is always touching
the land."** This candidate keeps the resting line everywhere and takes a side only with the movement
on top of it, which is a narrower claim than the rule forbids — **but if the sheltered shore reads as
bare, the rule was right and this loses.** Watch the lee, not the exposed side.
