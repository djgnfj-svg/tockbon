# 03-steps — the same slopes, with the light cut into levels

**Where it comes from:** the same bent surface as `02-ripple`. What changes is the reading: the lambert
term is quantised to three levels, so a smooth slope produces a **hard-edged shape** instead of a fade.
Cel shading applied to water. ⚠ Ameye's stylised-water breakdown reaches for `Posterize` for the same
reason one stage earlier.

**What it buys** — **it is the only one that reads from across the room**, and the only one whose
lightness belongs to the same family as the island's flat-shaded faces. A step is a drawing; a gradient
is a photograph.

**What it costs** — the same two sines. The step itself is free.

**What it CANNOT do** — ⚠⚠ **it cannot stop being stripes.** Two crossed sines cut into levels are
bands, and bands running the whole width of the sea read as **corduroy**, not as sea. Breaking them up
means warping the height field with noise, at which point the bands become blotches and the hard edge —
the only reason to choose this over `02-ripple` — is what makes the blotches look like a stain.
