# 05-spiral — the 블록 owns the seat, off a sunflower spiral

Nine places on the golden angle, radius growing as √k so the area fills evenly. Closed form, so the
same nine land in the same places on every machine and every run.

- **What it buys** — **it reads as a group of men rather than as furniture.** No two bodies line up on
  any axis, and there is no grid for the eye to notice.
- **What it costs** — the spacing is uneven by construction, so **the tightest pair is always tighter
  than the grid's** and that pair overlaps first when the bodies grow.
- **What it CANNOT do** — hold a shape. There is no row, no front and no flank, so a player cannot read
  where the squad's edge is — which is exactly what has to be read when two squads meet.
